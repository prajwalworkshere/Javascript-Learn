# Topic 5.9: DOM Manipulation Mini-Project — Interactive Task Manager

## 1. Project Overview

We are going to build an interactive Task Manager application.

Users will be able to:

1. Add new tasks.
2. Display tasks dynamically.
3. Mark tasks as completed.
4. Delete tasks.
5. Filter tasks.
6. Display the total number of tasks.
7. Validate task input.
8. Update the page without refreshing it.

```html
<body>

    <div class="container">

        <h1>My Task Manager</h1>

        <!-- Task input form -->

        <form id="taskForm">

            <input
                type="text"
                id="taskInput"
                placeholder="Enter a new task"
                maxlength="100"

            </button>

            </button>

        </div>


        <!-- Task count -->

        <h3 id="taskCount">Total Tasks: 0</h3>


        <!-- Dynamic task list -->

        <ul id="taskList">

        </ul>

    </div>


    <script>

        // =========================================
        // 1. SELECT HTML ELEMENTS
        // =========================================

        const taskForm = document.getElementById("taskForm");

        const taskInput = document.getElementById("taskInput");

        const taskList = document.getElementById("taskList");

        const taskCount = document.getElementById("taskCount");

        const message = document.getElementById("message");

        const filterButtons =
            document.querySelectorAll(".filter-btn");


        // =========================================
        // 2. STORE APPLICATION DATA
        // =========================================

        let tasks = [];

        let currentFilter = "all";


        // =========================================
        // 3. ADD NEW TASK
        // =========================================

        taskForm.addEventListener("submit", function (event) {

            event.preventDefault();

            const taskName = taskInput.value.trim();

            // Validate input

            if (taskName === "") {

                message.textContent = "Please enter a task.";

                message.className = "error";

                return;
            }

            // Create task object

            const newTask = {
                id: Date.now(),
                title: taskName,
                completed: false
            };

            // Add task to array

            tasks.push(newTask);

            // Clear input

            taskInput.value = "";

            // Display updated task list

            renderTasks();

            // Display success message

            message.textContent = "Task added successfully!";

            message.className = "success";

        });


        // =========================================
        // 4. DISPLAY TASKS
        // =========================================

        function renderTasks() {

            // Clear existing HTML

            taskList.textContent = "";

            // Filter tasks according to selection

            const filteredTasks = tasks.filter(function (task) {

                if (currentFilter === "pending") {
                    return !task.completed;
                }

                if (currentFilter === "completed") {
                    return task.completed;
                }

                return true;

            });


            // Show empty message

            if (filteredTasks.length === 0) {

                const emptyMessage = document.createElement("li");

                emptyMessage.textContent = "No tasks to display.";

                emptyMessage.classList.add("empty-message");

                taskList.append(emptyMessage);

            }


            // Create HTML elements for each task

            filteredTasks.forEach(function (task) {

                const li = document.createElement("li");

                li.classList.add("task-item");

                li.dataset.id = task.id;


                // Mark completed task

                if (task.completed) {

                    li.classList.add("completed");

                }


                // Create task text

                const span = document.createElement("span");

                span.classList.add("task-text");

                span.textContent = task.title;


                // Create action buttons container

                const actions = document.createElement("div");

                actions.classList.add("task-actions");


                // Create complete button

                const completeButton = document.createElement("button");

                completeButton.type = "button";

                completeButton.classList.add("complete-btn");

                completeButton.dataset.action = "toggle";

                completeButton.textContent =
                    task.completed ? "Undo" : "Complete";


                // Create delete button

                const deleteButton = document.createElement("button");

                deleteButton.type = "button";

                deleteButton.classList.add("delete-btn");

                deleteButton.dataset.action = "delete";

                deleteButton.textContent = "Delete";


                // Add buttons to actions container

                actions.append(completeButton, deleteButton);


                // Add task text and buttons to list item

                li.append(span, actions);


                // Add list item to task list

                taskList.append(li);

            });


            // Update task count

            updateTaskCount();

        }


        // =========================================
        // 5. UPDATE TASK COUNT
        // =========================================

        function updateTaskCount() {

            const total = tasks.length;

            const completed = tasks.filter(function (task) {
                return task.completed;
            }).length;

            const pending = total - completed;

            taskCount.textContent =
                `Total: ${total} | Pending: ${pending} | Completed: ${completed}`;

        }


        // =========================================
        // 6. HANDLE TASK BUTTONS USING EVENT DELEGATION
        // =========================================

        taskList.addEventListener("click", function (event) {

            // Find the clicked action button

            const button = event.target.closest("button[data-action]");

            // Ignore clicks that did not originate inside an action button

            if (!button || !taskList.contains(button)) {
                return;
            }

            // Find the parent task item

            const taskItem = button.closest(".task-item");

            if (!taskItem) {
                return;
            }

            // Get task ID

            const taskId = Number(taskItem.dataset.id);


            // Check which action was clicked

            const action = button.dataset.action;


            // Complete or undo task

            if (action === "toggle") {

                const task = tasks.find(function (task) {
                    return task.id === taskId;
                });

                if (task) {
                    task.completed = !task.completed;
                }

            }


            // Delete task

            if (action === "delete") {

                tasks = tasks.filter(function (task) {
                    return task.id !== taskId;
                });

            }


            // Refresh interface

            renderTasks();

        });


        // =========================================
        // 7. FILTER TASKS
        // =========================================

        filterButtons.forEach(function (button) {

            button.addEventListener("click", function () {

                currentFilter = button.dataset.filter;

                // Remove active class from all buttons

                filterButtons.forEach(function (btn) {

                    btn.classList.remove("active");

                });

                // Add active class to selected button

                button.classList.add("active");

                // Display filtered tasks

                renderTasks();

            });

        });


        // =========================================
        // 8. INITIAL RENDER
        // =========================================

        renderTasks();

    </script>

</body>

</html>
```

## 5. Deep Explanation of Important Functions

### 5.1 Selecting DOM Elements

```javascript
const taskForm = document.getElementById("taskForm");

const taskInput = document.getElementById("taskInput");

const taskList = document.getElementById("taskList");
```

We select the elements once and store references to them in variables.

For example:

```javascript
const taskInput = document.getElementById("taskInput");
```

Now `taskInput` refers to the actual HTML input element.

We can read its value:

```javascript
taskInput.value;
```

We can update its value:

```javascript
taskInput.value = "";
```

We can add events:

```javascript
taskInput.addEventListener("input", function () {
    console.log(taskInput.value);
});
```

### 5.2 Understanding the tasks array

```javascript
let tasks = [];
```

Initially, the array is empty.

When a user adds a task:

```javascript
const newTask = {
    id: Date.now(),
    title: taskName,
    completed: false
};
```

We create an object representing one task.

Example:

```javascript
{
    id: 1790000000000,
    title: "Learn JavaScript",
    completed: false
}
```

The actual ID is generated when the code runs.

Then:

```javascript
tasks.push(newTask);
```

adds the object to the array.

After adding three tasks, the array might look like this:

```javascript
[
    {
        id: 101,
        title: "Learn JavaScript",
        completed: false
    },
    {
        id: 102,
        title: "Practice DOM",
        completed: true
    },
    {
        id: 103,
        title: "Build a project",
        completed: false
    }
]
```

The IDs above are illustrative. The project generates IDs using `Date.now()`.

**Important concept:** The array stores the application data. The DOM displays that data.

These are two separate things.

### 5.3 Understanding the `renderTasks()` function

This is the central function of our project.

```javascript
function renderTasks() {
    taskList.textContent = "";

    // Create and display task elements
}
```

Its responsibility is to make the displayed task list match the current `tasks` array and selected filter.

Whenever a task is added, completed, deleted, or filtered, we call:

```javascript
renderTasks();
```

The function rebuilds the visible list.

This is sometimes called rendering the UI.

### Why clear the list first?

```javascript
taskList.textContent = "";
```

Suppose the array contains three tasks and we call `renderTasks()` twice.

If we do not clear the old list, we could append the same three tasks again.

Clearing the list ensures we rebuild it from the current data.

### 5.4 Creating HTML elements dynamically

```javascript
const li = document.createElement("li");

li.classList.add("task-item");
```

This creates an `<li>` element in memory and adds a CSS class.

Next:

```javascript
const span = document.createElement("span");

span.textContent = task.title;
```

This creates a `<span>` and inserts the task title as text.

Then:

```javascript
li.append(span);
```

places the span inside the list item.

Finally:

```javascript
taskList.append(li);
```

adds the list item to the page.

The resulting HTML structure is approximately:

```html
<ul id="taskList">

    <li class="task-item">

        <span class="task-text">
            Learn JavaScript
        </span>

        <div class="task-actions">

            <button>Complete</button>

            <button>Delete</button>

        </div>

    </li>

</ul>
```

The browser displays this structure even though JavaScript created it dynamically.

### 5.5 Understanding `dataset`

The project uses:

```javascript
li.dataset.id = task.id;
```

This stores the task ID in a custom HTML data attribute.

The resulting HTML looks like:

```html
<li class="task-item" data-id="101">
```

We can read it using:

```javascript
const taskId = taskItem.dataset.id;
```

Important: Values in `dataset` are strings.

Therefore, we convert the ID to a number:

```javascript
const taskId = Number(taskItem.dataset.id);
```

We also use:

```javascript
button.dataset.action = "delete";
```

This creates:

```html
<button data-action="delete">Delete</button>
```

The `data-*` attribute allows us to associate useful information with HTML elements.

### 5.6 Understanding event delegation

Instead of adding a separate click listener to every Complete and Delete button, we add one listener to the parent list:

```javascript
taskList.addEventListener("click", function (event) {
    // Handle the click
});
```

Why?

Because tasks are created dynamically.

When a new task is added, its buttons are also created dynamically. A listener attached to the parent can handle clicks that bubble up from those buttons.

This technique is called **event delegation**.

We then find the relevant button:

```javascript
const button = event.target.closest("button[data-action]");
```

`event.target` is the original element where the click occurred.

`closest()` searches from that element upward for the nearest matching button.

Then:

```javascript
if (!button || !taskList.contains(button)) {
    return;
}
```

This ensures that we have found a button inside the task list.

We can identify its action:

```javascript
const action = button.dataset.action;
```

It will be either:

```text
toggle
```

or:

```text
delete
```

The same listener handles both actions.

### 5.7 Completing and undoing tasks

```javascript
const task = tasks.find(function (task) {
    return task.id === taskId;
});
```

`find()` searches the array and returns the first matching object.

Then:

```javascript
task.completed = !task.completed;
```

The `!` operator reverses the Boolean value.

| Before | After |
|---|---|
| `false` | `true` |
| `true` | `false` |

If the task is pending, it becomes completed.

If it is completed, it becomes pending again.

### 5.8 Deleting a task

```javascript
tasks = tasks.filter(function (task) {
    return task.id !== taskId;
});
```

`filter()` creates a new array containing only the tasks that satisfy the condition.

The condition:

```javascript
task.id !== taskId
```

keeps every task except the one we want to delete.

Example:

Before:

```javascript
[
    { id: 1, title: "Learn JS", completed: false },
    { id: 2, title: "Practice DOM", completed: false },
    { id: 3, title: "Build project", completed: false }
]
```

Suppose we delete task ID `2`.

After:

```javascript
[
    { id: 1, title: "Learn JS", completed: false },
    { id: 3, title: "Build project", completed: false }
]
```

Then `renderTasks()` updates the page.

### 5.9 Filtering tasks

We use:

```javascript
const filteredTasks = tasks.filter(function (task) {

    if (currentFilter === "pending") {
        return !task.completed;
    }

    if (currentFilter === "completed") {
        return task.completed;
    }

    return true;

});
```

Let's understand each condition.

**All tasks:**

```javascript
return true;
```

Every task is included.

**Pending tasks:**

```javascript
return !task.completed;
```

Only tasks where `completed` is `false` are included.

**Completed tasks:**

```javascript
return task.completed;
```

Only tasks where `completed` is `true` are included.

The filter changes what we display, not the underlying tasks array.

## 8. Common Mistakes and Debugging

### Mistake 1: Forgetting `preventDefault()`

If you forget:

```javascript
event.preventDefault();
```

the browser may submit the form normally and navigate or reload the page.

### Mistake 2: Not clearing the input

After adding a task, use:

```javascript
taskInput.value = "";
```

Otherwise, the old task text remains in the input.

### Mistake 3: Using `innerHTML` for user-entered task text

Avoid:

```javascript
span.innerHTML = task.title;
```

Prefer:

```javascript
span.textContent = task.title;
```

This treats the user's task title as text rather than HTML.

### Mistake 4: Adding listeners to dynamically created buttons individually

You could attach listeners when creating each button, but event delegation is more convenient for a dynamic list.

### Mistake 5: Forgetting to rerender

After changing the array, call:

```javascript
renderTasks();
```

Otherwise, the data changes but the displayed interface may remain outdated.

### Mistake 6: Confusing filtered tasks with the original array

```javascript
const filteredTasks = tasks.filter(...);
```

This creates a new array. It does not remove hidden tasks from `tasks`.

### Mistake 7: Forgetting that `dataset` values are strings

Use:

```javascript
const id = Number(taskItem.dataset.id);
```

when comparing against numeric IDs.

### Mistake 8: Using `event.target` as if it is always the button

A click may originate from a child element inside a button. Using `closest()` makes the handler more robust.

## 11. Interview and Viva Questions

### Q1. What is DOM manipulation?

DOM manipulation is the process of using JavaScript to access and modify the structure, content, attributes, and styles of HTML elements.

### Q2. What is dynamic element creation?

Dynamic element creation means creating HTML elements at runtime using JavaScript, commonly with `document.createElement()`.

### Q3. What is event delegation?

Event delegation is a technique in which an event listener is attached to a parent element to handle events originating from its child elements through event propagation.

### Q4. Why is event delegation useful?

It reduces the number of event listeners and makes it easier to handle dynamically created child elements.

### Q5. What is the difference between `append()` and `appendChild()`?

`append()` can insert multiple nodes and strings, while `appendChild()` inserts a single node and returns the appended node.

### Q6. What is the difference between `filter()` and `find()`?

`filter()` returns a new array containing all matching elements. `find()` returns the first matching element or `undefined`.

### Q7. What is `dataset`?

`dataset` provides access to an element's custom `data-*` attributes through JavaScript.

### Q8. What is the purpose of `closest()`?

`closest()` searches the element itself and its ancestors for the nearest element matching a CSS selector.

### Q9. Why use `textContent` instead of `innerHTML`?

`textContent` inserts content as text, avoiding the interpretation of user-provided strings as HTML.

### Q10. What is rendering in this project?

Rendering means updating the visible DOM to reflect the current application data and selected filter.

### Q11. What is the difference between application data and the DOM?

Application data represents the information stored by the program, while the DOM represents the browser's document structure. JavaScript uses the data to construct or update the DOM.

### Q12. Why do we call `renderTasks()` after changing the tasks array?

To synchronize the displayed task list with the updated application data.
