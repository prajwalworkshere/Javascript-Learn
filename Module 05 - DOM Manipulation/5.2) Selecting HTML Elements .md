# Module 5 — DOM Manipulation

# Topic 5.2: Selecting HTML Elements in JavaScript

## 1. Introduction to DOM Selection

DOM selection is the process of finding HTML elements through JavaScript so that we can read their content, change their text, modify attributes, update styles, handle events, or remove elements.

When a browser loads an HTML document, it creates a Document Object Model (DOM) tree. JavaScript uses the DOM API to access and manipulate that tree.

### Example

```html
<!DOCTYPE html>
<html>
<body>
    <h1 id="heading">Welcome</h1>
    <p class="message">Hello, JavaScript!</p>

    <script>
        const heading = document.getElementById("heading");
        const message = document.querySelector(".message");

        console.log(heading.textContent);
        console.log(message.textContent);
    </script>
</body>
</html>
```

**Expected output:**

```text
Welcome
Hello, JavaScript!
```

### How it works

1. `document` represents the current HTML document.
2. `getElementById("heading")` finds the element with the ID `heading`.
3. `querySelector(".message")` finds the first element with the class `message`.
4. The selected elements are stored in variables.
5. `textContent` reads their text.

The basic workflow is:

`HTML document → Select element → Store reference → Read or modify element`

## 2. Complete overview of DOM selection methods

The DOM provides several ways to find elements. The appropriate method depends on whether you want one element, multiple elements, a specific attribute match, or an element relative to another element.

| Method or property | Purpose | Result |
|---|---|---|
| `getElementById()` | Find an element by ID | Element or `null` |
| `getElementsByClassName()` | Find elements by class name | Live `HTMLCollection` |
| `getElementsByTagName()` | Find elements by tag name | Live `HTMLCollection` |
| `getElementsByName()` | Find elements by their `name` attribute | Live `NodeList` |
| `querySelector()` | Find the first match for a CSS selector | Element or `null` |
| `querySelectorAll()` | Find all matches for a CSS selector | Static `NodeList` |
| `closest()` | Find the nearest matching ancestor, including the element itself | Element or `null` |
| `matches()` | Check whether an element matches a CSS selector | Boolean |
| `children` | Access direct child elements | Live `HTMLCollection` |
| `childNodes` | Access all direct child nodes, including text and comments | Live `NodeList` |

These are important selection APIs and related DOM traversal properties. The first six are the main document-selection methods to learn first.

## 3. `getElementById()`

### 3.1 Definition

`getElementById()` returns the element whose `id` matches the supplied string.

### 3.2 Syntax

```javascript
document.getElementById("idName");
```

**Important:** Do not include `#` in the argument.

### 3.3 Complete example

```html
<!DOCTYPE html>
<html>
<body>
    <h1 id="mainHeading">Learn JavaScript</h1>
    <p id="description">JavaScript is a programming language.</p>

    <script>
        const heading = document.getElementById("mainHeading");
        const description = document.getElementById("description");

        console.log(heading.textContent);
        console.log(description.textContent);
    </script>
</body>
</html>
```

**Expected output:**

```text
Learn JavaScript
JavaScript is a programming language.
```

### 3.4 Dry run

| Step | Operation | Result |
|---|---|---|
| 1 | Search for ID `mainHeading` | `<h1>` is found |
| 2 | Store result in `heading` | Reference to the `<h1>` |
| 3 | Search for ID `description` | `<p>` is found |
| 4 | Read both `textContent` values | Two text strings are printed |

### 3.5 What happens if an element is missing?

```javascript
const element = document.getElementById("missing");

console.log(element);
```

Output:

```text
null
```

If you then access `element.textContent`, JavaScript throws a `TypeError` because `element` is `null`.

Safer approach:

```javascript
const element = document.getElementById("missing");

if (element !== null) {
    console.log(element.textContent);
} else {
    console.log("Element not found");
}
```

Output:

```text
Element not found
```

### 3.6 Common mistakes

```javascript
// Correct
document.getElementById("mainHeading");

// Incorrect for getElementById()
document.getElementById("#mainHeading");
```

HTML IDs should be unique within a document. If duplicate IDs exist, do not rely on the method to identify the intended element.

### 3.7 Practical uses

- Finding a form or button.
- Updating a page heading.
- Reading a specific message.
- Selecting a particular section of a page.

## 4. `getElementsByClassName()`

### 4.1 Definition

`getElementsByClassName()` returns a live `HTMLCollection` of descendant elements that have the specified class name or class names.

### 4.2 Syntax

```javascript
document.getElementsByClassName("className");
```

### 4.3 Essential rules

1. Pass the class name **without a dot**.
2. The method returns a collection, not a single element.
3. Use indexing, such as `[0]`, to access a matching element.
4. The collection is live and reflects relevant changes to the DOM.
5. If no element matches, the method returns an empty collection, not `null`.
6. Multiple class names can be separated by spaces. An element must have all specified classes to match.

### 4.4 Example: Selecting one class

```html
<!DOCTYPE html>
<html>
<body>
    <p class="message">First message</p>
    <p class="message">Second message</p>
    <p class="other">Another paragraph</p>

    <script>
        const elements =
            document.getElementsByClassName("message");

        console.log(elements.length);
        console.log(elements[0].textContent);
        console.log(elements[1].textContent);
    </script>
</body>
</html>
```

**Expected output:**

```text
2
First message
Second message
```

### 4.5 Dry run

- The first paragraph has class `message`, so it matches.
- The second paragraph also has class `message`, so it matches.
- The third paragraph has class `other`, so it does not match.
- The collection contains two elements.
- `elements[0]` accesses the first match.
- `elements[1]` accesses the second match.

Remember that indexing starts at `0`.

### 4.6 Example: Selecting elements with multiple classes

```html
<p class="card featured">Featured card</p>
<p class="card">Regular card</p>
<p class="featured">Featured item</p>

<script>
    const elements =
        document.getElementsByClassName("card featured");

    console.log(elements.length);
    console.log(elements[0].textContent);
</script>
```

**Expected output:**

```text
1
Featured card
```

Only the first paragraph contains both classes.

The class order in the HTML does not matter. For example, `class="featured card"` also matches the query `"card featured"`.

### 4.7 The dot difference

```javascript
// Correct: class name without a dot
document.getElementsByClassName("message");

// Correct: CSS selector with a dot
document.querySelector(".message");
```

This is incorrect for an ordinary `class="message"` element:

```javascript
document.getElementsByClassName(".message");
```

`getElementsByClassName()` accepts class names, not CSS selector syntax.

### 4.8 Updating all matching elements

```html
<p class="notice">Notice one</p>
<p class="notice">Notice two</p>

<script>
    const notices = document.getElementsByClassName("notice");

    for (let i = 0; i < notices.length; i++) {
        notices[i].textContent = "Updated notice";
    }
</script>
```

**Result:** Both paragraphs display `Updated notice`.

### 4.9 Understanding a live collection

```html
<p class="item">Item one</p>

<script>
    const items = document.getElementsByClassName("item");

    console.log(items.length);

    const newItem = document.createElement("p");
    newItem.className = "item";
    newItem.textContent = "Item two";

    document.body.appendChild(newItem);

    console.log(items.length);
</script>
```

**Expected output:**

```text
1
2
```

The same collection reflects the new matching paragraph without another selection call.

### 4.10 Common mistake: assuming a match exists

```javascript
const items = document.getElementsByClassName("missing");

// If no matching elements exist:
console.log(items.length); // 0
console.log(items[0]);     // undefined
```

An empty collection is not `null`, but accessing its first item returns `undefined`.

## 5. `getElementsByTagName()`

### 5.1 Definition

`getElementsByTagName()` returns a live `HTMLCollection` of descendant elements whose tag names match the supplied name.

### 5.2 Syntax

```javascript
document.getElementsByTagName("tagName");
```

### 5.3 Example

```html
<!DOCTYPE html>
<html>
<body>
    <h2>First heading</h2>
    <p>First paragraph</p>
    <p>Second paragraph</p>
    <p>Third paragraph</p>

    <script>
        const paragraphs =
            document.getElementsByTagName("p");

        console.log(paragraphs.length);
        console.log(paragraphs[0].textContent);
        console.log(paragraphs[2].textContent);
    </script>
</body>
</html>
```

**Expected output:**

```text
3
First paragraph
Third paragraph
```

### 5.4 Dry run

1. JavaScript selects every descendant `<p>` element.
2. There are three matching paragraphs.
3. `paragraphs.length` returns `3`.
4. `paragraphs[0]` refers to the first paragraph.
5. `paragraphs[2]` refers to the third paragraph.

### 5.5 Updating all selected paragraphs

```javascript
const paragraphs = document.getElementsByTagName("p");

for (let i = 0; i < paragraphs.length; i++) {
    paragraphs[i].style.color = "blue";
}
```

This sets all matching paragraph text to blue.

### 5.6 Common mistake

```javascript
// Correct
document.getElementsByTagName("p");

// Incorrect: this method expects a tag name
document.getElementsByTagName(".message");
```

Use `querySelectorAll(".message")` when you need to select elements by a CSS class selector.

## 6. `getElementsByName()`

### 6.1 Definition

`getElementsByName()` returns a live `NodeList` of elements whose `name` attribute matches the supplied value.

It is especially useful for form controls that share the same name.

### 6.2 Syntax

```javascript
document.getElementsByName("fieldName");
```

### 6.3 Example: Selecting radio buttons

```html
<!DOCTYPE html>
<html>
<body>
    <label>
        <input type="radio" name="plan" value="basic">
        Basic
    </label>

    <label>
        <input type="radio" name="plan" value="premium">
        Premium
    </label>

    <script>
        const plans = document.getElementsByName("plan");

        console.log(plans.length);
        console.log(plans[0].value);
        console.log(plans[1].value);
    </script>
</body>
</html>
```

**Expected output:**

```text
2
basic
premium
```

### 6.4 Dry run

1. JavaScript searches for elements with `name="plan"`.
2. Both radio buttons match.
3. `plans.length` returns `2`.
4. The `value` property reads the value of each radio button.

### 6.5 When should you use it?

Use `getElementsByName()` when you need to work with controls that share a `name`, such as radio buttons.

For more complex selection requirements, `querySelectorAll()` is often more flexible.

**Important distinction:** `id` identifies a particular element, while `name` is commonly used to identify form fields and group related controls.

## 7. `querySelector()`

### 7.1 Definition

`querySelector()` returns the first element that matches a valid CSS selector.

### 7.2 Syntax

```javascript
document.querySelector("CSS selector");
```

Unlike the `getElement...` methods, it accepts CSS selector syntax.

### 7.3 Example: Selecting by ID

```html
<h1 id="title">JavaScript Basics</h1>

<script>
    const heading = document.querySelector("#title");
    console.log(heading.textContent);
</script>
```

**Output:**

```text
JavaScript Basics
```

### 7.4 Example: Selecting by class

```html
<p class="message">First message</p>
<p class="message">Second message</p>

<script>
    const message = document.querySelector(".message");
    console.log(message.textContent);
</script>
```

**Output:**

```text
First message
```

Only the first matching element is returned.

### 7.5 Example: Selecting by tag

```javascript
const firstParagraph = document.querySelector("p");
```

This selects the first matching `<p>` element.

### 7.6 Example: Selecting a descendant

```html
<div class="container">
    <p>Inside the container</p>
</div>

<p>Outside the container</p>

<script>
    const paragraph = document.querySelector(".container p");
    console.log(paragraph.textContent);
</script>
```

**Output:**

```text
Inside the container
```

The selector `.container p` finds a paragraph that is a descendant of an element with class `container`.

### 7.7 Example: Selecting by attribute

```html
<input type="email" name="email">

<script>
    const emailInput =
        document.querySelector('input[type="email"]');

    console.log(emailInput.type);
</script>
```

**Output:**

```text
email
```

### 7.8 No matching element

```javascript
const element = document.querySelector(".not-found");

console.log(element);
```

**Output:**

```text
null
```

A valid selector with no match returns `null`. An invalid CSS selector can throw a `SyntaxError`.

## 8. `querySelectorAll()`

### 8.1 Definition

`querySelectorAll()` returns a static `NodeList` containing all elements that match the supplied CSS selector.

### 8.2 Syntax

```javascript
document.querySelectorAll("CSS selector");
```

### 8.3 Example

```html
<!DOCTYPE html>
<html>
<body>
    <p class="message">First message</p>
    <p class="message">Second message</p>
    <p class="message">Third message</p>
    <p>Other paragraph</p>

    <script>
        const messages = document.querySelectorAll(".message");

        console.log(messages.length);
        console.log(messages[0].textContent);
        console.log(messages[1].textContent);
        console.log(messages[2].textContent);
    </script>
</body>
</html>
```

**Expected output:**

```text
3
First message
Second message
Third message
```

### 8.4 Iterating with `forEach()`

```javascript
const messages = document.querySelectorAll(".message");

messages.forEach(function(message) {
    message.style.color = "green";
});
```

This changes the text color of every selected message to green.

### 8.5 Static collection behavior

```html
<p class="item">Item one</p>

<script>
    const items = document.querySelectorAll(".item");

    console.log(items.length);

    const newItem = document.createElement("p");
    newItem.className = "item";
    newItem.textContent = "Item two";

    document.body.appendChild(newItem);

    console.log(items.length);
    console.log(document.querySelectorAll(".item").length);
</script>
```

**Expected output:**

```text
1
1
2
```

The original `items` collection remains unchanged. A new call to `querySelectorAll()` includes the newly added element.

### 8.6 What if no elements match?

```javascript
const items = document.querySelectorAll(".not-found");

console.log(items.length);
```

**Output:**

```text
0
```

`querySelectorAll()` returns an empty `NodeList`, not `null`.

## 9. CSS Selectors for DOM Selection

To use `querySelector()` and `querySelectorAll()` effectively, understand the following CSS selector patterns.

Assume this HTML:

```html
<div id="app" class="container">
    <p class="message">Hello</p>
    <p class="message featured">Welcome</p>
    <span data-role="status">Ready</span>
</div>
```

| CSS selector | Meaning |
|---|---|
| `p` | Select paragraph elements |
| `#app` | Select the element with ID `app` |
| `.message` | Select elements with class `message` |
| `.message.featured` | Select elements with both classes |
| `.container p` | Select paragraph descendants of `.container` |
| `.container > p` | Select paragraphs that are direct children of `.container` |
| `p, span` | Select paragraphs and spans |
| `[data-role="status"]` | Select elements with the specified attribute and value |
| `input[type="email"]` | Select email input elements |

### 9.1 Descendant versus direct child

```javascript
document.querySelectorAll(".container p");
```

This selects paragraphs anywhere inside `.container`, including nested descendants.

```javascript
document.querySelectorAll(".container > p");
```

This selects only paragraphs that are direct children of `.container`.

### 9.2 Selecting multiple classes

```javascript
document.querySelectorAll(".message.featured");
```

The selected element must have both `message` and `featured`.

Do not put a space between the class selectors when you mean both classes on the same element.

- `.message.featured` means both classes on one element.
- `.message .featured` means an element with class `featured` inside an element with class `message`.

## 10. `closest()`

### 10.1 Definition

`closest()` checks the element itself and then moves up through its ancestors until it finds the nearest element matching a CSS selector.

It returns the matching element or `null` if no match is found.

### 10.2 Syntax

```javascript
element.closest("CSS selector");
```

### 10.3 Example

```html
<div class="card">
    <div class="card-body">
        <button id="buyButton">Buy</button>
    </div>
</div>

<script>
    const button = document.getElementById("buyButton");
    const card = button.closest(".card");

    console.log(card.className);
</script>
```

**Output:**

```text
card
```

### 10.4 Dry run

1. `button` refers to the button element.
2. `closest(".card")` checks the button first.
3. The button does not have class `card`.
4. JavaScript checks its parent, then continues upward.
5. It finds the nearest ancestor with class `card`.
6. That element is returned.

### 10.5 Practical use

`closest()` is useful when a user clicks a button inside a card and your code needs to find the card containing that button.

---

## 11. `matches()`

### 11.1 Definition

`matches()` checks whether an element matches a specified CSS selector. It returns a Boolean value: `true` or `false`.

### 11.2 Syntax

```javascript
element.matches("CSS selector");
```

### 11.3 Example

```html
<button id="saveButton" class="button primary">Save</button>

<script>
    const button = document.getElementById("saveButton");

    console.log(button.matches(".primary"));
    console.log(button.matches(".danger"));
    console.log(button.matches("button"));
</script>
```

**Expected output:**

```text
true
false
true
```

### 11.4 Practical use

You can check whether an element has a particular class or matches a particular type of selector before performing an operation.

```javascript
if (button.matches(".primary")) {
    console.log("This is a primary button");
}
```

Output:

```text
This is a primary button
```

**Important:** `matches()` does not search the document for another element. It checks the element on which it is called.

## 12. `children` and `childNodes`

These are DOM properties rather than methods, but they are important for selecting related nodes and elements.

### 12.1 `children`

`children` provides a live `HTMLCollection` containing the direct child **elements** of a node.

```html
<div id="container">
    <p>First paragraph</p>
    <span>Second element</span>
</div>

<script>
    const container = document.getElementById("container");

    console.log(container.children.length);
    console.log(container.children[0].tagName);
    console.log(container.children[1].tagName);
</script>
```

**Expected output:**

```text
2
P
SPAN
```

Whitespace and text between the elements are not included in `children`.

### 12.2 `childNodes`

`childNodes` provides a live `NodeList` containing all direct child nodes, including text nodes and comment nodes.

```html
<div id="container"><p>Hello</p></div>

<script>
    const container = document.getElementById("container");

    console.log(container.childNodes.length);
    console.log(container.children.length);
</script>
```

**Expected output:**

```text
1
1
```

In this example, the `<div>` contains one direct child node: the `<p>` element. The paragraph's text is a child of the paragraph, not a direct child of the `<div>`.

If whitespace or comments are added directly inside the `<div>`, `childNodes.length` can be larger than `children.length`.

### 12.3 Key difference

| Property | Contains | Return type |
|---|---|---|
| `children` | Direct child elements only | Live `HTMLCollection` |
| `childNodes` | All direct child nodes, including text and comments | Live `NodeList` |

Use `children` when you need direct child elements. Use `childNodes` when you need all child nodes.

The `document` object also exposes convenient collections for common element types.

```text

1
1
```

These properties are convenient for common cases. For more complex requirements, use the appropriate selection methods.

## 14. Selecting Within a Parent Element

You do not always need to search the entire document. You can select an element first and then search within it.

### Example

```html
<div id="container">
    <p class="message">Inside container</p>
</div>

<p class="message">Outside container</p>

<script>
    const container = document.getElementById("container");

    const message = container.querySelector(".message");
    const messages = container.querySelectorAll(".message");

    console.log(message.textContent);
    console.log(messages.length);
</script>
```

**Expected output:**

```text
Inside container
1
```

The queries on `container` search its descendants, not the entire document.

The same principle applies to methods such as `getElementsByClassName()` and `getElementsByTagName()` when called on an element.

## 15. Live Collections versus Static Collections

This is a key interview topic.

### 15.1 Live collections

The following return live collections:

```javascript
document.getElementsByClassName("item");
document.getElementsByTagName("p");
document.getElementsByName("plan");
element.children;
element.childNodes;
```

A live collection reflects relevant DOM changes automatically.

### 15.2 Static collection

```javascript
document.querySelectorAll(".item");
```

The `NodeList` returned by `querySelectorAll()` is static. It does not automatically include elements added after the query.

### 15.3 Comparison

| Feature | Live `HTMLCollection` | Static `NodeList` from `querySelectorAll()` |
|---|---|---|
| Indexing | Yes | Yes |
| `length` property | Yes | Yes |
| Updates after DOM changes | Automatically reflects relevant changes | Does not update |
| Supports `forEach()` directly | Not as a standard `HTMLCollection` method | Yes |
| Example | `getElementsByClassName()` | `querySelectorAll()` |

**Important:** Not every `NodeList` is static. For example, `childNodes` returns a live `NodeList`. The method that produced the collection determines its behavior.

### 15.4 Converting a collection into an array

```javascript
const collection = document.getElementsByClassName("item");
const itemsArray = Array.from(collection);
```

`itemsArray` is an ordinary array. It does not automatically update when the DOM changes.

## 16. How to Choose the Correct Selection Method

| Requirement | Recommended approach |
|---|---|
| Select one element by ID | `getElementById()` |
| Select the first match using CSS syntax | `querySelector()` |
| Select all matches using CSS syntax | `querySelectorAll()` |
| Select by class name | `getElementsByClassName()` |
| Select by tag name | `getElementsByTagName()` |
| Select controls by `name` | `getElementsByName()` |
| Find the nearest matching ancestor | `closest()` |
| Check whether an element matches a selector | `matches()` |
| Get direct child elements | `children` |
| Get all direct child nodes | `childNodes` |

For modern code, `querySelector()` and `querySelectorAll()` are especially flexible because they support CSS selectors. However, the other methods remain useful and commonly appear in existing code.

## 17. Common Mistakes

### Mistake 1: Adding a dot to `getElementsByClassName()`

```javascript
// Incorrect for class="message"
document.getElementsByClassName(".message");

// Correct
document.getElementsByClassName("message");
```

### Mistake 2: Forgetting the hash in `querySelector()`

```javascript
// Correct: selects by ID
document.querySelector("#heading");

// Selects a <heading> tag, if one exists
document.querySelector("heading");
```

### Mistake 3: Treating a collection as a single element

```javascript
const messages = document.getElementsByClassName("message");

// Incorrect: messages is a collection
// messages.textContent = "Updated";

// Correct: access a specific matching element
if (messages.length > 0) {
    messages[0].textContent = "Updated";
}
```

### Mistake 4: Expecting `querySelector()` to return all matches

```javascript
const firstMessage = document.querySelector(".message");
```

This returns only the first matching element. Use `querySelectorAll()` to get all matching elements.

### Mistake 5: Confusing a missing element with an empty collection

```javascript
const oneElement = document.getElementById("missing");
const manyElements = document.querySelectorAll(".missing");

console.log(oneElement);        // null
console.log(manyElements.length); // 0
```

A single-element query returns `null` when nothing matches. A multiple-element query returns an empty collection.

### Mistake 6: Assuming all collections update automatically

```javascript
const items = document.querySelectorAll(".item");
```

This collection is static. Query again if you need a fresh result after DOM changes.

### Mistake 7: Selecting before the target HTML exists

If JavaScript runs before an element has been parsed, the selection might return `null` or an empty collection.

One solution is to put the script after the relevant HTML:

```html
<body>
    <p id="message">Hello</p>

    <script>
        const message = document.getElementById("message");
        console.log(message.textContent);
    </script>
</body>
```

Another option is to wait for `DOMContentLoaded`:

```javascript
document.addEventListener("DOMContentLoaded", function() {
    const message = document.getElementById("message");
    console.log(message.textContent);
});
```

### Mistake 8: Using an invalid CSS selector

```javascript
// Valid
document.querySelector(".message");

// Invalid CSS selector: can throw SyntaxError
// document.querySelector("..message");
```

Check that the selector follows CSS selector syntax.

## 18. Practical Mini-Project: Update Product Cards

This example combines IDs, classes, `querySelectorAll()`, nested selection, and event handling.

```html
<!DOCTYPE html>
<html>
<head>
    <title>Product Cards</title>
</head>
<body>
    <h1 id="pageTitle">Our Products</h1>

    <div class="product">
        <h2 class="product-name">Keyboard</h2>
        <p class="price">₹1,000</p>
    </div>

    <div class="product">
        <h2 class="product-name">Mouse</h2>
        <p class="price">₹500</p>
    </div>

    <button id="updateButton">Update Product Names</button>

    <script>
        const title = document.getElementById("pageTitle");
        const products = document.querySelectorAll(".product");
        const button = document.getElementById("updateButton");

        console.log(title.textContent);
        console.log("Products found:", products.length);

        button.addEventListener("click", function() {
            products.forEach(function(product, index) {
                const name = product.querySelector(".product-name");
                name.textContent = "Product " + (index + 1);
            });
        });
    </script>
</body>
</html>
```

### Before clicking the button

The page displays:

- Our Products
- Keyboard — ₹1,000
- Mouse — ₹500
- Update Product Names

The console displays:

```text
Our Products
Products found: 2
```

### After clicking the button

The product names become:

- Product 1 — ₹1,000
- Product 2 — ₹500

### Explanation

1. `getElementById()` selects the heading and button.
2. `querySelectorAll(".product")` selects both product containers.
3. `addEventListener()` registers a click handler.
4. `forEach()` processes each product.
5. `product.querySelector(".product-name")` searches inside the current product only.
6. `textContent` changes the product name without changing the price.

This is a common pattern in interactive web pages: select parent elements, then select the relevant descendants inside each parent.

## 20. Interview Questions and Answers

### Q1. What is DOM selection?

DOM selection is the process of finding HTML elements through JavaScript so that their content, attributes, styles, or behavior can be accessed or modified.

### Q2. What does `getElementById()` return?

It returns the element with the specified ID, or `null` if no matching element exists.

### Q3. What does `getElementsByClassName()` return?

It returns a live `HTMLCollection` of descendant elements matching the specified class name or class names.

### Q4. Should you use a dot in `getElementsByClassName()`?

No. Pass `"message"`, not `".message"`. The dot belongs to CSS selector syntax.

### Q5. How do you select an element with two classes using `getElementsByClassName()`?

Pass both class names separated by a space:

```javascript
document.getElementsByClassName("card active");
```

An element must have both classes to match.

### Q6. What does `getElementsByTagName()` return?

It returns a live `HTMLCollection` of descendant elements matching the specified tag name.

### Q7. What is `getElementsByName()` used for?

It finds elements whose `name` attribute matches a specified value. It is often useful for groups of form controls.

### Q8. What is the difference between `querySelector()` and `querySelectorAll()`?

`querySelector()` returns the first matching element or `null`. `querySelectorAll()` returns a static `NodeList` containing all matching elements.

### Q9. What is an `HTMLCollection`?

An `HTMLCollection` is an array-like collection of HTML elements. It supports indexing and the `length` property, but it is not an ordinary JavaScript array.

### Q10. What is a live collection?

A live collection automatically reflects relevant changes to the DOM, such as matching elements being added or removed.

### Q11. Is every `NodeList` static?

No. `querySelectorAll()` returns a static `NodeList`, but `childNodes` returns a live `NodeList`.

### Q12. What happens if `querySelectorAll()` finds no elements?

It returns an empty `NodeList` whose `length` is `0`.

### Q13. What is the difference between `closest()` and `querySelector()`?

`querySelector()` searches descendants of the object on which it is called. `closest()` checks the current element and then its ancestors, moving upward.

### Q14. What does `matches()` return?

It returns `true` if the element matches the supplied CSS selector and `false` otherwise.

### Q15. What is the difference between `children` and `childNodes`?

`children` contains direct child elements only. `childNodes` includes direct child nodes such as elements, text nodes, and comments.

### Q16. Can selection methods be called on an element instead of `document`?

Yes. Methods such as `querySelector()`, `querySelectorAll()`, `getElementsByClassName()`, and `getElementsByTagName()` can be used to search within an element's descendants.

### Q17. What is the difference between `id` and `class` selection?

An ID normally identifies one unique element, whereas a class can be shared by multiple elements.

### Q18. Why might a selection return `null`?

A single-element selection may return `null` if no matching element exists, or if the code executes before the relevant element has been parsed.

### Q19. Can an invalid CSS selector cause an error?

Yes. `querySelector()`, `querySelectorAll()`, `closest()`, and `matches()` can throw a `SyntaxError` if given an invalid selector.

### Q20. Which selection method should you use in modern JavaScript?

Use the method that best fits the requirement. `querySelector()` and `querySelectorAll()` are versatile because they support CSS selectors, while the other methods can be more direct for specific cases such as selecting by ID or class.

## 22. Quick Reference

```javascript
// Select one element by ID
document.getElementById("heading");

// Select by class name — no dot
document.getElementsByClassName("message");

// Select by tag name
document.getElementsByTagName("p");

// Select by name attribute
document.getElementsByName("plan");

// Select the first CSS selector match
document.querySelector(".message");

// Select all CSS selector matches
document.querySelectorAll(".message");

// Select an element with both classes
document.querySelector(".card.active");

// Find the nearest matching ancestor
element.closest(".card");

// Check whether an element matches a selector
element.matches(".primary");

// Access direct child elements
element.children;

// Access all direct child nodes
element.childNodes;

// Select a descendant inside a parent
const container = document.getElementById("container");
const message = container.querySelector(".message");
```
