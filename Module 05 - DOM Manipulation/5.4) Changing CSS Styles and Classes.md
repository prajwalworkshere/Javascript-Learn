# Module 5 — DOM Manipulation

# Topic 5.4: Changing CSS Styles and Classes in JavaScript

## 1. Introduction

JavaScript can modify the appearance of HTML elements by interacting with CSS through the DOM.

Consider a simple HTML element:

```html
<h1 id="heading">Hello JavaScript</h1>
```

CSS:

```css
h1 {
    color: blue;
    font-size: 30px;
}
```

Now suppose we want to change the heading color to red when a button is clicked.

We can use JavaScript:

```javascript
const heading = document.getElementById("heading");

heading.style.color = "red";
```

The heading's color changes from blue to red.

This is called **dynamic styling** because JavaScript changes the appearance of an element while the webpage is running.

### What will we learn?

There are two main approaches to changing CSS using JavaScript:

1. **Inline style manipulation:** Change CSS properties directly using `element.style`.
2. **CSS class manipulation:** Add, remove, or toggle CSS classes using `element.classList`.

We will also learn how to read computed styles using `getComputedStyle()`.

---

# 2. Understanding `element.style`

## 2.1 Definition

The `style` property provides access to an element's inline CSS styles through JavaScript.

It allows us to read, add, or modify CSS declarations directly on an HTML element.

### Interview definition

The `style` property is a DOM property that provides access to an element's inline CSS styles, allowing JavaScript to dynamically modify its appearance.

## 2.2 Syntax

```javascript
element.style.propertyName = "value";
```

Here:

- `element` is the selected HTML element.
- `style` accesses its inline CSS declarations.
- `propertyName` is the CSS property we want to change.
- `value` is the new CSS value.

### Example

```html
<h1 id="heading">Hello JavaScript</h1>

<script>
    const heading = document.getElementById("heading");

    heading.style.color = "red";
</script>
```

**Result:** The heading appears in red.

## 2.3 Important: JavaScript CSS property naming

CSS property names often use hyphens, whereas JavaScript style properties generally use camelCase.

| CSS property | JavaScript property |
|---|---|
| `background-color` | `backgroundColor` |
| `font-size` | `fontSize` |
| `font-weight` | `fontWeight` |
| `text-align` | `textAlign` |
| `border-radius` | `borderRadius` |
| `margin-top` | `marginTop` |
| `padding-left` | `paddingLeft` |
| `border-color` | `borderColor` |
| `max-width` | `maxWidth` |
| `min-height` | `minHeight` |
| `line-height` | `lineHeight` |
| `z-index` | `zIndex` |

**Rule:** When using CSS properties through `element.style`, convert hyphenated CSS property names into camelCase.

For example:

```javascript
// CSS: background-color
element.style.backgroundColor = "yellow";

// CSS: font-size
element.style.fontSize = "24px";

// CSS: border-radius
element.style.borderRadius = "10px";
```

# 5. Reading Inline Styles Using `element.style`

So far, we have used `style` to change CSS properties.

We can also use it to read inline styles.

## 5.1 Syntax

```javascript
element.style.propertyName;
```

### Example

```html
<h1 id="heading" style="color: red; font-size: 30px;">
    Hello JavaScript
</h1>

<script>
    const heading = document.getElementById("heading");

    console.log(heading.style.color);
    console.log(heading.style.fontSize);
</script>
```

**Expected output:**

```text
red
30px
```

## 5.2 Important: `element.style` reads inline styles

Consider this example:

```html
<!DOCTYPE html>
<html>
<head>
    <style>
        h1 {
            color: blue;
        }
    </style>
</head>
<body>

    <h1 id="heading">Hello JavaScript</h1>

    <script>
        const heading = document.getElementById("heading");

        console.log(heading.style.color);
    </script>

</body>
</html>
```

**Expected output:**

```text

```

Why is the output empty?

Because the CSS color was applied through a stylesheet, not through the element's inline `style` attribute.

`element.style` does not return the complete CSS styling applied to an element. It provides access to its inline style declarations.

To read the final calculated style, use `getComputedStyle()`.

# 6. `getComputedStyle()` in JavaScript

## 6.1 Definition

`getComputedStyle()` is a browser method that returns an object containing the computed CSS property values of an element.

It helps us read the final styles applied to an element after the browser considers applicable stylesheets, CSS rules, inheritance, and the cascade.

### Interview definition

`getComputedStyle()` is a JavaScript browser method that returns a read-only object containing the computed CSS values of an element.

## 6.2 Syntax

```javascript
getComputedStyle(element);
```

It takes the element whose computed styles we want to inspect.

The returned object provides access to CSS properties.

```javascript
const styles = getComputedStyle(element);

console.log(styles.color);
console.log(styles.backgroundColor);
console.log(styles.fontSize);
```

## 6.3 Example 1: Reading CSS from a stylesheet

```html
<!DOCTYPE html>
<html>
<head>
    <style>
        #heading {
            color: blue;
            font-size: 30px;
            background-color: yellow;
        }
    </style>
</head>
<body>

    <h1 id="heading">Hello JavaScript</h1>

    <script>
        const heading = document.getElementById("heading");

        const styles = getComputedStyle(heading);

        console.log(styles.color);
        console.log(styles.fontSize);
        console.log(styles.backgroundColor);
    </script>

</body>
</html>
```

**Expected output in a typical browser:**

```text
rgb(0, 0, 255)
30px
rgb(255, 255, 0)
```

Notice that the browser may return colors in RGB format rather than the original CSS color name.

## 6.4 Example 2: Reading inline and stylesheet styles

```html
<!DOCTYPE html>
<html>
<head>
    <style>
        #box {
            background-color: lightblue;
            width: 200px;
        }
    </style>
</head>
<body>

    <div id="box" style="height: 100px;">
        Hello
    </div>

    <script>
        const box = document.getElementById("box");

        console.log("Inline width:", box.style.width);
        console.log("Inline height:", box.style.height);

        const styles = getComputedStyle(box);

        console.log("Computed width:", styles.width);
        console.log("Computed height:", styles.height);
        console.log("Computed background:", styles.backgroundColor);
    </script>

</body>
</html>
```

**Expected output in a typical browser:**

```text
Inline width:
Inline height: 100px
Computed width: 200px
Computed height: 100px
Computed background: rgb(173, 216, 230)
```

Why?

- The width comes from the stylesheet.
- The height comes from the inline style.
- `box.style` reads inline declarations only.
- `getComputedStyle(box)` reads the resulting computed values.

## 6.5 Accessing CSS properties with hyphens

You can access computed styles using camelCase:

```javascript
styles.backgroundColor;
```

Or using bracket notation with the CSS property name:

```javascript
styles["background-color"];
```

Both can access the same computed CSS property.

## 6.6 Important points about `getComputedStyle()`

- It reads the computed styles of an element.
- It considers styles from stylesheets and inline CSS.
- It returns a read-only style declaration object.
- It does not directly modify CSS.
- The returned values may differ in format from the original CSS declarations.

**Remember:**

```javascript
element.style.color = "red";
```

Changes an inline style.

```javascript
getComputedStyle(element).color;
```

Reads a computed style.

You cannot use the returned computed style object to directly modify the element's CSS.

| Feature | `element.style` | `getComputedStyle()` |
|---|---|---|
| Purpose | Access inline styles | Read computed styles |

| Reads inline CSS | Yes | Yes, as part of computed result |
| Reads stylesheet CSS | No, not as a general computed value | Yes |
| Returns | Inline style declaration object | Read-only computed style declaration |
| Example | `element.style.color` | `getComputedStyle(element).color` |

### Example to remember

```

console.log(styles.backgroundColor);
```

**Expected output:**

```text

yellow
rgb(0, 0, 255)
rgb(255, 255, 0)
```

# 8. CSS Class Manipulation Using `classList`

Changing every CSS property individually using JavaScript can become difficult when an element needs many styles.

A better approach is often to define styles in CSS and use JavaScript to add or remove classes.

This is called **class manipulation**.

## 8.1 What is `classList`?

`classList` is a DOM property that provides a convenient way to work with an element's CSS classes.

It returns a `DOMTokenList`.

For example:

```html
<p id="message" class="active">Hello</p>
```

JavaScript:

```javascript
const message = document.getElementById("message");

console.log(message.classList);
```

The returned `DOMTokenList` represents the classes assigned to the element.

## 8.2 Important `classList` methods

| Method | Purpose |
|---|---|
| `add()` | Adds a class |
| `remove()` | Removes a class |
| `toggle()` | Adds or removes a class depending on whether it exists |
| `contains()` | Checks whether a class exists |
| `replace()` | Replaces one class with another |

Let's study each method with examples.

---

# 9. `classList.add()`

## Definition

`classList.add()` adds one or more CSS classes to an element.

### Syntax

```javascript
element.classList.add("className");
```

Multiple classes can also be added:

```javascript
element.classList.add("class1", "class2");
```

### Example

```html
<!DOCTYPE html>
<html>
<head>
    <style>
        .highlight {
            color: white;
            background-color: green;
            padding: 10px;
        }
    </style>
</head>
<body>

    <p id="message">Welcome to JavaScript</p>

    <script>
        const message = document.getElementById("message");

        message.classList.add("highlight");
    </script>

</body>
</html>
```

**Result:** The paragraph receives the `highlight` class and its styles are applied.

### Before JavaScript

```html
<p id="message">Welcome to JavaScript</p>
```

### After JavaScript

```html
<p id="message" class="highlight">Welcome to JavaScript</p>
```

### Important point

`classList.add()` does not remove existing classes.

For example:

```html
<p id="message" class="active">Hello</p>
```

JavaScript:

```javascript
message.classList.add("highlight");
```

Result:

```html
<p id="message" class="active highlight">Hello</p>
```

The original `active` class remains.

---

## Definition

`classList.remove()` removes one or more specified classes from an element.

### Syntax

```javascript
element.classList.remove("className");
```

Multiple classes can be removed:

```javascript
element.classList.remove("class1", "class2");
```

### Example

<html>

        .highlight {

        }
    </style>
</head>
<body>

    <p id="message" class="highlight">
        Hello JavaScript
    </p>

    <script>
        const message = document.getElementById("message");

        message.classList.remove("highlight");
    </script>

</body>
</html>
```

**Result:** The `highlight` class is removed.

```

### After

```html
<p id="message">Hello JavaScript</p>
```

Removing a class that does not exist does not throw an error.

# 11. `classList.toggle()`

## Definition

`classList.toggle()` adds a class if it is absent and removes it if it is already present.

### Syntax

```javascript
element.classList.toggle("className");
```

### How does it work?

Suppose an element does not have the `active` class.

```javascript
element.classList.toggle("active");
```

The class is added.

Calling the same statement again removes the class.

### Example

```html
<!DOCTYPE html>
<html>
<head>
    <style>
        .active {
            color: white;
            background-color: green;
        }
    </style>
</head>
<body>

    <p id="message">Hello JavaScript</p>

    <button id="toggleButton">Toggle Style</button>

    <script>
        const message = document.getElementById("message");
        const button = document.getElementById("toggleButton");

        button.addEventListener("click", function() {
            message.classList.toggle("active");
        });
    </script>

</body>
</html>
```

### Initial state

The paragraph has no `active` class.

### After first click

The `active` class is added.

The paragraph gets a green background and white text.

### After second click

The `active` class is removed.

The paragraph returns to its original appearance.

### Dry run

| Action | Class present before? | Result |
|---|---|---|
| Initial state | No | No change |
| First click | No | Adds `active` |
| Second click | Yes | Removes `active` |
| Third click | No | Adds `active` |

## 11.1 `toggle()` with a second argument

`toggle()` also accepts an optional Boolean force argument.

```javascript
element.classList.toggle("active", true);
```

This ensures that the class is present.

```javascript
element.classList.toggle("active", false);
```

This ensures that the class is absent.

This is useful when you want to explicitly set a class state instead of switching it blindly.

# 12. `classList.contains()`

## Definition

`classList.contains()` checks whether an element contains a particular CSS class.

It returns a Boolean value.

### Syntax

```javascript
element.classList.contains("className");
```

### Example

```html
<p id="message" class="active highlight">
    Hello
</p>

<script>
    const message = document.getElementById("message");

    console.log(message.classList.contains("active"));
    console.log(message.classList.contains("hidden"));
</script>
```

**Expected output:**

```text
true
false
```

### Practical use

Suppose you want to perform an operation only if a class exists.

```javascript
if (message.classList.contains("active")) {
    console.log("The element is active");
}
```

# 13. `classList.replace()`

## Definition

`classList.replace()` replaces an existing class with another class.

### Syntax

```javascript
element.classList.replace("oldClass", "newClass");
```

It returns `true` if the old class was found and replaced; otherwise, it returns `false`.

### Example

```html
<p id="message" class="old-style">Hello JavaScript</p>

<script>
    const message = document.getElementById("message");

    const result = message.classList.replace(
        "old-style",
        "new-style"
    );

    console.log(result);
    console.log(message.className);
</script>
```

**Expected output:**

```text
true
new-style
```

The class is changed from `old-style` to `new-style`.

# 14. `className` versus `classList`

These two properties are related, but they are not the same.

## `className`

`className` reads or replaces the complete class attribute as a string.

```javascript
element.className = "active";
```

This replaces all existing classes.

## `classList`

`classList` allows you to manage individual classes.

```javascript
element.classList.add("active");
```

This adds the class without removing other classes.

### Comparison

| Feature | `className` | `classList` |
|---|---|---|
| Type | String | `DOMTokenList` |
| Read all classes | Yes | Yes |
| Replace all classes | Yes | Possible through multiple operations |
| Add one class | Requires string reassignment or manipulation | `add()` |
| Remove one class | Requires string manipulation or reassignment | `remove()` |
| Toggle one class | No built-in method | `toggle()` |
| Check class existence | String checking | `contains()` |
| Recommended for individual class operations | No | Yes |

**Recommendation:** Use `classList` when you want to add, remove, replace, or toggle individual classes.

# 15. Inline Styles versus CSS Classes

This is an important practical concept.

There are two ways to apply CSS dynamically.

### Method 1: Using `element.style`

```javascript
element.style.color = "red";
element.style.backgroundColor = "yellow";
element.style.fontSize = "25px";
```

### Method 2: Using CSS classes

CSS:

```css
.highlight {
    color: red;
    background-color: yellow;
    font-size: 25px;
}
```

JavaScript:

```javascript
element.classList.add("highlight");
```

### Which approach should you use?

| Inline style | CSS class |
|---|---|
| Changes individual CSS properties | Applies a group of CSS declarations |
| Useful for dynamic values | Useful for predefined designs |
| CSS is written in JavaScript | CSS is maintained in stylesheets |
| Can become difficult to maintain for large designs | Usually easier to maintain and reuse |
| Example: `element.style.width = "200px"` | Example: `element.classList.add("card")` |

### Practical recommendation

Use `element.style` when:

- A CSS value is calculated dynamically.
- You need to change one or two properties.
- You are implementing a simple dynamic adjustment.

Use CSS classes when:

- Applying a predefined design.
- Implementing themes.
- Showing or hiding elements.
- Managing multiple styles together.
- Building maintainable interfaces.

# 17. Practical Project 2: Show and Hide an Element

This is a very common feature in real websites.

Examples:

- Show or hide a password.
- Open or close a menu.
- Expand or collapse content.
- Display additional information.

## 17.1 Understanding `display`

CSS provides the `display` property to control how an element participates in page layout.

For example:

```css
.hidden {
    display: none;
}
```

When an element has `display: none`, it is not displayed and does not occupy space in the layout.

We can use JavaScript to add or remove this class.

## 17.2 Complete runnable code

```html
<!DOCTYPE html>
<html>
<head>
    <title>Show and Hide</title>

    <style>
        .hidden {
            display: none;
        }
    </style>
</head>
<body>

    <h2>JavaScript DOM</h2>

    <p id="message">
        This paragraph can be hidden or shown.
    </p>

    <button id="toggleButton">Hide</button>

    <script>
        const message = document.getElementById("message");
        const button = document.getElementById("toggleButton");

        button.addEventListener("click", function() {

            const isHidden = message.classList.toggle("hidden");

            if (isHidden) {
                button.textContent = "Show";
            } else {
                button.textContent = "Hide";
            }

        });
    </script>

</body>
</html>
```

### Initial state

```text
JavaScript DOM

This paragraph can be hidden or shown.

[Hide]
```

### After clicking Hide

```text
JavaScript DOM

[Show]
```

### After clicking Show

```text
JavaScript DOM

This paragraph can be hidden or shown.

[Hide]
```

### Dry run

| Step | Operation | Result |
|---|---|---|
| 1 | User clicks button | Click event executes |
| 2 | `classList.toggle("hidden")` | Adds or removes class |
| 3 | Store returned Boolean | `isHidden` receives new class state |
| 4 | Check `isHidden` | Determines current visibility |
| 5 | Update button text | Displays Show or Hide |

**Important:** `classList.toggle()` returns `true` if the class is present after the operation and `false` otherwise.

- Initially, the webpage uses light mode.
- Clicking the button enables dark mode.
- Clicking it again returns to light mode.

```html
<!DOCTYPE html>

    <style>
        body {
            background-color: white;
            color: black;
            font-family: Arial, sans-serif;

        }

        .dark-mode {
            background-color: #222;
            color: white;
        }

        .dark-mode .card {
            background-color: #333;
        }

        .card {
            padding: 20px;
            margin: 20px;
            background-color: #eeeeee;
            border-radius: 10px;
        }
    </style>
</head>
<body>

    <h1>My Website</h1>

    <button id="themeButton">Enable Dark Mode</button>

    <div class="card">
        <h2>Welcome</h2>
        <p>This is a sample website.</p>
    </div>

    <script>
        const themeButton = document.getElementById("themeButton");

        themeButton.addEventListener("click", function() {

            const darkModeEnabled =
                document.body.classList.toggle("dark-mode");

            if (darkModeEnabled) {
                themeButton.textContent = "Enable Light Mode";
            } else {
                themeButton.textContent = "Enable Dark Mode";
            }

        });
    </script>

</body>
</html>
```

### Understanding the important statement

```javascript
document.body.classList.toggle("dark-mode");
```

Here:

- `document` represents the webpage document.
- `body` selects the body element.
- `classList` accesses the body's classes.
- `toggle()` adds or removes `dark-mode`.

The CSS rules for `.dark-mode` then control the appearance of the page.

### Dry run

| User action | Body class | Appearance |
|---|---|---|
| Initial page | No `dark-mode` | Light mode |
| First click | `dark-mode` added | Dark mode |
| Second click | `dark-mode` removed | Light mode |
| Third click | `dark-mode` added | Dark mode |

**Note:** This project changes the theme for the current page session. It does not remember the user's preference after reloading. Saving preferences is a separate topic involving browser storage.

# 19. Common Mistakes and Their Corrections

## Mistake 1: Using CSS hyphen notation with `element.style`

Incorrect:

```javascript
element.style.background-color = "red";
```

Correct:

```javascript
element.style.backgroundColor = "red";
```

Reason: JavaScript uses camelCase property names for CSS properties accessed through `style`.

## Mistake 2: Forgetting units

Incorrect:

```javascript
element.style.fontSize = "30";
```

Correct:

```javascript
element.style.fontSize = "30px";
```

Reason: Font size requires a CSS length value.

## Mistake 3: Thinking `element.style` reads all CSS

Suppose the stylesheet contains:

```css
h1 {
    color: red;
}
```

This may return an empty string:

```javascript
console.log(heading.style.color);
```

Use:

```javascript
console.log(getComputedStyle(heading).color);
```

to read the computed color.

## Mistake 4: Trying to modify computed styles

Incorrect:

```javascript
getComputedStyle(element).color = "red";
```

Correct:

```javascript
element.style.color = "red";
```

Reason: The computed style object is read-only.

## Mistake 5: Replacing all classes accidentally

Suppose:

```html
<p id="message" class="card active">Hello</p>
```

Incorrect if you only want to add a class:

```javascript
message.className = "highlight";
```

This removes the existing classes.

Correct:

```javascript
message.classList.add("highlight");
```

## Mistake 6: Confusing `toggle()` with `add()`

```javascript
element.classList.toggle("active");
```

This may add or remove the class.

If your goal is always to add it, use:

```javascript
element.classList.add("active");
```

If your goal is always to remove it, use:

```javascript
element.classList.remove("active");
```

## Mistake 7: Forgetting that class names are case-sensitive

```javascript
element.classList.add("active");
```

and:

```javascript
element.classList.contains("Active");
```

refer to different class names.

Use consistent class naming.

## Mistake 8: Using the wrong CSS value

Incorrect:

```javascript
element.style.display = "hidden";
```

Correct:

```javascript
element.style.display = "none";
```

`hidden` is not a valid value for the CSS `display` property.

You can also use:

```javascript
element.hidden = true;
```

This uses the HTML `hidden` property rather than the CSS `display` property.

# 21. Interview Questions and Answers

## Q1. How can you change CSS using JavaScript?

We can change CSS using the `style` property of an HTML element.

Example:

```javascript
element.style.color = "red";
```

## Q2. What is the `style` property in JavaScript?

The `style` property provides access to an element's inline CSS declarations and allows JavaScript to read or modify them.

## Q3. How do CSS property names differ in JavaScript?

CSS property names generally use hyphen notation, whereas JavaScript style properties use camelCase.

Example:

```css
background-color
```

becomes:

```javascript
backgroundColor
```

## Q4. What is `getComputedStyle()`?

`getComputedStyle()` is a browser method that returns a read-only object containing the computed CSS property values of an element.

## Q5. What is the difference between `style` and `getComputedStyle()`?

`element.style` accesses inline styles, while `getComputedStyle()` reads the final computed styles after the browser applies the CSS cascade.

## Q6. Can we modify CSS using `getComputedStyle()`?

No. The object returned by `getComputedStyle()` is read-only. We can modify styles using `element.style` or by changing CSS classes.

## Q7. What is `classList`?

`classList` is a DOM property that provides methods to manage an element's CSS classes.

## Q8. What is `classList.add()`?

It adds one or more CSS classes to an element without removing its existing classes.

## Q9. What is `classList.remove()`?

It removes one or more specified CSS classes from an element.

## Q10. What is `classList.toggle()`?

It adds a class if it is absent and removes it if it is already present.

## Q11. What is `classList.contains()`?

It checks whether an element contains a particular class and returns a Boolean value.

## Q12. What is `classList.replace()`?

It replaces an existing class with another class and returns whether the replacement occurred.

## Q13. What is the difference between `className` and `classList`?

`className` accesses the entire class attribute as a string, while `classList` provides methods for managing individual classes.

## Q14. Why is `classList` often preferred over `className`?

`classList` allows individual classes to be added, removed, toggled, or checked without accidentally replacing other existing classes.

## Q15. How can you hide an element using JavaScript?

Using inline CSS:

```javascript
element.style.display = "none";
```

Or using a CSS class:

```css
.hidden {
    display: none;
}
```

```javascript
element.classList.add("hidden");
```

## Q16. How can you show an element that has `display: none`?

Using inline CSS:

```javascript
element.style.display = "block";
```

Or by removing the class responsible for hiding it:

```javascript
element.classList.remove("hidden");
```

The appropriate display value depends on the element's intended layout. Removing a dedicated hiding class is often preferable because it lets the stylesheet control the original display behavior.

## Q17. What is the difference between `display: none` and `visibility: hidden`?

`display: none` removes the element from the layout, so it occupies no layout space.

`visibility: hidden` hides the element but preserves its layout space.

## Q18. Can we add multiple classes using `classList.add()`?

Yes.

```javascript
element.classList.add("active", "highlight", "large");
```

## Q19. What does `classList.toggle("active", true)` do?

It ensures that the `active` class is present.

## Q20. What does `classList.toggle("active", false)` do?

It ensures that the `active` class is absent.
