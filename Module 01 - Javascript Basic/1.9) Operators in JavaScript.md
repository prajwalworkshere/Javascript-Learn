
# Topic 09: Operators in JavaScript

**Module 1 · JavaScript Fundamentals · Beginner Level**

## 1\. What Is an Operator?

An operator is a symbol or keyword that performs an operation on one or more values, called operands.

For example:

```
let a = 10;
let b = 5;

let sum = a + b;

console.log(sum);
```

**Output:**

```
15
```

Here:

- `a` and `b` are operands.
- `+` is the operator.
- `a + b` is an expression.
- `sum` stores the result, `15`.

## 2\. Types of Operators

JavaScript provides several categories of operators.

| Operator Category | Purpose | Examples |
| --- | --- | --- |
| Arithmetic | Perform calculations | `+`, `-`, `*`, `/` |
| Assignment | Assign or update values | `=`, `+=`, `-=` |
| Comparison | Compare values | `>`, `<`, `===` |
| Logical | Combine or reverse conditions | `&&`, `\|\|`, `!` |
| Unary | Operate on a single operand | `typeof`, `!`, `++` |
| Ternary | Choose between two expressions | `condition ? a : b` |
| Nullish Coalescing | Provide a fallback for `null` or `undefined` | `??` |
| Optional Chaining | Safely access a potentially absent property | `?.` |
| Bitwise | Operate on binary representations | `&`, `\|`, `^` |

We'll begin with the operators you'll use most often.

## 3\. Arithmetic Operators

Arithmetic operators perform mathematical calculations.

### 3.1 Arithmetic Operator Table

| Operator | Name | Example | Result |
| --- | --- | --- | --- |
| `+` | Addition | `10 + 5` | `15` |
| `-` | Subtraction | `10 - 5` | `5` |
| `*` | Multiplication | `10 * 5` | `50` |
| `/` | Division | `10 / 5` | `2` |
| `%` | Remainder (modulo) | `10 % 3` | `1` |
| `**` | Exponentiation | `2 ** 3` | `8` |

### 3.2 Addition, Subtraction, Multiplication, and Division

```
let a = 20;
let b = 6;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);
```

**Output:**

```
26
14
120
3.3333333333333335
```

JavaScript's `number` type uses floating-point arithmetic, so some division and decimal calculations may not produce an exact decimal representation.

### 3.3 Remainder Operator `%`

The remainder operator returns the remainder after division.

```
console.log(10 % 3);
console.log(15 % 5);
console.log(17 % 4);
console.log(8 % 2);
```

**Output:**

```
1
0
1
0
```

**Dry run:**

```
10 % 3

10 divided by 3 = 3 remainder 1

Therefore: 10 % 3 = 1
```

**Practical use case: Checking even and odd numbers**

```
let number = 7;

if (number % 2 === 0) {
    console.log("Even number");
} else {
    console.log("Odd number");
}
```

**Output:**

```
Odd number
```

Why?

- `7 % 2` produces `1`.
- `1 === 0` is `false`.
- Therefore, the `else` block runs.

For even numbers, the remainder when divided by `2` is `0`.

### 3.4 Exponentiation Operator `**`

The exponentiation operator raises a number to a power.

```
console.log(2 ** 3);
console.log(5 ** 2);
console.log(10 ** 0);
```

**Output:**

```
8
25
1
```

Explanation:

- `2 ** 3` means $2 \times 2 \times 2 = 8$.
- `5 ** 2` means $5 \times 5 = 25$.
- `10 ** 0` equals `1`.

### 3.5 Unary Plus and Unary Minus

Unary operators work with one operand.

```
let a = 10;

console.log(+a);
console.log(-a);
console.log(-(-a));
```

**Output:**

```
10
-10
10
```

Unary plus attempts to convert its operand to a number.

```
console.log(+"25");
console.log(+"hello");
```

**Output:**

```
25
NaN
```

Unary minus negates a numeric value.

```
console.log(-5);
console.log(-(-5));
```

**Output:**

```
-5
5
```

## 4\. Assignment Operators

Assignment operators assign values to variables or update their existing values.

### 4.1 Basic Assignment `=`

```
let age = 21;

console.log(age);
```

**Output:**

```
21
```

Remember that `=` is an assignment operator, not an equality comparison operator.

### 4.2 Compound Assignment Operators

Compound assignment operators combine an operation with assignment.

| Operator | Equivalent Form |
| --- | --- |
| `x += 5` | `x = x + 5` |
| `x -= 5` | `x = x - 5` |
| `x *= 5` | `x = x * 5` |
| `x /= 5` | `x = x / 5` |
| `x %= 5` | `x = x % 5` |
| `x **= 2` | `x = x ** 2` |

Example:

```
let score = 10;

score += 5;
console.log(score);

score -= 3;
console.log(score);

score *= 2;
console.log(score);
```

**Output:**

```
15
12
24
```

**Dry run**

Initially:

```
score = 10;
```

After `score += 5`:

```
score = 10 + 5
score = 15
```

After `score -= 3`:

```
score = 15 - 3
score = 12
```

After `score *= 2`:

```
score = 12 * 2
score = 24
```

**Practical use case: Updating a shopping cart's total**

```
let total = 500;

total += 200;
total -= 100;

console.log(total);
```

**Output:**

```
600
```

### Common Mistake

```
let x = 10;

x += 5;

console.log(x);
```

The output is `15`, not `5`. The `+=` operator adds to the existing value and assigns the result back to `x`.

## 5\. Increment and Decrement Operators

These operators increase or decrease a numeric value by one.

- `++` increases a value by `1`.
- `--` decreases a value by `1`.

They each have two forms:

- Prefix: `++x` or `--x`
- Postfix: `x++` or `x--`

### 5.1 Basic Increment

```
let count = 5;

count++;

console.log(count);
```

**Output:**

```
6
```

This is similar to:

```
count = count + 1;
```

### 5.2 Prefix Increment `++x`

The prefix form increments the variable and then produces its new value.

```
let x = 5;

let result = ++x;

console.log(x);
console.log(result);
```

**Output:**

```
6
6
```

**Dry run:**

1. Initially, `x = 5`.
2. `++x` increments `x` to `6`.
3. The expression produces `6`.
4. `result` receives `6`.

### 5.3 Postfix Increment `x++`

The postfix form produces the original value of the variable and then increments the variable.

```
let x = 5;

let result = x++;

console.log(x);
console.log(result);
```

**Output:**

```
6
5
```

**Dry run:**

1. Initially, `x = 5`.
2. The expression `x++` produces the old value, `5`.
3. `result` receives `5`.
4. `x` is incremented to `6`.

**Visual comparison**

| Prefix: `++x` | Postfix: `x++` |
| --- | --- |
| Update first, then produce the new value. | Produce the old value, then update. |
| `x = 6`, `result = 6` | `x = 6`, `result = 5` |

### 5.4 Decrement Operators

```
let a = 5;
let b = 5;

console.log(--a);
console.log(b--);

console.log(a);
console.log(b);
```

**Output:**

```
4
5
4
4
```

Explanation:

- `--a` decreases `a` first, so it produces `4`.
- `b--` produces the old value `5`, then decreases `b` to `4`.

**Best practice:** Use increment and decrement in simple expressions. Avoid complicated expressions that modify the same variable multiple times, because they are harder to read and debug.

## 6\. Comparison Operators

Comparison operators compare two values and return a Boolean: `true` or `false`.

| Operator | Meaning | Example | Result |
| --- | --- | --- | --- |
| `>` | Greater than | `10 > 5` | `true` |
| `<` | Less than | `10 < 5` | `false` |
| `>=` | Greater than or equal to | `10 >= 10` | `true` |
| `<=` | Less than or equal to | `5 <= 10` | `true` |
| `===` | Strict equality | `5 === 5` | `true` |
| `!==` | Strict inequality | `5 !== "5"` | `true` |
| `==` | Loose equality | `5 == "5"` | `true` |
| `!=` | Loose inequality | `5 != "5"` | `false` |

### Example

```
let a = 10;
let b = 20;

console.log(a > b);
console.log(a < b);
console.log(a >= 10);
console.log(b <= 20);
console.log(a === b);
console.log(a !== b);
```

**Output:**

```
false
true
true
true
false
true
```

### Strict Versus Loose Comparison

```
console.log(10 == "10");
console.log(10 === "10");
console.log(10 != "10");
console.log(10 !== "10");
```

**Output:**

```
true
false
false
true
```

- `==` and `!=` can perform type coercion.
- `===` and `!==` compare without converting operands to a common type.

For most application code, prefer strict comparisons.

### Practical Example: Eligibility

```
let age = 19;

console.log(age >= 18);
```

**Output:**

```
true
```

The expression evaluates to `true` because `19` is greater than or equal to `18`.

## 7\. Logical Operators

Logical operators combine or reverse conditions.

The three main logical operators are:

| Operator | Name | Meaning |
| --- | --- | --- |
| `&&` | AND | Returns the first falsy operand, or the last operand if all operands are truthy. |
| `\|\|` | OR | Returns the first truthy operand, or the last operand if all operands are falsy. |
| `!` | NOT | Converts its operand to a Boolean and reverses the truth value. |

For Boolean operands, the familiar rules are:

| A | B | `A && B` | `A \|\| B` |
| --- | --- | --- | --- |
| `true` | `true` | `true` | `true` |
| `true` | `false` | `false` | `true` |
| `false` | `true` | `false` | `true` |
| `false` | `false` | `false` | `false` |

### 7.1 Logical AND `&&`

AND requires both conditions to be truthy.

```
let age = 22;
let hasID = true;

console.log(age >= 18 && hasID);
```

**Output:**

```
true
```

**Dry run:**

1. `age >= 18` is `true`.
2. `hasID` is `true`.
3. Both operands are truthy, so the result is `true`.

If either condition is falsy, the result of this Boolean example is `false`.

**Practical use case: Allowing access only when both conditions are met**

```
let usernameCorrect = true;
let passwordCorrect = false;

if (usernameCorrect && passwordCorrect) {
    console.log("Login successful");
} else {
    console.log("Login failed");
}
```

**Output:**

```
Login failed
```

### 7.2 Logical OR `||`

OR can succeed when either condition is truthy.

```
let isAdmin = false;
let isManager = true;

console.log(isAdmin || isManager);
```

**Output:**

```
true
```

**Practical use case: Allowing either of two roles to access a page**

```
let isAdmin = false;
let isManager = true;

if (isAdmin || isManager) {
    console.log("Access granted");
} else {
    console.log("Access denied");
}
```

**Output:**

```
Access granted
```

### 7.3 Logical NOT `!`

NOT reverses the truthiness of a value.

```
console.log(!true);
console.log(!false);
console.log(!0);
console.log(!"Hello");
```

**Output:**

```
false
true
true
false
```

For example:

```
let isLoggedIn = false;

if (!isLoggedIn) {
    console.log("Please log in");
}
```

**Output:**

```
Please log in
```

The `!` operator converts the value to a Boolean and reverses it.

### 7.4 Important: Logical Operators Return Values

In JavaScript, `&&` and `||` do not always return Boolean values. They return one of their operands according to short-circuit rules.

```
console.log("Hello" && 100);
console.log("" && 100);

console.log("Hello" || 100);
console.log("" || 100);
```

**Output:**

```
100

Hello
100
```

The second output is an empty string, so the console displays a blank line.

**Rules:**

- `A && B`: if `A` is falsy, return `A`; otherwise, return `B`.
- `A || B`: if `A` is truthy, return `A`; otherwise, return `B`.

This is called **short-circuit evaluation** because JavaScript can stop evaluating once the result is determined.

Example:

```
let username = "";

let displayName = username || "Guest";

console.log(displayName);
```

**Output:**

```
Guest
```

Since `username` is an empty string (falsy), `||` returns `"Guest"`.

## 8\. Ternary Operator `? :`

The ternary operator is a compact way to choose between two expressions based on a condition.

**Syntax:**

```
condition ? valueIfTrue : valueIfFalse;
```

Example:

```
let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);
```

**Output:**

```
Adult
```

**Dry run:**

1. Check `age >= 18`.
2. The condition is `true`.
3. Choose the expression after `?`.
4. `result` receives `"Adult"`.

Equivalent `if...else` code:

```
let age = 20;
let result;

if (age >= 18) {
    result = "Adult";
} else {
    result = "Minor";
}

console.log(result);
```

The output is also `Adult`.

### Practical Example: Pass or Fail

```
let marks = 65;

let status = marks >= 40 ? "Pass" : "Fail";

console.log(status);
```

**Output:**

```
Pass
```

Use a ternary operator for simple choices. For complicated decision-making, ordinary `if...else` statements are generally easier to read.

## 9\. The `typeof` Operator

The `typeof` operator returns a string describing the type of a value.

```
let name = "Prajwal";
let age = 21;
let active = true;

console.log(typeof name);
console.log(typeof age);
console.log(typeof active);
```

**Output:**

```
string
number
boolean
```

Other examples:

```
console.log(typeof undefined);
console.log(typeof 123n);
console.log(typeof Symbol("id"));
console.log(typeof {});
console.log(typeof []);
console.log(typeof null);
```

**Output:**

```
undefined
bigint
symbol
object
object
object
```

Remember:

- `typeof []` is `"object"`.
- `typeof null` is `"object"` because of a historical quirk.
- `Array.isArray(value)` is the preferred way to check whether a value is an array.

## 10\. The Nullish Coalescing Operator `??`

The nullish coalescing operator returns a fallback value only when the left operand is `null` or `undefined`.

**Syntax:**

```
value ?? fallbackValue;
```

Example:

```
let username = null;

console.log(username ?? "Guest");
```

**Output:**

```
Guest
```

If the value exists and is not nullish, it is returned—even if it is `0`, `false`, or an empty string.

```
console.log(0 ?? 100);
console.log(false ?? true);
console.log("" ?? "Default");
console.log(null ?? "Default");
console.log(undefined ?? "Default");
```

**Output:**

```
0
false

Default
Default
```

The third output is an empty string.

### Difference Between `||` and `??`

This is an important interview topic.

```
console.log(0 || 100);
console.log(0 ?? 100);

console.log(false || true);
console.log(false ?? true);
```

**Output:**

```
100
0
true
false
```

| Operator | Uses fallback when the left operand is... |
| --- | --- |
| `\|\|` | Any falsy value |
| `??` | Only `null` or `undefined` |

Use `??` when `0`, `false`, and `""` are valid values that you want to preserve.

## 11\. Optional Chaining `?.`

Optional chaining safely accesses a property when the value before `?.` might be `null` or `undefined`.

Without optional chaining:

```
let user = null;

// console.log(user.name); // TypeError
```

Trying to access `name` on `null` throws a `TypeError`.

With optional chaining:

```
let user = null;

console.log(user?.name);
```

**Output:**

```
undefined
```

The expression short-circuits to `undefined` instead of throwing an error.

### Practical Example

```
let student = {
    name: "Prajwal",
    address: {
        city: "Panvel"
    }
};

console.log(student.address?.city);
console.log(student.contact?.phone);
```

**Output:**

```
Panvel
undefined
```

`student.contact` does not exist, so `student.contact?.phone` safely returns `undefined`.

Optional chaining does not automatically handle every possible error. It protects against a nullish value at the point where `?.` is used.

## 12\. Bitwise Operators: A Basic Introduction

Bitwise operators work with the binary representations of numbers. They are more specialized than arithmetic and logical operators.

| Operator | Name |
| --- | --- |
| `&` | Bitwise AND |
| `\|` | Bitwise OR |
| `^` | Bitwise XOR |
| `~` | Bitwise NOT |
| `<<` | Left shift |
| `>>` | Sign-propagating right shift |
| `>>>` | Zero-fill right shift |

For ordinary `Number` operands, bitwise operations use 32-bit integer representations.

### Example: Bitwise AND

```
console.log(5 & 3);
```

**Output:**

```
1
```

Binary representation:

```
5 = 101
3 = 011
    ---
AND 001 = 1
```

A bit remains `1` only when both corresponding bits are `1`.

### Example: Bitwise OR

```
console.log(5 | 3);
```

**Output:**

```
7
```

```
5 = 101
3 = 011
    ---
 OR 111 = 7
```

Bitwise operations are used in some low-level algorithms, flags, and binary data processing. For now, understand their purpose and syntax; focus first on arithmetic, assignment, comparison, and logical operators.

## 13\. Operator Precedence

**Operator precedence** determines which operations are evaluated first when an expression contains multiple operators.

Example:

```
console.log(10 + 5 * 2);
```

**Output:**

```
20
```

Multiplication has higher precedence than addition, so JavaScript evaluates `5 * 2` first.

```
10 + 5 * 2
   ↓
10 + 10
   ↓
20
```

### Parentheses Change the Order

```
console.log((10 + 5) * 2);
```

**Output:**

```
30
```

The parentheses force `10 + 5` to be evaluated first.

```
(10 + 5) * 2
     ↓
    15 * 2
     ↓
     30
```

### Important Precedence Examples

| Operator Group | Example | Result |
| --- | --- | --- |
| Parentheses | `(2 + 3) * 4` | `20` |
| Exponentiation | `2 ** 3` | `8` |
| Multiplication | `2 + 3 * 4` | `14` |
| Division | `20 / 5 + 2` | `6` |
| Addition and subtraction | `10 + 5 - 2` | `13` |
| Comparison | `5 + 2 > 6` | `true` |
| Logical AND | `true && false` | `false` |
| Logical OR | `false \|\| true` | `true` |

This table illustrates common cases, not the complete precedence hierarchy.

### Associativity

When operators have the same precedence, associativity helps determine the evaluation grouping.

For example, subtraction groups from left to right:

```
console.log(20 - 5 - 3);
```

**Output:**

```
12
```

Evaluation:

```
(20 - 5) - 3
15 - 3
12
```

Exponentiation groups from right to left:

```
console.log(2 ** 3 ** 2);
```

**Output:**

```
512
```

This is interpreted as:

```
2 ** (3 ** 2);
```

Because `3 ** 2` is `9`, the expression becomes `2 ** 9`, which is `512`.

**Best practice:** Use parentheses when an expression could be confusing, even if you already know the precedence rules.

## 14\. Complete Practical Program: Student Result Calculator

This example combines arithmetic, comparison, assignment, and ternary operators.

```
let studentName = "Prajwal";

let marks1 = 75;
let marks2 = 80;
let marks3 = 65;

let total = marks1 + marks2 + marks3;
let average = total / 3;

let passed = marks1 >= 40 &&
             marks2 >= 40 &&
             marks3 >= 40;

let result = passed ? "Pass" : "Fail";

console.log("Student:", studentName);
console.log("Total:", total);
console.log("Average:", average);
console.log("Result:", result);
```

**Output:**

```
Student: Prajwal
Total: 220
Average: 73.33333333333333
Result: Pass
```

### Dry Run

**Step 1: Calculate total**

```
75 + 80 + 65 = 220
```

**Step 2: Calculate average**

```
220 / 3 = 73.33333333333333
```

**Step 3: Check all marks**

```
75 >= 40 → true
80 >= 40 → true
65 >= 40 → true
```

The `&&` operator combines all three conditions. Since every condition is true, `passed` becomes `true`.

**Step 4: Determine the result**

```
passed ? "Pass" : "Fail";
```

The condition is true, so `result` becomes `"Pass"`.

This program demonstrates how operators work together in a practical application.

## 15\. Common Mistakes

### Mistake 1: Confusing `=` with `===`

```
let age = 18;            // Assignment
console.log(age === 18); // Comparison
```

**Output:**

```
true
```

### Mistake 2: Confusing Prefix and Postfix Increment

```
let x = 5;

console.log(x++);
console.log(x);
```

**Output:**

```
5
6
```

The first line prints the old value.

### Mistake 3: Using `&&` When You Need `||`

```
let isAdmin = false;
let isManager = true;

console.log(isAdmin && isManager);
console.log(isAdmin || isManager);
```

**Output:**

```
false
true
```

Use AND when all required conditions must hold. Use OR when at least one condition is sufficient.

### Mistake 4: Assuming Logical Operators Always Return Booleans

```
console.log("Hello" || "Guest");
```

**Output:**

```
Hello
```

`||` returns an operand, not necessarily a Boolean.

### Mistake 5: Assuming `||` and `??` Behave Identically

```
console.log(0 || 10);
console.log(0 ?? 10);
```

**Output:**

```
10
0
```

`||` uses a fallback for falsy values; `??` uses a fallback only for `null` or `undefined`.

### Mistake 6: Forgetting Precedence

```
console.log(2 + 3 * 4);
```

**Output:**

```
14
```

Multiplication happens before addition. Use `(2 + 3) * 4` if you intend the result to be `20`.

### Mistake 7: Using Loose Equality Without Intending Coercion

```
console.log(0 == false);
console.log(0 === false);
```

**Output:**

```
true
false
```

Prefer strict equality unless you specifically want loose equality behavior.

## 18\. Interview and Viva Questions

### Q1. What is an operator in JavaScript?

An operator is a symbol or keyword that performs an operation on one or more operands and produces a result.

### Q2. What are the main types of operators?

Arithmetic, assignment, comparison, logical, unary, ternary, nullish coalescing, optional chaining, and bitwise operators are important categories.

### Q3. What is the difference between `=` and `===`?

`=` assigns a value to a variable, while `===` checks strict equality without converting the operands to a common type.

### Q4. What is the difference between `==` and `===`?

`==` allows certain type conversions during comparison. `===` compares without that conversion.

### Q5. What is the difference between `++x` and `x++`?

Prefix increment updates the variable before producing the expression's value. Postfix increment produces the old value and then updates the variable.

### Q6. What is the remainder operator?

The `%` operator returns the remainder of division. It is commonly used to check whether a number is even or odd.

### Q7. What is the difference between `&&` and `||`?

`&&` stops at the first falsy operand and returns it; otherwise, it returns the final operand. `||` stops at the first truthy operand and returns it, or returns the final operand if none is truthy.

For Boolean operands, AND requires both conditions to be true, whereas OR requires at least one condition to be true.

### Q8. What is the ternary operator?

The ternary operator is a conditional expression written as `condition ? expression1 : expression2`. It evaluates the condition and selects one of the two expressions.

### Q9. What is operator precedence?

Operator precedence determines which operator is evaluated first when an expression contains multiple operators.

### Q10. What is short-circuit evaluation?

Short-circuit evaluation means JavaScript stops evaluating a logical expression as soon as the result is determined by the operand already evaluated.

### Q11. What is the difference between `||` and `??`?

`||` returns a fallback for any falsy left operand. `??` returns a fallback only when the left operand is `null` or `undefined`.

### Q12. What is optional chaining?

Optional chaining, written `?.`, safely accesses a property or method when the value immediately before it is `null` or `undefined`, returning `undefined` instead of throwing a property-access error.

### Q13. What does `typeof` do?

It returns a string identifying the type of a value, with special cases such as `typeof null === "object"` and `typeof function() {} === "function"`.

### Q14. Can logical operators return non-Boolean values?

Yes. JavaScript's `&&` and `||` return one of their operands according to short-circuit rules. The `!` operator, by contrast, returns a Boolean.
