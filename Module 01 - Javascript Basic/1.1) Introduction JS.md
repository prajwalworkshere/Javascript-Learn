# Topic 01: Introduction to JavaScript

## 1. What is JavaScript?

### Definition

JavaScript is a high-level, dynamically typed, multi-paradigm programming language primarily used to add interactivity and functionality to websites. It can also be used for backend development, mobile applications, desktop applications, automation, and other software through appropriate runtimes and frameworks.

In simple words, **JavaScript makes applications do things**.

For example:
- Clicking a button changes text on a webpage.
- Submitting a form checks whether the entered information is valid.
- A shopping cart calculates the total price of products.
- A weather application fetches live weather information from an API.
- A backend server processes requests and communicates with a database.

JavaScript is not limited to browsers. It can run outside the browser using environments such as Node.js.

---

## 2. Why was JavaScript created?

Initially, websites were primarily used to display static information. HTML provided the structure, and CSS controlled the appearance, but developers needed a way to make webpages respond to user actions.

JavaScript was created in 1995 by Brendan Eich while working at Netscape. It was initially developed to add scripting and interactivity to webpages.

Over time, JavaScript evolved into a widely used programming language supporting complex applications.

### Evolution of JavaScript

| Year | Development |
|---|---|
| 1995 | JavaScript was created by Brendan Eich. |
| 1997 | ECMAScript became a standardized specification for the language. |
| 2009 | Node.js helped JavaScript run outside browsers. |
| 2015 | ECMAScript 2015 (ES6) introduced major improvements, including `let`, `const`, classes, and arrow functions. |
| Today | JavaScript is used across frontend, backend, and many other application environments. |

### Important terminology

**JavaScript:** The programming language.

**ECMAScript:** The specification that defines the core language features and behavior of JavaScript.

**ES6:** A commonly used name for ECMAScript 2015, a major language update.

**Node.js:** A JavaScript runtime that lets you execute JavaScript outside a web browser.

## 3. How does JavaScript work?

Consider a webpage with a button.

When the user clicks the button, JavaScript can detect that event and execute instructions to change the webpage.

The basic process is:

1. The developer writes JavaScript code.
2. The browser loads the script.
3. A JavaScript engine parses and executes the code.
4. The code can interact with browser features, such as the DOM.
5. The browser displays the resulting changes.

### Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First JavaScript Program</title>
</head>
<body>

    <h1>Welcome to JavaScript</h1>

    <button onclick="alert('Hello, JavaScript!')">
        Click Me
    </button>

</body>
</html>
```

**Output and behavior:**

- A webpage displays the heading `Welcome to JavaScript`.
- A button labeled `Click Me` appears.
- Clicking the button displays a browser alert containing `Hello, JavaScript!`.

The `onclick` attribute runs JavaScript when the user clicks the button. This is useful for demonstrating the concept, although modern applications generally use JavaScript event listeners instead.

## 4. Is JavaScript compiled or interpreted?

JavaScript is often described as an interpreted language because developers can run scripts without manually compiling them into executable machine code.

However, modern JavaScript engines use a combination of techniques, including parsing, bytecode execution, and Just-In-Time (JIT) compilation.

For example, the V8 engine used by Chrome and Node.js can compile frequently executed code into optimized machine code.

### Simplified execution process

```text
JavaScript Source Code
          |
          v
       Parsing
          |
          v
   Internal Representation
          |
          v
 Execution and Optimization
          |
          v
       Program Result
```

This is a simplified model. The exact implementation differs between JavaScript engines.

### Interview answer

JavaScript is commonly called an interpreted language, but modern engines use both interpretation and compilation techniques. Therefore, it is more accurate to explain that JavaScript execution depends on the engine, which may compile code into optimized machine code at runtime.

## 5. Important characteristics of JavaScript

### 5.1 High-level language

A high-level language provides abstractions that make programming easier for humans.

For example:

```javascript
let total = 10 + 20;

console.log(total);
```

Output:

```text
30
```

You can work with values and operations without manually managing CPU instructions or machine memory.

**Practical use:** Building applications with readable, maintainable code.

### 5.2 Dynamically typed language

In JavaScript, you do not need to specify a variable's data type when declaring it. The type is associated with the value.

```javascript
let value = 100;

console.log(typeof value);

value = "Hello";

console.log(typeof value);
```

Output:

```text
number
string
```

The same variable can hold a number and later a string.

This flexibility is useful, but it also means you must pay attention to types when performing operations.

### 5.3 Multi-paradigm language

JavaScript supports several programming styles.

**Procedural programming:**

```javascript
let price = 100;
let quantity = 3;

let total = price * quantity;

console.log(total);
```

**Functional programming:**

```javascript
const numbers = [1, 2, 3];

const doubled = numbers.map(number => number * 2);

console.log(doubled);
```

Output:

```text
[2, 4, 6]
```

**Object-oriented programming:**

```javascript
class Student {
    constructor(name) {
        this.name = name;
    }

    introduce() {
        console.log(`I am ${this.name}`);
    }
}

const student = new Student("Aarav");

student.introduce();
```

Output:

```text
I am Aarav
```

JavaScript supports all three styles, allowing developers to choose the approach that fits the problem.

### 5.4 Event-driven programming

JavaScript can respond to events such as clicks, keyboard input, form submissions, and network responses.

```javascript
const button = document.querySelector("#myButton");

button.addEventListener("click", function () {
    console.log("Button clicked!");
});
```

This example assumes that the HTML page contains an element with `id="myButton"`.

When the user clicks the button, the callback function executes.

**Practical use:** Menus, dropdowns, forms, interactive dashboards, and games.

### 5.5 Asynchronous programming

JavaScript supports operations that allow an application to handle tasks such as network requests without blocking the main thread while waiting for their results.

```javascript
console.log("Start");

setTimeout(() => {
    console.log("Task completed");
}, 1000);

console.log("End");
```

Typical output:

```text
Start
End
Task completed
```

The timer schedules a callback to run after approximately one second. The main script continues instead of waiting for that timer to finish.

**Practical use:** Fetching API data, timers, and handling other asynchronous operations.

### 5.6 Cross-platform capabilities

JavaScript can run in different environments.

| Environment | Common use |
|---|---|
| Web browser | Interactive websites and web applications |
| Node.js | Servers, command-line tools, automation |
| Electron | Desktop applications |
| React Native | Mobile applications |
| Serverless runtimes | Event-driven backend functions |

The availability of specific APIs depends on the runtime. For example, `document.querySelector()` is a browser DOM API and is not available by default in a standard Node.js process.

## 6. What can you build with JavaScript?

### Frontend development

JavaScript can dynamically update webpage content, validate forms, manage application state, and respond to user actions.

Examples: Portfolio websites, dashboards, shopping websites, and interactive forms.

### Backend development

With Node.js, JavaScript can handle HTTP requests, apply business logic, and communicate with databases.

Examples: Authentication services, REST APIs, and e-commerce backends.

### API integration

JavaScript can request information from external services.

```javascript
async function getData() {
    const response = await fetch(
        "https://jsonplaceholder.typicode.com/users/1"
    );

    const user = await response.json();

    console.log(user.name);
}

getData();
```

Example output:

```text
Leanne Graham
```

This example requires an environment with `fetch` support and internet access. The output depends on the response from the API.

### Automation

JavaScript can automate repetitive tasks using Node.js scripts and appropriate packages.

Examples: Processing files, transforming JSON data, and running development tools.

## 7. JavaScript versus Java

JavaScript and Java are different programming languages despite their similar names.

| Feature | JavaScript | Java |
|---|---|---|
| Typing | Dynamically typed | Statically typed |
| Common execution environment | Browsers and JavaScript runtimes | JVM |
| Typical source files | `.js` | `.java` |
| Common uses | Web frontend, backend, automation | Backend systems, Android development, enterprise applications |
| Object model | Prototype-based, with class syntax | Class-based |
| Compilation and execution | Engine-dependent, often using JIT compilation | Commonly compiled to JVM bytecode and executed by the JVM |

Neither language is universally better. The right choice depends on the application and its requirements.

## 8. First JavaScript program

### Code

```javascript
console.log("Hello, World!");

console.log(10 + 20);

console.log("I am learning JavaScript.");
```

### Output

```text
Hello, World!
30
I am learning JavaScript.
```

### Explanation

**Line 1**

```javascript
console.log("Hello, World!");
```

- `console` provides access to the console interface.
- `log()` prints a value to the console.
- `"Hello, World!"` is a string.
- The semicolon terminates the statement.

**Line 2**

```javascript
console.log(10 + 20);
```

JavaScript evaluates `10 + 20`, producing `30`, and then prints the result.

**Line 3**

```javascript
console.log("I am learning JavaScript.");
```

JavaScript prints the supplied string.

### Dry run

| Step | Statement | Result |
|---|---|---|
| 1 | `console.log("Hello, World!");` | Prints `Hello, World!` |
| 2 | `console.log(10 + 20);` | Calculates and prints `30` |
| 3 | `console.log("I am learning JavaScript.");` | Prints the sentence |

The program runs sequentially, from top to bottom, because there are no branches or asynchronous operations changing the order of these statements.

## 9. Common beginner mistakes

### Mistake 1: Confusing JavaScript with Java

They are different languages. Learning Java syntax does not automatically teach you JavaScript syntax.

### Mistake 2: Thinking JavaScript runs only in browsers

JavaScript also runs in Node.js and other compatible runtimes.

### Mistake 3: Assuming every JavaScript environment supports browser APIs

This code works in a browser with a suitable HTML document:

```javascript
document.querySelector("h1");
```

But it normally fails in Node.js with a `ReferenceError`, because `document` is not provided by the standard Node.js environment.

### Mistake 4: Expecting `console.log()` to display text on a webpage

`console.log()` writes to the developer console, not directly into the webpage.

To update webpage text, you might use:

```javascript
document.querySelector("h1").textContent = "Updated heading";
```

This assumes the page contains an `h1` element.

### Mistake 5: Assuming JavaScript is always executed one line at a time without optimization

JavaScript engines may compile and optimize code internally. The observable behavior follows the language's rules, but the engine's implementation is more sophisticated than simple line-by-line interpretation.

## 11. Interview and viva questions

### Q1. What is JavaScript?

JavaScript is a high-level, dynamically typed, multi-paradigm programming language used to implement application logic and interactivity in web applications. It can also run outside browsers using environments such as Node.js.

### Q2. Who created JavaScript?

Brendan Eich created JavaScript in 1995 while working at Netscape.

### Q3. What is ECMAScript?

ECMAScript is the standardized specification defining the core syntax, types, objects, and behavior of JavaScript.

### Q4. Is JavaScript interpreted or compiled?

JavaScript engines commonly combine interpretation and compilation techniques. Many modern engines use JIT compilation to optimize frequently executed code.

### Q5. Can JavaScript run without a browser?

Yes. It can run in environments such as Node.js, which provide a runtime outside the browser.

### Q6. Is JavaScript the same as Java?

No. They are separate programming languages with different type systems, execution environments, and language designs.

### Q7. What is a JavaScript engine?

A JavaScript engine is software that processes and executes JavaScript code. Examples include V8 and SpiderMonkey.

### Q8. What is the difference between JavaScript and ECMAScript?

JavaScript is the language as used by developers and platforms; ECMAScript is the standard that specifies its core language behavior. JavaScript environments may provide additional APIs beyond that standard.

### Q9. What does dynamically typed mean?

It means a variable can hold values of different types during execution without requiring an explicit type declaration.

### Q10. What are common uses of JavaScript?

Frontend development, backend development, API integration, automation, desktop applications, and mobile applications.
