# Topic 02: HTML vs CSS vs JavaScript

**Module:** JavaScript Fundamentals  
**Level:** Beginner  
**Learning goals:** Understand the purpose of HTML, CSS, and JavaScript, how they work together, how browsers process a webpage, and how to use them in a practical project.

---

## 1. Introduction

Websites commonly use three core technologies:

1. **HTML** — defines the structure and content.
2. **CSS** — controls the appearance and layout.
3. **JavaScript** — implements behavior and interactivity.

Imagine you're building a house.

- HTML is the structure: walls, doors, windows, and rooms.
- CSS is the design: paint, decoration, furniture arrangement, and appearance.
- JavaScript is the behavior: automatic doors, security systems, and controls.

This analogy is useful for remembering their roles, but each technology can do more than the analogy suggests.

### Example: A simple login page

Consider a login page containing:

- An email input field.
- A password input field.
- A Login button.
- A message shown when the user submits the form.

Each technology has a different responsibility.

| Requirement | Technology | Reason |
|---|---|---|
| Display the email field | HTML | Creates the input element |
| Display the password field | HTML | Creates the password input |
| Add a Login button | HTML | Creates the button |
| Set the background color | CSS | Controls visual styling |
| Align fields vertically | CSS | Controls layout |
| Change the button color on hover | CSS | Applies a visual interaction state |
| Check whether the email is empty | JavaScript | Implements validation logic |
| Display an error message | JavaScript | Updates content in response to an action |
| Send login details to a server | JavaScript | Can make a network request |

**Important:** JavaScript-based validation improves usability, but authentication and security checks must also be performed on the server.

## 2. What is HTML?

### Definition

HTML stands for **HyperText Markup Language**. It is the standard markup language used to describe the structure and content of webpages.

HTML is a markup language, not a programming language in the usual sense. It uses elements and attributes to describe content and its meaning.

### Why do we need HTML?

Without HTML, a browser would not have the familiar document structure of headings, paragraphs, links, images, forms, and buttons.

HTML tells the browser what content exists and how that content is organized.

### Basic HTML syntax

```html
<h1>Welcome to My Website</h1>

<p>This is my first webpage.</p>

<button>Click Me</button>
```

Explanation:

- `<h1>` defines a top-level heading.
- `<p>` defines a paragraph.
- `<button>` defines a button.
- The content between an opening and closing tag is the element's content.

### HTML elements and attributes

An HTML element can contain a tag, attributes, and content.

```html
<a href="https://example.com">Visit Example</a>
```

Here:

- `<a>` is the anchor tag.
- `href` is an attribute specifying the link destination.
- `https://example.com` is the attribute value.
- `Visit Example` is the visible link text.

### Practical use cases of HTML

HTML is used to create:

- Page headings and paragraphs.
- Navigation links.
- Images and videos.
- Forms and input fields.
- Tables and lists.
- Semantic page sections such as `header`, `main`, and `footer`.

## 3. What is CSS?

### Definition

CSS stands for **Cascading Style Sheets**. It is a stylesheet language used to control the presentation, appearance, and layout of HTML documents.

### Why do we need CSS?

HTML can create the content and structure, but CSS lets developers control how that content looks.

For example, CSS can specify:

- Text color and font size.
- Background colors.
- Margins and padding.
- Borders and shadows.
- Flexbox and grid layouts.
- Responsive layouts for different screen sizes.
- Hover and focus states.
- Animations and transitions.

### Basic CSS syntax

```css
h1 {
    color: blue;
    font-size: 32px;
}

p {
    color: gray;
    font-size: 18px;
}
```

Explanation:

- `h1` and `p` are selectors.
- `color` and `font-size` are properties.
- `blue`, `32px`, `gray`, and `18px` are property values.
- A declaration combines a property and its value.

### Syntax structure

```css
selector {
    property: value;
}
```

For example:

```css
button {
    background-color: green;
    color: white;
    padding: 10px 20px;
}
```

This styles buttons with a green background, white text, and padding.

### Practical use cases of CSS

CSS is used to:

- Create professional website layouts.
- Make navigation bars and cards.
- Build responsive interfaces.
- Apply consistent design across multiple pages.
- Improve readability and visual hierarchy.
- Add transitions and animations.

## 4. What is JavaScript?

### Definition

JavaScript is a high-level, dynamically typed programming language used to implement logic and behavior in applications. In browsers, it can interact with the DOM to respond to user actions and update webpage content.

JavaScript can also run outside browsers using environments such as Node.js.

### Why do we need JavaScript?

Suppose a webpage has a button.

HTML can create the button, and CSS can style it. JavaScript can make something happen when the user clicks it.

For example:

- Show or hide a menu.
- Validate a form.
- Calculate a shopping cart total.
- Display a message.
- Fetch information from an API.
- Update a dashboard without reloading the entire page.

### Basic JavaScript syntax

```javascript
console.log("Hello, JavaScript!");
```

Output:

```text
Hello, JavaScript!
```

The `console.log()` method writes a value to the developer console.

### Example: Responding to a button click

```javascript
const button = document.querySelector("#myButton");

button.addEventListener("click", function () {
    console.log("Button clicked!");
});
```

This assumes the webpage contains an element with `id="myButton"`.

When the button is clicked, the registered callback runs and prints a message.

### Practical use cases of JavaScript

JavaScript is used for:

- Interactive webpages.
- Form validation.
- DOM manipulation.
- API communication.
- Client-side application logic.
- Backend servers through Node.js.
- Browser-based games and tools.

## 5. HTML vs CSS vs JavaScript

This is an important interview topic.

| Feature | HTML | CSS | JavaScript |
|---|---|---|---|
| Full form | HyperText Markup Language | Cascading Style Sheets | JavaScript |
| Type | Markup language | Stylesheet language | Programming language |
| Primary purpose | Structure and content | Presentation and layout | Logic and behavior |
| Controls | Elements and document structure | Colors, spacing, positioning | Actions, calculations, conditions |
| Typical syntax | Tags and attributes | Selectors and declarations | Expressions, statements, functions |
| Example | `<button>Click</button>` | `button { color: red; }` | `button.addEventListener(...)` |
| File extension | `.html` | `.css` | `.js` |
| Example task | Create a button | Style the button | Respond to its click |

### Interview-ready answer

HTML defines the structure and content of a webpage, CSS controls its visual appearance and layout, and JavaScript implements its behavior and interactivity. Together, they form the foundation of most browser-based web applications.

## 6. How do HTML, CSS, and JavaScript work together?

Let's build a webpage with a heading and a button.

The button will:

1. Exist because of HTML.
2. Have its appearance controlled by CSS.
3. Change the heading when clicked because of JavaScript.

### Project structure

Create a folder named `topic02-demo` with these three files:

```text
topic02-demo/
├── index.html
├── style.css
└── script.js
```

### File 1: `index.html`

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>HTML CSS JavaScript Demo</title>

    <link rel="stylesheet" href="style.css">
    <script src="script.js" defer></script>
</head>
<body>

    <main class="container">
        <h1 id="heading">Welcome to My Website</h1>

        <p>Learn how HTML, CSS, and JavaScript work together.</p>

        <button id="changeButton">Change Heading</button>
    </main>

</body>
</html>
```

### File 2: `style.css`

```css
body {
    font-family: Arial, sans-serif;
    background-color: #f2f5f9;
    margin: 0;
    padding: 40px;
}

.container {
    max-width: 600px;
    margin: 50px auto;
    padding: 30px;
    background-color: white;
    border-radius: 12px;
    text-align: center;
}

h1 {
    color: #1d3557;
}

p {
    color: #555;
}

button {
    padding: 12px 20px;
    background-color: #2563eb;
    color: white;
    border: none;
    border-radius: 6px;
    cursor: pointer;
}

button:hover {
    background-color: #1d4ed8;
}
```

### File 3: `script.js`

```javascript
const heading = document.querySelector("#heading");
const button = document.querySelector("#changeButton");

button.addEventListener("click", function () {
    heading.textContent = "JavaScript Changed the Heading!";
});
```

### Expected result

When you open `index.html` in a browser:

- You see a centered white card.
- The heading and paragraph appear inside the card.
- A blue button appears below the paragraph.
- Hovering over the button changes its background color.
- Clicking the button changes the heading text.

### Understanding the complete flow

**Step 1: HTML creates the elements.**

The browser parses `index.html` and builds a document structure. The heading becomes an element that JavaScript can select.

**Step 2: CSS styles the elements.**

The browser loads `style.css` and applies matching rules to the document elements.

**Step 3: JavaScript selects the elements.**

```javascript
const heading = document.querySelector("#heading");
const button = document.querySelector("#changeButton");
```

`querySelector()` searches the document using CSS selector syntax. The `#` symbol selects an element by its ID.

**Step 4: JavaScript registers an event listener.**

```javascript
button.addEventListener("click", function () {
    heading.textContent = "JavaScript Changed the Heading!";
});
```

The browser registers the callback for the button's `click` event.

**Step 5: The user clicks the button.**

The callback executes, and `textContent` changes the heading's text.

**Step 6: The browser updates the display.**

The browser reflects the DOM change in the rendered page.

### Why is `defer` used?

In the HTML file, notice:

```html
<script src="script.js" defer></script>
```

The `defer` attribute tells the browser to fetch the external script while parsing the HTML and execute it after HTML parsing has finished, before the document's `DOMContentLoaded` event.

This helps ensure that the elements exist before the script attempts to select them.

## 7. Understanding the DOM

DOM stands for **Document Object Model**.

The DOM is a programming interface through which scripts can access and manipulate a document's elements, attributes, and content.

When a browser parses HTML, it constructs a tree-like representation of the document.

Consider:

```html
<body>
    <h1>Hello</h1>
    <p>Welcome to JavaScript</p>
</body>
```

A simplified DOM tree looks like this:

```text
Document
└── html
    ├── head
    └── body
        ├── h1
        │   └── "Hello"
        └── p
            └── "Welcome to JavaScript"
```

JavaScript can select the heading and change its text:

```javascript
const heading = document.querySelector("h1");

heading.textContent = "Hello, World!";
```

The browser updates the displayed heading to `Hello, World!`.

**Important distinction:** The DOM is not JavaScript itself. It is an API provided by browser environments. JavaScript is the language that can use that API.

## 8. How does a browser render a webpage?

A simplified browser rendering process looks like this:

```text
HTML
 |
 v
HTML Parsing
 |
 v
DOM Tree

CSS
 |
 v
CSS Parsing
 |
 v
CSSOM

DOM + CSSOM
 |
 v
Render Tree
 |
 v
Layout
 |
 v
Paint and Compositing
 |
 v
Displayed Webpage
```

JavaScript can interact with the DOM and CSS-related APIs, causing changes that may require the browser to update styles, layout, painting, or compositing.

This is a conceptual overview. Modern browsers may optimize and combine some stages.

### Important terms

**DOM:** The document's object representation.

**CSSOM:** The browser's object representation of CSS rules.

**Render tree:** A simplified model of the content and styles used to determine what is rendered.

**Layout:** Determining the size and position of rendered elements.

**Painting:** Drawing visual details such as text, backgrounds, and borders.

## 9. Different ways to add CSS and JavaScript

### 9.1 Inline CSS

CSS is written directly in an HTML element's `style` attribute.

```html
<p style="color: red;">Hello</p>
```

Useful for quick demonstrations, but generally not preferred for maintaining larger projects.

### 9.2 Internal CSS

CSS is placed inside a `<style>` element.

```html
<head>
    <style>
        p {
            color: red;
        }
    </style>
</head>
```

Useful for small, self-contained demonstrations.

### 9.3 External CSS

CSS is stored in a separate file.

```html
<link rel="stylesheet" href="style.css">
```

Useful for reusable styles and larger projects.

### 9.4 Inline JavaScript

JavaScript can be placed in an HTML event attribute.

```html
<button onclick="alert('Hello!')">Click</button>
```

This is useful for quick demonstrations, but separating behavior from HTML is generally easier to maintain.

### 9.5 Internal JavaScript

JavaScript can be written inside a `<script>` element.

```html
<script>
    console.log("Hello from JavaScript");
</script>
```

### 9.6 External JavaScript

JavaScript is placed in a separate file.

```html
<script src="script.js" defer></script>
```

This is a common approach for organizing projects.

## 10. Common mistakes and misconceptions

### Mistake 1: Treating HTML as a programming language

HTML describes document structure. It does not provide general-purpose programming constructs such as JavaScript functions and loops.

### Mistake 2: Expecting CSS to perform arbitrary calculations or application logic

CSS can calculate certain layout and style values, but general application logic belongs in JavaScript or another programming environment.

### Mistake 3: Assuming JavaScript automatically knows which HTML element to modify

You generally need to select the element before changing it.

```javascript
const heading = document.querySelector("#heading");

heading.textContent = "Updated!";
```

The selector must match an existing element when the code runs. Otherwise, `querySelector()` returns `null`, and accessing `textContent` on `null` throws a `TypeError`.

### Mistake 4: Incorrect file paths

If the HTML contains:

```html
<script src="script.js" defer></script>
```

the browser expects to find `script.js` at the corresponding relative path.

A wrong path can prevent the script from loading.

### Mistake 5: Forgetting that browser APIs are environment-specific

The `document` object is available in browsers, but it is not normally available in a standard Node.js process.

### Mistake 6: Putting all project code into one file unnecessarily

Small examples can use a single HTML file, but separating HTML, CSS, and JavaScript often improves readability and maintenance.

## 12. Interview and viva questions

### Q1. What is HTML?

HTML is a markup language that defines the structure and content of webpages.

### Q2. What is CSS?

CSS is a stylesheet language that controls the appearance, presentation, and layout of HTML documents.

### Q3. What is JavaScript?

JavaScript is a programming language used to implement application logic and interactive behavior. In browsers, it can manipulate the DOM and respond to events.

### Q4. What is the difference between HTML, CSS, and JavaScript?

HTML defines structure, CSS defines presentation, and JavaScript defines behavior and application logic.

### Q5. What is the DOM?

The Document Object Model is a programming interface representing a document as objects that scripts can inspect and manipulate.

### Q6. What is the difference between HTML and the DOM?

HTML is a markup language used to describe document structure. The DOM is the object representation of the document created and maintained by the browser.

### Q7. What is the purpose of the `<script>` tag?

The `<script>` element embeds JavaScript or references an external JavaScript file.

### Q8. What is the purpose of `defer`?

For a classic external script, `defer` allows the script to be downloaded while HTML is parsed and executed after parsing completes, preserving the order of deferred classic scripts.

### Q9. Can JavaScript change CSS?

Yes. JavaScript can modify element styles, change classes, and update attributes, which can affect the page's appearance.

### Q10. Can JavaScript run without HTML?

Yes. JavaScript can run in environments such as Node.js without an HTML document. However, browser DOM operations require an appropriate browser document.

### Q11. What happens when a user clicks a button?

The browser dispatches a click event. If JavaScript has registered a matching event listener, the associated callback can execute and update application state or the DOM.

### Q12. Why separate HTML, CSS, and JavaScript into different files?

Separation of concerns makes code easier to organize, reuse, test, debug, and maintain.

## 13. Quick revision notes

- HTML = structure and content.
- CSS = presentation and layout.
- JavaScript = logic and behavior.
- DOM = the document's object representation.
- `querySelector()` selects an element using a CSS selector.
- `textContent` reads or changes text content.
- `addEventListener()` registers a function to respond to events.
- External CSS is linked using `<link>`.
- External JavaScript is loaded using `<script src="...">`.
- `defer` helps external classic scripts execute after HTML parsing.
- Browser APIs and Node.js APIs are not identical.
