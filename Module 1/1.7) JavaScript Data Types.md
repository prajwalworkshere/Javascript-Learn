# Topic 07: JavaScript Data Types

## 1. What Are Data Types?

A **data type** defines the kind of value a variable holds and the operations that can be performed on that value.

For example:

```javascript
let studentName = "Prajwal";
let age = 21;
let isStudent = true;
```

Here:
- `studentName` stores text.
- `age` stores a number.
- `isStudent` stores a Boolean value (`true` or `false`).

JavaScript uses data types to determine how values behave when we perform operations on them.

### Why are data types important?

Data types help us:
1. Store different kinds of information.
2. Perform correct operations.
3. Understand the result of expressions.
4. Avoid unexpected behavior and bugs.
5. Validate user input.
6. Write reliable applications.

For example:

```javascript
console.log(10 + 20);
console.log("10" + "20");
```

**Output:**

```text
30
1020
```

In the first expression, JavaScript adds two numbers. In the second, it joins two strings together. The `+` operator behaves differently depending on the operand types.

## 2. Types of Data Types in JavaScript

JavaScript data types are commonly divided into two groups:

1. Primitive data types
2. Non-primitive (reference) types

```text
JavaScript Data Types
|
|-- Primitive Types
|   |-- Number
|   |-- String
|   |-- Boolean
|   |-- Undefined
|   |-- Null
|   |-- BigInt
|   |-- Symbol
|
|-- Non-Primitive Type
    |-- Object
        |-- Object literals
        |-- Arrays
        |-- Functions
```

Technically, arrays and functions are special kinds of objects, but they are often studied separately because they have different uses.

## 3. Primitive Data Types

A **primitive data type** represents a single value that is not an object.

JavaScript has seven primitive types:

- Number
- String
- Boolean
- Undefined
- Null
- BigInt
- Symbol

Primitive values are immutable. This means the value itself cannot be changed internally. A variable can still be reassigned to hold a different primitive value when declared with `let` or `var`.

### 3.1 Number

The `number` type represents integers and decimal numbers.

```javascript
let age = 21;
let price = 99.50;
let temperature = -5;
let result = 0;

console.log(age);
console.log(price);
console.log(temperature);
console.log(result);
```

**Output:**

```text
21
99.5
-5
0
```

Unlike some other languages, JavaScript does not have separate standard primitive types for integers and floating-point numbers. Both use `number`.

#### Special numeric values

```javascript
console.log(10 / 0);
console.log(-10 / 0);
console.log("hello" * 2);
console.log(typeof NaN);
```

**Output:**

```text
Infinity
-Infinity
NaN
number
```

- `Infinity`: represents positive infinity.
- `-Infinity`: represents negative infinity.
- `NaN`: means “Not a Number”; it represents an invalid numeric result.
- `NaN` itself has the type `number`.

A useful way to check whether a result is `NaN` is:

```javascript
let result = Number("hello");

console.log(result);
console.log(Number.isNaN(result));
```

**Output:**

```text
NaN
true
```

Avoid checking `NaN` using `result === NaN`, because `NaN` is not equal to itself.

### 3.2 String

A **string** is a sequence of text characters.

Strings can be written using single quotes, double quotes, or backticks.

```javascript
let firstName = "Prajwal";
let city = 'Panvel';
let message = `Welcome to JavaScript`;

console.log(firstName);
console.log(city);
console.log(message);
```

**Output:**

```text
Prajwal
Panvel
Welcome to JavaScript
```

#### String concatenation

Concatenation means joining strings together.

```javascript
let firstName = "Prajwal";
let lastName = "Gadge";

let fullName = firstName + " " + lastName;

console.log(fullName);
```

**Output:**

```text
Prajwal Gadge
```

#### Template literals

Template literals use backticks and allow expressions to be embedded using `${...}`.

```javascript
let name = "Prajwal";
let age = 21;

console.log(`My name is ${name} and I am ${age} years old.`);
```

**Output:**

```text
My name is Prajwal and I am 21 years old.
```

Template literals are useful when constructing messages, displaying user information, and generating dynamic text.

#### Strings are immutable

You cannot change an individual character of an existing string.

```javascript
let word = "Hello";

word[0] = "Y";

console.log(word);
```

**Output:**

```text
Hello
```

The attempted character assignment does not change the string. You can create a new string or reassign the variable instead:

```javascript
let word = "Hello";
word = "Yellow";

console.log(word);
```

**Output:**

```text
Yellow
```

The variable now refers to a different string value.

### 3.3 Boolean

The Boolean type has only two values:

- `true`
- `false`

Booleans are commonly used in conditions, comparisons, and decision-making.

```javascript
let isLoggedIn = true;
let hasPermission = false;

console.log(isLoggedIn);
console.log(hasPermission);
console.log(10 > 5);
console.log(10 < 5);
```

**Output:**

```text
true
false
true
false
```

Example in a real situation:

```javascript
let age = 20;
let canVote = age >= 18;

console.log(canVote);
```

**Output:**

```text
true
```

The expression `age >= 18` evaluates to a Boolean value, which is assigned to `canVote`.

### 3.4 Undefined

`undefined` usually indicates that a variable has been declared but has not been assigned a value.

```javascript
let course;

console.log(course);
console.log(typeof course);
```

**Output:**

```text
undefined
undefined
```

The variable exists, but no value has been assigned to it.

A function can also return `undefined` when it does not explicitly return a value.

```javascript
function greet() {
    console.log("Hello!");
}

let result = greet();

console.log(result);
```

**Output:**

```text
Hello!
undefined
```

The function prints `"Hello!"`, but it does not return a value. Therefore, `result` receives `undefined`.

### 3.5 Null

`null` represents the intentional absence of a value.

```javascript
let selectedUser = null;

console.log(selectedUser);
console.log(typeof selectedUser);
```

**Output:**

```text
null
object
```

Important: `typeof null` returns `"object"` because of a historical JavaScript quirk. This does **not** mean that `null` is an ordinary object. It is a primitive value.

#### Difference between `undefined` and `null`

| `undefined` | `null` |
|---|---|
| Usually indicates that a value has not been assigned. | Usually indicates an intentionally empty value. |
| Commonly appears as a variable's initial value when declared without assignment. | Commonly assigned explicitly by the programmer. |
| `typeof` returns `"undefined"`. | `typeof` returns `"object"` due to a historical quirk. |

Example:

```javascript
let username;
let selectedProduct = null;

console.log(username);
console.log(selectedProduct);
```

**Output:**

```text
undefined
null
```

Think of it this way:

- `undefined`: “I don't have a value assigned yet.”
- `null`: “I intentionally have no value right now.”

### 3.6 BigInt

The `bigint` type represents integers larger than the range safely represented by the `number` type.

A BigInt literal can be written by adding `n` to an integer literal.

```javascript
let bigNumber = 123456789012345678901234567890n;

console.log(bigNumber);
console.log(typeof bigNumber);
```

**Output:**

```text
123456789012345678901234567890n
bigint
```

BigInt is useful when working with very large integer values, such as certain identifiers or exact large-integer calculations.

#### Important BigInt rule

You cannot directly mix a BigInt and a Number in ordinary arithmetic.

```javascript
let a = 10n;
let b = 5;

// console.log(a + b); // TypeError
console.log(a + BigInt(b));
```

**Output:**

```text
15n
```

Convert deliberately when you need to combine these types. Conversion from a Number to BigInt requires an integer value.

### 3.7 Symbol

A `symbol` is a primitive type used to create unique identifiers.

```javascript
let id1 = Symbol("id");
let id2 = Symbol("id");

console.log(id1 === id2);
console.log(typeof id1);
```

**Output:**

```text
false
symbol
```

Even though both symbols have the same description (`"id"`), they are different values.

Symbols are useful when you need unique property keys, especially in advanced JavaScript code.

You do not need to use symbols frequently as a beginner, but you should know that they are one of the seven primitive types.

## 4. Non-Primitive Data Types: Objects

An **object** is a collection of properties. Each property can associate a key with a value.

Objects are useful when related information needs to be grouped together.

```javascript
let student = {
    name: "Prajwal",
    age: 21,
    course: "JavaScript"
};

console.log(student);
console.log(student.name);
console.log(student.age);
console.log(student.course);
```

**Output:**

```text
{ name: 'Prajwal', age: 21, course: 'JavaScript' }
Prajwal
21
JavaScript
```

The exact formatting of the first output may differ between a browser console and Node.js.

Here:

- `name`, `age`, and `course` are property keys.
- `"Prajwal"`, `21`, and `"JavaScript"` are their corresponding values.

### Accessing object properties

Using dot notation:

```javascript
console.log(student.name);
```

Using bracket notation:

```javascript
console.log(student["course"]);
```

Both return the value of the requested property.

### Modifying an object

```javascript
let student = {
    name: "Prajwal",
    age: 21
};

student.age = 22;
student.city = "Panvel";

console.log(student.age);
console.log(student.city);
```

**Output:**

```text
22
Panvel
```

Objects can be modified even when the variable holding the object is declared with `const`. The `const` declaration prevents reassignment of the variable, not modification of the object's properties.

```javascript
const student = {
    name: "Prajwal"
};

student.name = "Rahul"; // Allowed

console.log(student.name);
```

**Output:**

```text
Rahul
```

However, this is not allowed:

```javascript
const student = {
    name: "Prajwal"
};

// student = { name: "Rahul" }; // TypeError
```

## 5. Arrays

An **array** is an ordered collection of values. Arrays are objects in JavaScript and can contain values of different types.

```javascript
let marks = [85, 90, 78, 92];

console.log(marks);
console.log(marks[0]);
console.log(marks[2]);
console.log(marks.length);
```

**Output:**

```text
[85, 90, 78, 92]
85
78
4
```

Important points:

- Array indexes begin at `0`.
- `marks[0]` returns the first item.
- `marks[2]` returns the third item.
- `marks.length` returns the number of elements.

Arrays can store mixed types:

```javascript
let details = ["Prajwal", 21, true, null];

console.log(details[0]);
console.log(details[1]);
console.log(details[2]);
console.log(details[3]);
```

**Output:**

```text
Prajwal
21
true
null
```

### Checking the type of an array

```javascript
let marks = [80, 90, 95];

console.log(typeof marks);
console.log(Array.isArray(marks));
```

**Output:**

```text
object
true
```

`typeof` returns `"object"` for arrays, so use `Array.isArray()` when you specifically need to check whether a value is an array.

## 6. Functions Are Also Objects

Functions are reusable blocks of code. In JavaScript, functions are also objects, although they have the additional capability of being called.

```javascript
function add(a, b) {
    return a + b;
}

console.log(add(10, 20));
console.log(typeof add);
```

**Output:**

```text
30
function
```

Notice that `typeof add` returns `"function"`, not `"object"`. This is a special result for callable functions.

Functions can be assigned to variables:

```javascript
let greet = function () {
    console.log("Hello!");
};

greet();
```

**Output:**

```text
Hello!
```

You will study functions in depth in a later topic.

## 7. The `typeof` Operator

The `typeof` operator returns a string describing the type of a value.

### Common `typeof` results

| Value | Result |
|---|---|
| `25` | `"number"` |
| `3.14` | `"number"` |
| `"Hello"` | `"string"` |
| `true` | `"boolean"` |
| `undefined` | `"undefined"` |
| `null` | `"object"` |
| `123n` | `"bigint"` |
| `Symbol("id")` | `"symbol"` |
| `{}` | `"object"` |
| `[]` | `"object"` |
| `function() {}` | `"function"` |

### Runnable example

```javascript
console.log(typeof 25);
console.log(typeof "Hello");
console.log(typeof true);
console.log(typeof undefined);
console.log(typeof null);
console.log(typeof 123n);
console.log(typeof Symbol("id"));
console.log(typeof {});
console.log(typeof []);
console.log(typeof function () {});
```

**Output:**

```text
number
string
boolean
undefined
object
bigint
symbol
object
object
function
```

### Important rules to remember

1. `typeof null` returns `"object"` because of a historical quirk.
2. `typeof []` returns `"object"` because arrays are objects.
3. `typeof function() {}` returns `"function"`.
4. `typeof` returns a string, so compare it with quotes.

Correct:

```javascript
let age = 21;

console.log(typeof age === "number");
```

Output:

```text
true
```

Incorrect:

```javascript
// typeof age === number
```

Here, `number` is not written as a string. Unless a variable named `number` exists, this will cause a `ReferenceError`.

## 8. Primitive Values vs Reference Values

This distinction is especially important for interviews and debugging.

### 8.1 Copying primitive values

When a primitive value is assigned to another variable, the value is copied.

```javascript
let a = 10;
let b = a;

b = 20;

console.log(a);
console.log(b);
```

**Output:**

```text
10
20
```

Dry run:

1. `a` receives `10`.
2. `b = a` copies the value `10` into `b`.
3. `b = 20` changes the value stored in `b`.
4. `a` remains `10`.

```text
a = 10
b = 10  (copied from a)

Then b = 20

a = 10
b = 20
```

Changing `b` does not change `a`.

### 8.2 Copying an object reference

When an object is assigned to another variable, the reference to that object is copied. Both variables can access the same object.

```javascript
let person1 = {
    name: "Prajwal"
};

let person2 = person1;

person2.name = "Rahul";

console.log(person1.name);
console.log(person2.name);
```

**Output:**

```text
Rahul
Rahul
```

Dry run:

1. An object is created with `name: "Prajwal"`.
2. `person1` refers to that object.
3. `person2 = person1` copies the reference.
4. Both variables now refer to the same object.
5. Changing the object's `name` through `person2` is visible through `person1`.

```text
person1 ----\
             ---> Same object { name: "Rahul" }
person2 ----/
```

**Important technical detail:** JavaScript passes arguments by value. For objects, the value being copied is the reference. JavaScript does not pass variables themselves by reference.

### 8.3 Reassigning a reference variable

Reassignment is different from modifying a shared object.

```javascript
let first = { score: 50 };
let second = first;

second = { score: 100 };

console.log(first.score);
console.log(second.score);
```

**Output:**

```text
50
100
```

Now `second` refers to a new object. `first` still refers to the original object.

## 9. Type Conversion: A Preview

JavaScript can convert values from one type to another. This is called **type conversion**.

### Explicit conversion

You deliberately request a conversion.

```javascript
let value = "25";

console.log(Number(value));
console.log(typeof Number(value));
```

**Output:**

```text
25
number
```

Other examples:

```javascript
console.log(String(100));
console.log(Boolean(1));
console.log(Boolean(0));
```

**Output:**

```text
100
true
false
```

The displayed value `100` is a string in the first line, even though the console output does not show quotes in every environment.

### Implicit conversion

JavaScript sometimes converts values automatically.

```javascript
console.log("5" + 2);
console.log("5" - 2);
```

**Output:**

```text
52
3
```

The `+` operator joins strings when string concatenation applies. The `-` operator converts these operands to numbers for subtraction.

Type conversion and truthy/falsy values will be covered in greater depth in later topics.

## 10. Complete Practical Example

Let's build a small student information program using different data types.

```javascript
let studentName = "Prajwal";        // String
let age = 21;                       // Number
let isEnrolled = true;              // Boolean
let middleName;                     // Undefined
let scholarship = null;             // Null
let marks = [85, 90, 78];           // Array
let student = {                     // Object
    name: studentName,
    age: age,
    enrolled: isEnrolled,
    marks: marks
};

console.log("Name:", student.name);
console.log("Age:", student.age);
console.log("Enrolled:", student.enrolled);
console.log("Middle name:", middleName);
console.log("Scholarship:", scholarship);
console.log("First mark:", student.marks[0]);
console.log("Student type:", typeof student);
console.log("Marks is an array:", Array.isArray(student.marks));
```

**Expected output:**

```text
Name: Prajwal
Age: 21
Enrolled: true
Middle name: undefined
Scholarship: null
First mark: 85
Student type: object
Marks is an array: true
```

### Dry run

| Variable | Stored value | Type |
|---|---|---|
| `studentName` | `"Prajwal"` | String |
| `age` | `21` | Number |
| `isEnrolled` | `true` | Boolean |
| `middleName` | `undefined` | Undefined |
| `scholarship` | `null` | Null |
| `marks` | `[85, 90, 78]` | Array / object |
| `student` | Object containing student information | Object |

The `student` object combines related information into one structure. Its `marks` property refers to the array stored in `marks`.

## 11. Common Mistakes

### Mistake 1: Thinking `"25"` is a number

```javascript
let age = "25";

console.log(typeof age);
```

Output:

```text
string
```

Quotes make this value a string.

### Mistake 2: Thinking `null` is an ordinary object

```javascript
console.log(typeof null);
```

Output:

```text
object
```

This is a historical quirk. `null` is still a primitive value.

### Mistake 3: Using `typeof` to identify arrays

```javascript
let items = [1, 2, 3];

console.log(typeof items);
```

Output:

```text
object
```

Use:

```javascript
console.log(Array.isArray(items));
```

Output:

```text
true
```

### Mistake 4: Confusing `undefined` and `null`

```javascript
let a;
let b = null;

console.log(a);
console.log(b);
```

Output:

```text
undefined
null
```

The first variable has no assigned value; the second has intentionally been assigned `null`.

### Mistake 5: Assuming an object is copied independently

```javascript
let x = { value: 10 };
let y = x;

y.value = 50;

console.log(x.value);
```

Output:

```text
50
```

Both variables refer to the same object.

### Mistake 6: Mixing BigInt and Number

```javascript
let a = 10n;
let b = 5;

// console.log(a + b); // TypeError
```

Convert explicitly if the operation is appropriate:

```javascript
console.log(a + BigInt(b));
```

Output:

```text
15n
```

## 14. Interview and Viva Questions

### Q1. What is a data type in JavaScript?

A data type defines the kind of value a variable holds and determines which operations are meaningful for that value.

### Q2. What are the primitive data types in JavaScript?

The seven primitive types are Number, String, Boolean, Undefined, Null, BigInt, and Symbol.

### Q3. What is the difference between primitive and non-primitive types?

Primitive values are non-object values. Objects are reference values that can hold properties and nested data structures. When an object reference is copied, the variables can refer to the same object.

### Q4. What is `typeof`?

`typeof` is an operator that returns a string describing the type of a value.

### Q5. Why does `typeof null` return `"object"`?

It is a historical JavaScript quirk retained for compatibility. `null` is a primitive value, not an ordinary object.

### Q6. What is the difference between `undefined` and `null`?

`undefined` commonly indicates that a value has not been assigned, whereas `null` is commonly used to represent an intentionally absent value.

### Q7. What is `NaN`?

`NaN` means “Not a Number.” It represents an invalid numeric result and has the type `number`. Use `Number.isNaN()` to check for it.

### Q8. How do you check whether a value is an array?

Use `Array.isArray(value)` because `typeof` returns `"object"` for arrays.

### Q9. What is BigInt?

BigInt represents integers that can exceed the safe integer range of the Number type. BigInt literals use the `n` suffix.

### Q10. What is a Symbol?

A Symbol is a primitive value that is unique, even when two symbols are created with the same description.

### Q11. Are strings mutable in JavaScript?

No. Strings are immutable. Operations that appear to modify a string create a new string instead.

### Q12. What happens when an object is assigned to another variable?

The reference value is copied, so both variables can refer to the same object. Mutating that object through one variable is visible through the other.

### Q13. Is JavaScript statically or dynamically typed?

JavaScript is dynamically typed. A variable can hold values of different types at different times.

```javascript
let value = 10;
value = "Hello";

console.log(value);
```

Output:

```text
Hello
```

This works because `let` allows reassignment and JavaScript does not require the variable to keep one fixed type.

### Q14. Are arrays and functions objects?

Arrays are objects. Functions are callable objects, and `typeof` reports `"function"` for them.

- **`null`:** An intentional absence of value.
- **`NaN`:** An invalid numeric result; its type is `"number"`.
- **BigInt:** Uses the `n` suffix for integer literals.
- **Primitive assignment:** Copies the value.
- **Object assignment:** Copies the reference value.
- **Dynamic typing:** A variable can hold values of different types over time.
