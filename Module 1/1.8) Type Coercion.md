# Topic 08: Type Conversion and Type Coercion in JavaScript

## 1. Introduction

In JavaScript, a value can be converted from one data type to another.

For example, we might convert:
- A string into a number.
- A number into a string.
- A number into a Boolean.
- A string containing a number into a numeric value before performing calculations.

Consider this example:

```javascript
let a = "10";
let b = 5;

console.log(a + b);
console.log(a - b);
```

**Output:**

```text
105
5
```

Why did the first expression produce `105`, while the second produced `5`?

Because JavaScript handles the `+` and `-` operators differently when strings are involved.

- `"10" + 5` results in `"105"` because string concatenation takes place.
- `"10" - 5` results in `5` because the operands are converted to numbers for subtraction.

To understand these results, we need to learn two concepts:

1. Type conversion
2. Type coercion

---

## 2. What Is Type Conversion?

**Definition:** Type conversion is the process of changing a value from one data type to another.

There are two common forms:

1. Explicit type conversion
2. Implicit type conversion

### 2.1 Explicit type conversion

Explicit conversion occurs when the programmer deliberately converts a value using a function or operation.

Example:

```javascript
let value = "100";

let numberValue = Number(value);

console.log(numberValue);
console.log(typeof numberValue);
```

**Output:**

```text
100
number
```

Dry run:

1. `value` stores the string `"100"`.
2. `Number(value)` attempts to convert the string into a number.
3. The converted number `100` is stored in `numberValue`.
4. `typeof numberValue` returns `"number"`.

Other common conversion functions include:

```javascript
String(100);      // "100"
Number("100");    // 100
Boolean(1);       // true
```

Explicit conversion is useful when handling form inputs, API data, calculations, and user-provided values.

### 2.2 Implicit type conversion

Implicit conversion occurs when JavaScript automatically converts a value's type while evaluating an expression.

Example:

```javascript
let result = "10" - 5;

console.log(result);
console.log(typeof result);
```

**Output:**

```text
5
number
```

JavaScript converts `"10"` into the number `10` to perform subtraction.

The programmer did not call `Number()` directly, so this is implicit conversion.

## 3. The `Number()` Function

The `Number()` function attempts to convert a value into a number.

### Example 1: Convert a numeric string

```javascript
let age = "21";

console.log(Number(age));
console.log(typeof Number(age));
```

**Output:**

```text
21
number
```

### Example 2: Convert a decimal string

```javascript
let price = "99.50";

console.log(Number(price));
```

**Output:**

```text
99.5
```

### Example 3: Convert a Boolean

```javascript
console.log(Number(true));
console.log(Number(false));
```

**Output:**

```text
1
0
```

JavaScript converts:
- `true` to `1`
- `false` to `0`

### Example 4: Convert `null`

```javascript
console.log(Number(null));
```

**Output:**

```text
0
```

### Example 5: Convert an empty string

```javascript
console.log(Number(""));
console.log(Number("   "));
```

**Output:**

```text
0
0
```

An empty or whitespace-only string converts to `0` with `Number()`.

### Example 6: Convert invalid numeric text

```javascript
console.log(Number("hello"));
console.log(Number("12abc"));
```

**Output:**

```text
NaN
NaN
```

`NaN` means “Not a Number.” It is the result when the attempted numeric conversion cannot produce a valid number.

### Summary of `Number()`

| Input | Result | Resulting type |
|---|---:|---|
| `Number("25")` | `25` | Number |
| `Number("3.5")` | `3.5` | Number |
| `Number(true)` | `1` | Number |
| `Number(false)` | `0` | Number |
| `Number(null)` | `0` | Number |
| `Number("")` | `0` | Number |
| `Number("hello")` | `NaN` | Number |

Remember that `NaN` is itself of type `"number"`.

```javascript
console.log(typeof Number("hello"));
```

Output:

```text
number
```

## 4. The `String()` Function

The `String()` function converts a value into a string.

### Example 1: Convert a number

```javascript
let age = 21;

let result = String(age);

console.log(result);
console.log(typeof result);
```

**Output:**

```text
21
string
```

The displayed output looks like the number `21`, but the value is now a string.

### Example 2: Convert a Boolean

```javascript
console.log(String(true));
console.log(String(false));
```

**Output:**

```text
true
false
```

Both results are strings.

### Example 3: Convert `null` and `undefined`

```javascript
console.log(String(null));
console.log(String(undefined));
```

**Output:**

```text
null
undefined
```

These outputs represent the text `"null"` and `"undefined"` respectively.

### Example 4: Convert an array

```javascript
let numbers = [10, 20, 30];

console.log(String(numbers));
```

**Output:**

```text
10,20,30
```

For a typical array, its string conversion joins the element representations with commas.

### Summary of `String()`

| Input | Result |
|---|---|
| `String(100)` | `"100"` |
| `String(true)` | `"true"` |
| `String(false)` | `"false"` |
| `String(null)` | `"null"` |
| `String(undefined)` | `"undefined"` |
| `String([10, 20])` | `"10,20"` |

## 5. The `Boolean()` Function

The `Boolean()` function converts a value to either `true` or `false`.

```javascript
console.log(Boolean(1));
console.log(Boolean(0));
console.log(Boolean("Hello"));
console.log(Boolean(""));
```

**Output:**

```text
true
false
true
false
```

To use this correctly, you need to understand **truthy and falsy values**.

### 5.1 Falsy values

A falsy value becomes `false` when converted to a Boolean.

The main falsy values are:

- `false`
- `0`
- `-0`
- `0n`
- `""` (empty string)
- `null`
- `undefined`
- `NaN`

Example:

```javascript
console.log(Boolean(false));
console.log(Boolean(0));
console.log(Boolean(""));
console.log(Boolean(null));
console.log(Boolean(undefined));
console.log(Boolean(NaN));
```

**Output:**

```text
false
false
false
false
false
false
```

### 5.2 Truthy values

Truthy values become `true` when converted to a Boolean.

Examples include:

- Nonzero numbers such as `1`, `-1`, and `100`
- Nonempty strings, including `"false"` and `"0"`
- Arrays, including `[]`
- Objects, including `{}`
- Functions

```javascript
console.log(Boolean(100));
console.log(Boolean(-1));
console.log(Boolean("Hello"));
console.log(Boolean("false"));
console.log(Boolean("0"));
console.log(Boolean([]));
console.log(Boolean({}));
```

**Output:**

```text
true
true
true
true
true
true
true
```

**Important interview point:** An empty array `[]` and an empty object `{}` are truthy in JavaScript.

An empty string `""` is falsy, but a string containing a space `" "` is truthy.

```javascript
console.log(Boolean(""));
console.log(Boolean(" "));
```

**Output:**

```text
false
true
```

## 6. Understanding Type Coercion with Operators

JavaScript sometimes performs implicit conversion based on the operator being used.

### 6.1 The `+` operator

The `+` operator can perform numeric addition or string concatenation.

```javascript
console.log(10 + 5);
console.log("10" + 5);
console.log(10 + "5");
console.log("Hello" + " World");
```

**Output:**

```text
15
105
105
Hello World
```

When string concatenation applies, JavaScript converts the other operand to a string and joins the values.

Dry run:

```javascript
console.log("10" + 5);
```

Step 1: The left operand is a string.

```text
"10"
```

Step 2: The right operand is a number.

```text
5
```

Step 3: String concatenation applies, producing:

```text
"105"
```

The result is a string.

```javascript
console.log(typeof ("10" + 5));
```

Output:

```text
string
```

### 6.2 The `-` operator

The subtraction operator performs numeric subtraction, so operands are converted to numbers when possible.

```javascript
console.log("10" - 5);
console.log("20" - "5");
console.log("10" - 2);
```

**Output:**

```text
5
15
8
```

### 6.3 The `*` operator

```javascript
console.log("10" * 2);
console.log("5" * "4");
```

**Output:**

```text
20
20
```

The operands are converted to numbers.

### 6.4 The `/` operator

```javascript
console.log("20" / 5);
console.log("12" / "3");
```

**Output:**

```text
4
4
```

Again, numeric conversion takes place.

### 6.5 The comparison operators

Comparison operators can also trigger conversion, depending on the operator.

```javascript
console.log("5" == 5);
console.log("5" === 5);
console.log("10" > 5);
```

**Output:**

```text
true
false
true
```

- `==` permits certain type conversions before comparing values.
- `===` compares without converting the operands to a common type.
- `>` performs a comparison; in this example, the string and number are compared numerically.

As a general practice, prefer `===` and `!==` unless you deliberately need loose equality.

## 7. Difference Between `==` and `===`

This is one of the most common JavaScript interview questions.

### Loose equality: `==`

Loose equality allows type conversion in certain comparisons.

```javascript
console.log(5 == "5");
console.log(0 == false);
console.log(null == undefined);
```

**Output:**

```text
true
true
true
```

### Strict equality: `===`

Strict equality does not convert different types to make them match.

```javascript
console.log(5 === "5");
console.log(0 === false);
console.log(null === undefined);
```

**Output:**

```text
false
false
false
```

### Comparison table

| Feature | `==` | `===` |
|---|---|---|
| Name | Loose equality | Strict equality |
| Allows equality-related type conversion | Yes, in applicable cases | No |
| Checks types without coercing operands | No | Yes |
| Recommended default | Usually avoid unless intentional | Usually prefer |

Example:

```javascript
let age = 21;

console.log(age == "21");
console.log(age === "21");
console.log(age === 21);
```

**Output:**

```text
true
false
true
```

Use strict equality to avoid many confusing comparisons.

## 8. Type Coercion with `if` Statements

An `if` statement evaluates its condition as a Boolean.

```javascript
let username = "";

if (username) {
    console.log("Username exists");
} else {
    console.log("Username is empty");
}
```

**Output:**

```text
Username is empty
```

Because an empty string is falsy, the `else` block runs.

Another example:

```javascript
let username = "Prajwal";

if (username) {
    console.log("Username exists");
}
```

**Output:**

```text
Username exists
```

The nonempty string is truthy.

### Common mistake: treating `"false"` as false

```javascript
let value = "false";

if (value) {
    console.log("Condition is true");
} else {
    console.log("Condition is false");
}
```

**Output:**

```text
Condition is true
```

The string `"false"` is nonempty, so it is truthy. It is not the Boolean value `false`.

This matters when processing form inputs, query parameters, and API responses because such data is often received as strings.

## 9. The `+` Operator and Unexpected Results

Let's examine several expressions.

```javascript
console.log(1 + 2);
console.log("1" + 2);
console.log(1 + "2");
console.log("1" + "2");
console.log("1" - 2);
console.log("1" * 2);
```

**Output:**

```text
3
12
12
12
-1
2
```

Remember:

- `1 + 2` performs numeric addition.
- `"1" + 2` produces the string `"12"`.
- `1 + "2"` produces the string `"12"`.
- `"1" + "2"` concatenates the strings.
- `"1" - 2` produces `-1`.
- `"1" * 2` produces `2`.

The key lesson is that **the operator and the operand types determine the result**.

## 10. Practical Example: Calculating a Shopping Bill

Imagine an application receives the product price from an HTML input field.

Input field values are commonly strings, even when users type numbers.

```javascript
let price = "150";
let quantity = "3";

let total = Number(price) * Number(quantity);

console.log("Total bill:", total);
console.log("Result type:", typeof total);
```

**Output:**

```text
Total bill: 450
Result type: number
```

Dry run:

1. `price` stores `"150"` as a string.
2. `quantity` stores `"3"` as a string.
3. `Number(price)` converts `"150"` to `150`.
4. `Number(quantity)` converts `"3"` to `3`.
5. `150 * 3` produces `450`.
6. The result is a number.

### Safer validation

What happens if a user enters invalid text?

```javascript
let price = Number("abc");
let quantity = Number("3");

if (Number.isNaN(price) || Number.isNaN(quantity)) {
    console.log("Please enter valid numbers.");
} else {
    console.log("Total:", price * quantity);
}
```

**Output:**

```text
Please enter valid numbers.
```

For real applications, validation may also need to reject negative values, infinite values, or invalid quantities.

## 11. `Number()` vs `parseInt()` vs `parseFloat()`

These tools all help convert text into numeric values, but their behavior differs.

### `Number()`

Attempts to convert the entire value.

```javascript
console.log(Number("25"));
console.log(Number("25px"));
```

**Output:**

```text
25
NaN
```

### `parseInt()`

Parses an integer from the beginning of a string.

```javascript
console.log(parseInt("25"));
console.log(parseInt("25px"));
console.log(parseInt("3.9"));
```

**Output:**

```text
25
25
3
```

### `parseFloat()`

Parses a floating-point number from the beginning of a string.

```javascript
console.log(parseFloat("3.14"));
console.log(parseFloat("3.14px"));
console.log(parseFloat("25"));
```

**Output:**

```text
3.14
3.14
25
```

### Comparison table

| Input | `Number()` | `parseInt()` | `parseFloat()` |
|---|---:|---:|---:|
| `"25"` | `25` | `25` | `25` |
| `"3.14"` | `3.14` | `3` | `3.14` |
| `"25px"` | `NaN` | `25` | `25` |
| `""` | `0` | `NaN` | `NaN` |

Use the function that matches your validation needs. For example, `Number("25px")` rejects the entire string, while `parseInt("25px")` extracts the initial integer.

**Note:** `parseInt()` and `parseFloat()` are parsers, not strict validators. If the entire input must be a valid number, validate the complete input instead of relying on a parser alone.

## 12. Common Mistakes

### Mistake 1: Using `+` when you want addition

Incorrect for numeric addition:

```javascript
let a = "10";
let b = "20";

console.log(a + b);
```

Output:

```text
1020
```

Correct:

```javascript
console.log(Number(a) + Number(b));
```

Output:

```text
30
```

### Mistake 2: Thinking an empty array is falsy

```javascript
console.log(Boolean([]));
```

Output:

```text
true
```

Arrays are objects, and objects are truthy, even when empty.

### Mistake 3: Thinking `"0"` is falsy

```javascript
console.log(Boolean("0"));
```

Output:

```text
true
```

`"0"` is a nonempty string.

### Mistake 4: Using `==` without understanding conversion

```javascript
console.log(0 == false);
```

Output:

```text
true
```

Prefer strict equality when comparing values of a known type:

```javascript
console.log(0 === false);
```

Output:

```text
false
```

### Mistake 5: Assuming invalid numeric text becomes zero

```javascript
console.log(Number("abc"));
```

Output:

```text
NaN
```

It does not become `0`.

### Mistake 6: Assuming `Number()` and `parseInt()` behave identically

```javascript
console.log(Number("12px"));
console.log(parseInt("12px"));
```

Output:

```text
NaN
12
```

Their parsing rules are different.

## 15. Interview and Viva Questions

### Q1. What is type conversion?

Type conversion is the process of changing a value from one data type to another. It can be explicit or implicit.

### Q2. What is the difference between type conversion and type coercion?

Type conversion is the general process of changing types. In common JavaScript terminology, explicit conversion is requested by the programmer, while coercion often refers to automatic or implicit conversion performed by JavaScript.

### Q3. What is the difference between `Number()` and `parseInt()`?

`Number()` attempts to convert the entire value into a number. `parseInt()` parses an integer from the beginning of a string and stops when it reaches a character that cannot continue the number.

### Q4. What does `Number("hello")` return?

It returns `NaN` because `"hello"` cannot be converted into a valid number.

### Q5. What are truthy and falsy values?

Truthy values become `true` when converted to a Boolean. Falsy values become `false`. Examples of falsy values include `0`, `""`, `null`, `undefined`, `false`, and `NaN`.

### Q6. Is an empty array truthy or falsy?

An empty array is truthy.

```javascript
console.log(Boolean([]));
```

Output:

```text
true
```

### Q7. What is the difference between `==` and `===`?

`==` allows certain type conversions during comparison, while `===` compares without converting the operands to a common type.

### Q8. Why does `"10" + 5` return `"105"`?

The `+` operator performs string concatenation in this expression. The number `5` is converted to the string `"5"` and joined to `"10"`.

### Q9. Why does `"10" - 5` return `5`?

Subtraction is a numeric operation, so JavaScript converts `"10"` into the number `10` and subtracts `5`.

### Q10. What does `Boolean("false")` return?

It returns `true` because `"false"` is a nonempty string, not the Boolean value `false`.

### Q11. What is implicit type conversion?

It is automatic conversion performed by JavaScript while evaluating an expression or operation.

### Q12. What is explicit type conversion?

It is conversion deliberately requested by the programmer, for example with `Number("25")`, `String(25)`, or `Boolean(1)`.
