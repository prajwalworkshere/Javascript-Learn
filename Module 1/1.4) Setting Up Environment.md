## 2. What Do We Need to Learn JavaScript?

To begin learning JavaScript, you need only a few basic tools.

| Tool | Purpose |
|---|---|
| Code editor | Write and organize code |
| Web browser | Run browser-based JavaScript |
| Browser Developer Tools | Inspect output, errors, and webpage behavior |
| Node.js | Run JavaScript outside a browser |
| Terminal | Execute commands such as `node app.js` |

Let's understand each tool.

### 2.1 Code editor

A code editor is an application used to write and edit programming code.

Examples include:

- Visual Studio Code (VS Code)
- Sublime Text
- Notepad++

For this course, we will use **Visual Studio Code (VS Code)**.

VS Code provides syntax highlighting, autocomplete, error hints, debugging tools, and extensions.

Official website: https://code.visualstudio.com/

### 2.2 Web browser

A browser lets you run JavaScript that interacts with webpages.

Examples:

- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

For the exercises in these notes, Chrome or Edge is a convenient choice.

### 2.3 Node.js

Node.js lets you execute JavaScript programs outside a web browser.

For example, you can create `app.js` and execute it with:

```bash
node app.js
```

Official website: https://nodejs.org/

### 2.4 Terminal

A terminal is a text-based interface where you enter commands to interact with your computer.

Examples include:

- Windows Terminal
- Command Prompt
- PowerShell
- The integrated terminal in VS Code

You will use the terminal to run JavaScript files with Node.js.

## 4. Install Node.js

### Step 1: Open the official website

https://nodejs.org/

Download a suitable **LTS (Long-Term Support)** version.

An LTS release is generally a good choice for beginners because it is intended for stable, supported use.

### Step 2: Install Node.js

Run the installer and follow the instructions.

The standard installation includes Node.js and npm.

- **Node.js:** Executes JavaScript outside the browser.
- **npm:** Helps install and manage JavaScript packages.

### Step 3: Verify the installation

Open a new terminal.

In VS Code, you can open the integrated terminal using:

**Terminal → New Terminal**

Run:

```bash
node --version
```

Example output:

```text
v22.x.x
```

The actual version will depend on what you installed.

Next, run:

```bash
npm --version
```

Example output:

```text
10.x.x
```

Your actual npm version may differ.

If both commands display version numbers, the tools are available in your terminal.

### What if the command is not recognized?

If you see a message such as:

```text
'node' is not recognized as an internal or external command
```

Possible causes include:

- Node.js is not installed.
- The terminal was open during installation and needs to be reopened.
- The Node.js installation directory is not configured in your PATH.

Try closing and reopening the terminal first. If the error persists, check the installation and PATH configuration.

## 5. Understand the JavaScript Project Structure

Let's create a small project.

Your folder will look like this:

```text
JavaScript-Learning/
│
├── index.html
├── style.css
├── script.js
│
└── app.js
```

Each file has a different purpose.

| File | Purpose |
|---|---|
| `index.html` | Defines the webpage structure |
| `style.css` | Defines the webpage appearance |
| `script.js` | Adds browser-side JavaScript behavior |
| `app.js` | Example standalone JavaScript program for Node.js |

The names `script.js` and `app.js` are not special. You can choose other filenames.

The `.js` extension conventionally identifies a JavaScript source file.

## 6. Your First JavaScript Program in a Browser

### Step 1: Create `index.html`

Add the following code:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First JavaScript Page</title>
</head>
<body>

    <h1>Welcome to JavaScript</h1>
    <p id="message">This is my first webpage.</p>

    <script src="script.js"></script>
</body>
</html>
```

### Step 2: Create `script.js`

Add this code:

```javascript
console.log("Hello, JavaScript!");

document.getElementById("message").textContent =
    "JavaScript is working!";
```

### Step 3: Run the HTML file

Save both files in the same folder.

Open `index.html` in your browser.

You should see:

```text
Welcome to JavaScript

JavaScript is working!
```

The message in the paragraph changes because JavaScript modifies the DOM element.

### Step 4: Check the console

Open Developer Tools in Chrome or Edge. Common keyboard shortcuts include:

- Windows: `F12` or `Ctrl + Shift + J` to open the console directly.
- macOS: `Option + Command + J`.

You should see:

```text
Hello, JavaScript!
```

### Dry run

1. The browser loads `index.html`.
2. It encounters `<script src="script.js"></script>`.
3. The browser loads and executes `script.js`.
4. `console.log()` prints a message in Developer Tools.
5. `document.getElementById("message")` finds the paragraph.
6. `.textContent` changes its text.

**Important:** In this example, the script appears after the paragraph, so the paragraph already exists when the JavaScript executes.

## 7. Your First Standalone JavaScript Program Using Node.js

Now let's run JavaScript without an HTML webpage.

### Step 1: Create `app.js`

```javascript
let name = "Prajwal";
let age = 21;

console.log("My name is " + name);
console.log("My age is " + age);
console.log("Next year I will be " + (age + 1));
```

### Step 2: Open the terminal

In VS Code, select:

**Terminal → New Terminal**

Make sure the terminal is in your `JavaScript-Learning` directory.

### Step 3: Run the program

Enter:

```bash
node app.js
```

### Expected output

```text
My name is Prajwal
My age is 21
Next year I will be 22
```

### Dry run

Initially:

```text
name = "Prajwal"
age = 21
```

First statement:

```javascript
console.log("My name is " + name);
```

Combines the string with the value of `name`.

Output:

```text
My name is Prajwal
```

Second statement:

```javascript
console.log("My age is " + age);
```

Output:

```text
My age is 21
```

Third statement:

```javascript
console.log("Next year I will be " + (age + 1));
```

First, JavaScript calculates:

```text
21 + 1 = 22
```

Then it combines the result with the string.

Output:

```text
Next year I will be 22
```

**Note:** The name and age are example values. You can change them to your own test data.

## 8. Understand the Browser Console

The browser console is one of the most useful tools for a JavaScript beginner.

You can use it to:

- Execute JavaScript statements.
- Inspect variable values.
- Test calculations.
- Display messages.
- Diagnose errors.

Try these statements one at a time in the console.

### Example 1: Print a message

```javascript
console.log("Learning JavaScript");
```

Output:

```text
Learning JavaScript
```

### Example 2: Perform calculations

```javascript
console.log(10 + 20);
console.log(10 * 5);
console.log(20 / 4);
```

Output:

```text
30
50
5
```

### Example 3: Create a variable

```javascript
let marks = 85;
console.log(marks);
```

Output:

```text
85
```

### Example 4: Update a variable

```javascript
marks = 95;
console.log(marks);
```

Output:

```text
95
```

If you run the first example and then the second example in the same console context, `marks` remains available.

If you reload the page or switch to a different execution context, the variable may no longer be available.

## 9. Useful `console` Methods

Besides `console.log()`, there are other helpful methods.

### 9.1 `console.log()`

Used for ordinary output.

```javascript
console.log("Hello");
```

### 9.2 `console.error()`

Used to display an error-style message.

```javascript
console.error("Something went wrong");
```

This displays an error-style entry in the console. It does not automatically stop your program.

### 9.3 `console.warn()`

Used to display a warning-style message.

```javascript
console.warn("Please check your input");
```

### 9.4 `console.table()`

Useful for displaying arrays of objects in a tabular format.

```javascript
const students = [
    { name: "Aarav", marks: 85 },
    { name: "Diya", marks: 92 },
    { name: "Kabir", marks: 78 }
];

console.table(students);
```

The console displays a table containing the students and their marks.

These methods are useful while learning and debugging. They are not substitutes for proper error handling or application logging in production systems.

## 10. Understand Basic Terminal Commands

You do not need to memorize every terminal command immediately. Start with these.

| Command | Purpose |
|---|---|
| `node --version` | Display the Node.js version |
| `npm --version` | Display the npm version |
| `node app.js` | Execute a JavaScript file using Node.js |
| `cd folder-name` | Change the current directory |
| `dir` | List files and folders in Windows Command Prompt or PowerShell |
| `ls` | List files and folders in shells that support it, such as PowerShell |

### Example

Suppose your project is stored at:


```bash

```

Then:

```bash

```

If you are using VS Code's integrated terminal and it already points to your project folder, you may not need the `cd` command.

## 11. Common Errors and How to Fix Them

### Error 1: `node` is not recognized

**Possible cause:** Node.js is not installed or the terminal cannot find it.

**Fix:** Install Node.js from the official website, reopen the terminal, and check:

```bash
node --version
```

### Error 2: Cannot find the JavaScript file

Example:

```text
Cannot find module '.../app.js'
```

**Possible cause:** You are running the command from the wrong directory, or the file has a different name.

**Fix:**

1. Check the filename.
2. List the files in the current directory.
3. Navigate to the folder containing the file.
4. Run the command again.

```bash
node app.js
```

### Error 3: Browser says `document is not defined`

Example:

```javascript
console.log(document.title);
```

This code requires a browser DOM context. It normally fails in a standalone Node.js program.

**Fix:** Run it in a browser page, or use an appropriate Node.js API if your goal is unrelated to webpage manipulation.

### Error 4: JavaScript changes nothing on the page

Possible causes:

- The element's ID is incorrect.
- The script executes before the element exists.
- The JavaScript file was not loaded.
- A previous JavaScript error stopped the relevant code from running.

**Fix:** Check the spelling of the ID, confirm the file path, and inspect the browser console.

### Error 5: Changes are not visible

Possible causes include unsaved files or cached resources.

**Fix:**

1. Save your files.
2. Reload the page.
3. If necessary, perform a hard reload.

### Error 6: Missing quotation marks

Incorrect:

```javascript
console.log(Hello);
```

If `Hello` is not a defined variable, this produces a `ReferenceError`.

Correct:

```javascript
console.log("Hello");
```

### Error 7: Running browser code as a Node.js script

Incorrect assumption:

> Every JavaScript API available in Chrome must also be available in Node.js.

Remember that the language is shared, but the environment-specific APIs differ.

## 13. Browser vs Node.js: Which Should You Use?

| Task | Recommended environment |
|---|---|
| Learning variables and operators | Either |
| Testing a small JavaScript statement | Browser console or Node.js |
| Changing webpage content | Browser |
| Handling button clicks on a webpage | Browser |
| Reading a local file using Node.js APIs | Node.js |
| Building a backend API | Node.js |
| Practicing JavaScript without creating HTML | Node.js or browser console |

You can learn the core language before choosing a specialization. Later, browser development and backend development will use the same JavaScript fundamentals in different ways.

## 16. Interview and Viva Questions

### Q1. What is a code editor?

A code editor is an application used to write and edit source code. It may provide features such as syntax highlighting, autocomplete, and debugging support.

### Q2. What is VS Code?

Visual Studio Code is a source-code editor that supports JavaScript development and many other programming languages through built-in features and extensions.

### Q3. What is Node.js?

Node.js is a JavaScript runtime that allows JavaScript programs to run outside a web browser.

### Q4. What is npm?

npm is a package manager commonly used with Node.js to install and manage JavaScript packages and project dependencies.

### Q5. How do you run a JavaScript file using Node.js?

Use the terminal command:

```bash
node filename.js
```

### Q6. How can you run JavaScript in a browser?

You can use the browser developer console or include JavaScript in an HTML document through a `<script>` element.

### Q7. What is the browser developer console used for?

It lets developers execute JavaScript, inspect values, view logged messages, and investigate errors.

### Q8. Can we run JavaScript without installing Node.js?

Yes. You can execute JavaScript in a browser console. You need Node.js when you want to use Node.js-specific features or run programs through the Node.js runtime.

### Q9. What is the purpose of a `.js` file?

A `.js` file conventionally stores JavaScript source code that can be loaded by a browser or executed using a runtime such as Node.js.

### Q10. What is the difference between VS Code and Node.js?

VS Code is a code editor. Node.js is a runtime that executes JavaScript programs. They work together, but they are not the same thing.
