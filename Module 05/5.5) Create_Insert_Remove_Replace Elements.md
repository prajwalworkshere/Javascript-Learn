# Module 5 — DOM Manipulation

# Topic 5.5: Creating, Inserting, Replacing, and Removing HTML Elements

## 1. Introduction to Dynamic DOM Manipulation

In HTML, we normally write elements manually.

```html
<div>
    <h2>Product Name</h2>
    <p>Price: ₹500</p>
</div>
```

But modern websites often need to create HTML elements dynamically using JavaScript.

For example:

- Adding products to a shopping cart.
- Displaying comments on a post.
- Adding tasks to a to-do list.
- Showing notifications.
- Displaying search results.
- Creating cards from API data.

JavaScript provides DOM methods that allow us to create, insert, replace, and remove HTML elements while the webpage is running.

### What will we learn?

| Operation | Methods |
|---|---|
| Create elements | `document.createElement()` |
| Create text nodes | `document.createTextNode()` |
| Insert elements | `appendChild()`, `append()`, `prepend()` |
| Insert at a specific position | `insertBefore()`, `insertAdjacentElement()` |
| Insert HTML | `insertAdjacentHTML()` |
| Replace elements | `replaceChild()`, `replaceWith()` |
| Remove elements | `removeChild()`, `remove()` |
| Copy elements | `cloneNode()` |

---

# 2. Understanding the Basic Workflow

Before learning individual methods, understand the general process of dynamically creating an element.

Suppose we want to add a new paragraph to our webpage.

### Step 1: Create an element

```javascript
const paragraph = document.createElement("p");
```

This creates a new paragraph element.

### Step 2: Add content

```javascript
paragraph.textContent = "Hello JavaScript";
```

This adds text inside the paragraph.

### Step 3: Select the parent element

```javascript
const container = document.getElementById("container");
```

We select the element where we want to insert the paragraph.

### Step 4: Insert the element

```javascript
container.appendChild(paragraph);
```

Now the paragraph becomes part of the webpage's DOM tree.

### Complete HTML

```html
<!DOCTYPE html>
<html>
<head>
    <title>Dynamic DOM</title>
</head>
<body>

    <div id="container"></div>

    <script>
        const paragraph = document.createElement("p");

        paragraph.textContent = "Hello JavaScript";

        const container = document.getElementById("container");

        container.appendChild(paragraph);
    </script>

</body>
</html>
```

### Output

The browser displays:

```text
Hello JavaScript
```

### Understanding the DOM tree

**Before JavaScript executes:**

```text
document
  |
  └── html
       |
       ├── head
       |
       └── body
            |
            └── div#container
```

**After JavaScript executes:**

```text
document
  |
  └── html
       |
       ├── head
       |
       └── body
            |
            └── div#container
                  |
                  └── p
                       |
                       └── "Hello JavaScript"
```

Notice that JavaScript created a new paragraph and inserted it inside the existing `div`.

# 3. `document.createElement()`

## 3.1 Definition

`document.createElement()` is a DOM method used to create a new HTML element dynamically.

It creates an element object, but it does not automatically insert that element into the webpage.

This distinction is very important.

### Interview definition

`document.createElement()` is a DOM method that creates a new HTML element node with the specified tag name. The created element must be inserted into the document before it becomes part of the visible webpage.

## 3.2 Syntax

```javascript
document.createElement("tagName");
```

Examples:

```javascript
const heading = document.createElement("h1");

const paragraph = document.createElement("p");

const button = document.createElement("button");

const div = document.createElement("div");

const image = document.createElement("img");
```

## 3.3 Important: Creating does not mean inserting

Consider:

```javascript
const heading = document.createElement("h1");

heading.textContent = "Welcome";
```

Have we created a heading?

**Yes.**

Will it appear on the webpage?

**No.**

Why?

Because we have only created the element in JavaScript. We have not inserted it into the DOM tree.

To display it, we must insert it into an existing element.

```javascript
document.body.appendChild(heading);
```

Now it becomes part of the webpage.

## 3.4 Complete example

```html
<!DOCTYPE html>
<html>
<head>
    <title>Create Element</title>
</head>
<body>

    <script>
        const heading = document.createElement("h1");

        heading.textContent = "Welcome to JavaScript";

        document.body.appendChild(heading);
    </script>

</body>
</html>
```

### Output

```text
Welcome to JavaScript
```

## 3.5 Adding attributes and classes to created elements

After creating an element, we can modify it just like an existing element.

```javascript
const image = document.createElement("img");

image.src = "photo.jpg";
image.alt = "Profile Photo";
image.width = 200;
image.classList.add("profile-image");
```

We can also set attributes using `setAttribute()`:

```javascript
image.setAttribute("src", "photo.jpg");
image.setAttribute("alt", "Profile Photo");
```

Both approaches can be used, depending on the property and requirement.

### Complete example

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container"></div>

    <script>
        const image = document.createElement("img");

        image.src = "photo.jpg";
        image.alt = "My Profile";
        image.width = 200;

        image.classList.add("profile-image");

        document.getElementById("container").appendChild(image);
    </script>

</body>
</html>
```

The browser attempts to display the image from `photo.jpg`. The image must exist at the specified location to load successfully.

# 4. `document.createTextNode()`

## 4.1 Definition

`document.createTextNode()` creates a new text node containing the specified text.

Unlike `createElement()`, which creates an HTML element, `createTextNode()` creates a text node.

### Syntax

```javascript
document.createTextNode("Your text");
```

### Example

```javascript
const text = document.createTextNode("Hello JavaScript");
```

This creates a text node, but it does not insert it into the webpage.

We need to attach it to an element.

```javascript
const paragraph = document.createElement("p");

const text = document.createTextNode("Hello JavaScript");

paragraph.appendChild(text);

document.body.appendChild(paragraph);
```

### Output

```text
Hello JavaScript
```

## 4.2 Understanding the difference

Consider:

```javascript
const paragraph = document.createElement("p");

const text = document.createTextNode("Hello World");

paragraph.appendChild(text);
```

The resulting structure is:

```text
p
 |
 └── "Hello World"
```

Here:

- `paragraph` is an element node.
- `text` is a text node.
- The text node is a child of the paragraph.

## 4.3 `createElement()` vs `createTextNode()`

| Feature | `createElement()` | `createTextNode()` |
|---|---|---|
| Purpose | Creates an HTML element | Creates a text node |
| Creates | Element node | Text node |
| Example | `createElement("p")` | `createTextNode("Hello")` |
| Can contain children? | Yes | No |
| Automatically inserted? | No | No |

## 4.4 Practical example

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container"></div>

    <script>
        const container = document.getElementById("container");

        const heading = document.createElement("h2");

        const text = document.createTextNode("My Website");

        heading.appendChild(text);

        container.appendChild(heading);
    </script>

</body>
</html>
```

Output:

```text
My Website
```

**Important:** For simple text, `textContent` is usually more convenient:

```javascript
const heading = document.createElement("h2");

heading.textContent = "My Website";
```

Use `createTextNode()` when you specifically need to create and manipulate a separate text node.

# 5. `appendChild()`

## 5.1 Definition

`appendChild()` inserts a node as the last child of a specified parent element.

### Interview definition

`appendChild()` is a DOM method that inserts a specified node at the end of the child node list of a parent element.

### Syntax

```javascript
parentElement.appendChild(childNode);
```

Here:

- `parentElement` is the element that will contain the new node.
- `childNode` is the node we want to insert.

## 5.2 Basic example

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container">
        <p>First paragraph</p>
    </div>

    <script>
        const container = document.getElementById("container");

        const newParagraph = document.createElement("p");

        newParagraph.textContent = "Second paragraph";

        container.appendChild(newParagraph);
    </script>

</body>
</html>
```

### Before JavaScript

```html
<div id="container">
    <p>First paragraph</p>
</div>
```

### After JavaScript

```html
<div id="container">
    <p>First paragraph</p>
    <p>Second paragraph</p>
</div>
```

The new paragraph is inserted at the end of the container.

## 5.3 Adding multiple elements using `appendChild()`

`appendChild()` accepts one node at a time.

```javascript
const container = document.getElementById("container");

const p1 = document.createElement("p");
p1.textContent = "First";

const p2 = document.createElement("p");
p2.textContent = "Second";

container.appendChild(p1);
container.appendChild(p2);
```

Both paragraphs are added at the end.

## 5.4 Important behavior: Moving an existing element

Suppose an element is already present in the DOM.

If we append that same element somewhere else, it is moved rather than copied.

Example:

```html
<div id="first">
    <p id="message">Hello</p>
</div>

<div id="second"></div>

<script>
    const message = document.getElementById("message");

    const second = document.getElementById("second");

    second.appendChild(message);
</script>
```

### Before

```text
first
  |
  └── message

second
```

### After

```text
first

second
  |
  └── message
```

The paragraph has moved from the first container to the second container.

There is still only one paragraph with that ID.

**Remember:** `appendChild()` moves an existing node if it already belongs to a document. It does not automatically make a duplicate.

# 6. `append()`

## 6.1 Definition

`append()` inserts one or more nodes or strings at the end of an element's children.

It is a modern and flexible alternative to `appendChild()` for many insertion tasks.

### Syntax

```javascript
parentElement.append(item1, item2, item3);
```

The arguments can be nodes or strings.

## 6.2 Example: Appending an element

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container"></div>

    <script>
        const container = document.getElementById("container");

        const paragraph = document.createElement("p");

        paragraph.textContent = "Hello JavaScript";

        container.append(paragraph);
    </script>

</body>
</html>
```

Output:

```text
Hello JavaScript
```

## 6.3 Example: Appending multiple items

```javascript
const container = document.getElementById("container");

const heading = document.createElement("h2");
heading.textContent = "My Website";

const paragraph = document.createElement("p");
paragraph.textContent = "Welcome to my website";

container.append(heading, paragraph);
```

Both elements are appended in the given order.

## 6.4 Example: Appending a string

```javascript
const container = document.getElementById("container");

container.append("Hello World");
```

This inserts a text node containing `Hello World`.

It does not interpret the string as HTML.

For example:

```javascript
container.append("<h1>Hello</h1>");
```

The browser displays the literal text:

```text
<h1>Hello</h1>
```

It does not create an actual heading element.

## 6.5 `appendChild()` vs `append()`

| Feature | `appendChild()` | `append()` |
|---|---|---|
| Inserts nodes | Yes | Yes |
| Accepts strings | No | Yes |
| Accepts multiple arguments | No | Yes |
| Returns | The appended node | `undefined` |
| Inserts at the end | Yes | Yes |

### Important interview point

`appendChild()` accepts a single Node and returns that node.

`append()` accepts multiple nodes or strings and returns `undefined`.

Both insert content at the end of the parent element.

# 7. `prepend()`

## 7.1 Definition

`prepend()` inserts one or more nodes or strings at the beginning of an element's children.

### Syntax

```javascript
parentElement.prepend(item1, item2);
```

### Example

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container">
        <p>Existing paragraph</p>
    </div>

    <script>
        const container = document.getElementById("container");

        const heading = document.createElement("h2");

        heading.textContent = "New Heading";

        container.prepend(heading);
    </script>

</body>
</html>
```

### Before

```text
container
  |
  └── Existing paragraph
```

### After

```text
container
  |
  ├── New Heading
  |
  └── Existing paragraph
```

The heading is inserted before the existing paragraph.

## 7.2 Example: Prepending multiple elements

```javascript
const container = document.getElementById("container");

const first = document.createElement("p");
first.textContent = "First";

const second = document.createElement("p");
second.textContent = "Second";

container.prepend(first, second);
```

The resulting order is:

```text
First
Second
Existing content
```

The items are inserted in the order in which they are passed.

# 8. `insertBefore()`

## 8.1 Definition

`insertBefore()` inserts a new node before a specified existing child node.

It is useful when you want to insert an element at a particular position rather than simply at the beginning or end.

### Syntax

```javascript
parentElement.insertBefore(newNode, referenceNode);
```

Parameters:

- `newNode`: The node we want to insert.
- `referenceNode`: The existing child node before which the new node should be inserted.

If `referenceNode` is `null`, the new node is inserted at the end.

## 8.2 Example

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container">

        <p id="first">First paragraph</p>

        <p id="third">Third paragraph</p>

    </div>

    <script>
        const container = document.getElementById("container");

        const newParagraph = document.createElement("p");

        newParagraph.textContent = "Second paragraph";

        const third = document.getElementById("third");

        container.insertBefore(newParagraph, third);
    </script>

</body>
</html>
```

### Before

```text
container
  |
  ├── First paragraph
  |
  └── Third paragraph
```

### After

```text
container
  |
  ├── First paragraph
  |
  ├── Second paragraph
  |
  └── Third paragraph
```

The new paragraph is inserted immediately before the third paragraph.

## 8.3 Example: Insert at the end using `insertBefore()`

```javascript
container.insertBefore(newParagraph, null);
```

Passing `null` as the reference node inserts the new node at the end.

## 8.4 Important rule

The reference node must be a child of the parent on which `insertBefore()` is called.

Incorrect:

```javascript
container.insertBefore(newParagraph, elementFromAnotherContainer);
```

If the reference node is not a child of `container`, the operation throws a `NotFoundError`.

# 9. `insertAdjacentElement()`

## 9.1 Definition

`insertAdjacentElement()` inserts an existing element at a specified position relative to another element.

Unlike `appendChild()` or `prepend()`, it allows us to specify positions around the selected element itself.

### Syntax

```javascript
referenceElement.insertAdjacentElement(position, newElement);
```

The `position` argument must be one of these four values:

| Position | Meaning |
|---|---|
| `"beforebegin"` | Before the reference element |
| `"afterbegin"` | Inside the reference element, before its first child |
| `"beforeend"` | Inside the reference element, after its last child |
| `"afterend"` | After the reference element |

## 9.2 Understanding positions visually

Suppose we have:

```html
<div id="container">
    Existing content
</div>
```

The four positions work like this:

```text
                 beforebegin
                      |
                      v
              New element

          +----------------------+
          |       container      |
          |                      |
afterbegin|    New element       |
          |                      |
          |    Existing content  |
          |                      |
beforeend|    New element       |
          +----------------------+

              New element
                      ^
                      |
                   afterend
```

## 9.3 Example

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container">
        Existing content
    </div>

    <script>
        const container = document.getElementById("container");

        const paragraph = document.createElement("p");

        paragraph.textContent = "New Paragraph";

        container.insertAdjacentElement("beforeend", paragraph);
    </script>

</body>
</html>
```

The paragraph is inserted inside the container at the end.

## 9.4 Example of all four positions

The following code demonstrates each position separately.

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container">
        Existing content
    </div>

    <script>
        const container = document.getElementById("container");

        function createParagraph(text) {
            const p = document.createElement("p");
            p.textContent = text;
            return p;
        }

        container.insertAdjacentElement(
            "beforebegin",
            createParagraph("Before the container")
        );

        container.insertAdjacentElement(
            "afterbegin",
            createParagraph("First child")
        );

        container.insertAdjacentElement(
            "beforeend",
            createParagraph("Last child")
        );

        container.insertAdjacentElement(
            "afterend",
            createParagraph("After the container")
        );
    </script>

</body>
</html>
```

The resulting structure is:

```text
body
 |
 ├── Before the container
 |
 ├── div#container
 |     |
 |     ├── First child
 |     |
 |     ├── Existing content
 |     |
 |     └── Last child
 |
 └── After the container
```

**Important:** `"beforebegin"` and `"afterend"` require the reference element to have a parent element.

# 10. `insertAdjacentHTML()`

## 10.1 Definition

`insertAdjacentHTML()` parses an HTML string and inserts the resulting elements at a specified position relative to the selected element.

Unlike `append()`, which treats a string as text, `insertAdjacentHTML()` interprets the string as HTML.

### Syntax

```javascript
element.insertAdjacentHTML(position, htmlString);
```

It accepts:

1. A position.
2. A string containing HTML.

It supports the same four positions:

- `"beforebegin"`
- `"afterbegin"`
- `"beforeend"`
- `"afterend"`

## 10.2 Example

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container">
        <p>Existing paragraph</p>
    </div>

    <script>
        const container = document.getElementById("container");

        container.insertAdjacentHTML(
            "beforeend",
            "<p>New paragraph</p>"
        );
    </script>

</body>
</html>
```

### Resulting HTML

```html
<div id="container">
    <p>Existing paragraph</p>
    <p>New paragraph</p>
</div>
```

The string is interpreted as HTML, so a real paragraph element is created.

## 10.3 Difference between `append()` and `insertAdjacentHTML()`

Consider:

```javascript
container.append("<p>Hello</p>");
```

This inserts literal text:

```text
<p>Hello</p>
```

But:

```javascript
container.insertAdjacentHTML(
    "beforeend",
    "<p>Hello</p>"
);
```

This inserts a real paragraph element.

## 10.4 Security warning: Avoid inserting untrusted HTML

`insertAdjacentHTML()` parses HTML. If untrusted user input is inserted into it, an attacker may inject malicious markup or scripts.

This can lead to Cross-Site Scripting (XSS).

Risky example:

```javascript
const userInput = "<img src=x onerror=alert('Hacked')>";

container.insertAdjacentHTML("beforeend", userInput);
```

Do not insert untrusted data as HTML.

For plain user-provided text, use:

```javascript
const paragraph = document.createElement("p");

paragraph.textContent = userInput;

container.append(paragraph);
```

This treats the input as text instead of parsing it as HTML.

**Remember:** `textContent` is generally the safer choice when displaying plain text.

# 11. `replaceChild()`

## 11.1 Definition

`replaceChild()` replaces an existing child node with a new node inside a parent element.

### Interview definition

`replaceChild()` is a DOM method that replaces an existing child node of a parent with another node.

### Syntax

```javascript
parentElement.replaceChild(newNode, oldNode);
```

Parameters:

- `newNode`: The node that will replace the old node.
- `oldNode`: The existing child node that will be replaced.

## 11.2 Example

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container">

        <p id="old">Old paragraph</p>

    </div>

    <script>
        const container = document.getElementById("container");

        const oldParagraph = document.getElementById("old");

        const newParagraph = document.createElement("p");

        newParagraph.textContent = "New paragraph";

        container.replaceChild(newParagraph, oldParagraph);
    </script>

</body>
</html>
```

### Before

```text
container
  |
  └── Old paragraph
```

### After

```text
container
  |
  └── New paragraph
```

The old paragraph is replaced by the new paragraph.

## 11.3 What does `replaceChild()` return?

It returns the old node that was replaced.

Example:

```javascript
const removedNode = container.replaceChild(
    newParagraph,
    oldParagraph
);

console.log(removedNode.textContent);
```

Output:

```text
Old paragraph
```

# 12. `replaceWith()`

## 12.1 Definition

`replaceWith()` replaces an element with one or more nodes or strings.

It is called directly on the element that we want to replace.

### Syntax

```javascript
oldElement.replaceWith(newElement);
```

It can also accept multiple nodes or strings:

```javascript
oldElement.replaceWith(node1, node2, "Some text");
```

## 12.2 Example

```html
<!DOCTYPE html>
<html>
<body>

    <p id="old">Old paragraph</p>

    <script>
        const oldParagraph = document.getElementById("old");

        const newParagraph = document.createElement("p");

        newParagraph.textContent = "New paragraph";

        oldParagraph.replaceWith(newParagraph);
    </script>

</body>
</html>
```

The old paragraph is replaced by the new paragraph.

## 12.3 `replaceChild()` vs `replaceWith()`

| Feature | `replaceChild()` | `replaceWith()` |
|---|---|---|
| Called on | Parent element | Element being replaced |
| Syntax | `parent.replaceChild(new, old)` | `old.replaceWith(new)` |
| Accepts multiple arguments | No | Yes |
| Accepts strings | No | Yes |
| Return value | Old replaced node | `undefined` |

Both methods can replace an existing element.

# 13. `removeChild()`

## 13.1 Definition

`removeChild()` removes a specified child node from its parent element.

### Interview definition

`removeChild()` is a DOM method that removes a specified child node from a parent node and returns the removed node.

### Syntax

```javascript
parentElement.removeChild(childNode);
```

## 13.2 Example

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container">

        <p id="message">Hello JavaScript</p>

    </div>

    <script>
        const container = document.getElementById("container");

        const message = document.getElementById("message");

        container.removeChild(message);
    </script>

</body>
</html>
```

### Before

```text
container
  |
  └── message
```

### After

```text
container
```

The paragraph is removed from the container.

## 13.3 What does `removeChild()` return?

It returns the removed node.

```javascript
const removedElement = container.removeChild(message);

console.log(removedElement.textContent);
```

Output:

```text
Hello JavaScript
```

The returned node still exists as a JavaScript object, but it is no longer attached to that parent.

You could insert it somewhere else later:

```javascript
document.body.appendChild(removedElement);
```

# 14. `remove()`

## 14.1 Definition

`remove()` removes an element directly from the DOM.

Unlike `removeChild()`, it does not require us to select the parent element.

### Syntax

```javascript
element.remove();
```

## 14.2 Example

```html
<!DOCTYPE html>
<html>
<body>

    <p id="message">Hello JavaScript</p>

    <script>
        const message = document.getElementById("message");

        message.remove();
    </script>

</body>
</html>
```

The paragraph is removed from the webpage.

## 14.3 `removeChild()` vs `remove()`

| Feature | `removeChild()` | `remove()` |
|---|---|---|
| Called on | Parent element | Element being removed |
| Syntax | `parent.removeChild(child)` | `child.remove()` |
| Requires parent reference | Yes | No |
| Return value | Removed node | `undefined` |
| Removes from DOM | Yes | Yes |

### Recommendation

Use `remove()` when you already have a reference to the element.

Use `removeChild()` when you are working with a parent and want to remove one of its children.

# 15. `cloneNode()`

## 15.1 Definition

`cloneNode()` creates a copy of an existing DOM node.

It is useful when you want to duplicate an existing element rather than build a new one from scratch.

### Syntax

```javascript
element.cloneNode(deep);
```

The `deep` parameter is Boolean:

- `false`: Creates a shallow copy without child nodes.
- `true`: Creates a deep copy including descendant nodes.

If omitted, it defaults to `false`.

## 15.2 Shallow cloning

```html
<div id="container">
    <p>Hello JavaScript</p>
</div>
```

JavaScript:

```javascript
const container = document.getElementById("container");

const copy = container.cloneNode(false);

document.body.appendChild(copy);
```

The copy contains the `div` element itself and its attributes, but not its child paragraph.

## 15.3 Deep cloning

```javascript
const container = document.getElementById("container");

const copy = container.cloneNode(true);

document.body.appendChild(copy);
```

This copies the `div` along with its child paragraph.

### Visual comparison

Original:

```text
div#container
  |
  └── p
       |
       └── Hello JavaScript
```

Shallow copy:

```text
div#container
```

Deep copy:

```text
div#container
  |
  └── p
       |
       └── Hello JavaScript
```

## 15.4 Important points about cloning

1. `cloneNode()` does not automatically insert the copy into the document.
2. You must append or insert the copy yourself.
3. Event listeners added using `addEventListener()` are not copied.
4. Inline event handler attributes may be copied.
5. Cloning an element with an ID can create duplicate IDs.

Example:

```javascript
const original = document.getElementById("card");

const copy = original.cloneNode(true);

copy.id = "card-copy";

document.body.appendChild(copy);
```

Change the copied ID when necessary to maintain unique IDs.

# 16. Understanding `appendChild()`, `append()`, `prepend()`, and `insertBefore()`

These methods are commonly confused because all of them insert content into an element.

Let's compare them carefully.

Suppose our HTML is:

```html
<div id="container">
    <p id="first">First</p>
    <p id="second">Second</p>
</div>
```

### 1. `appendChild()`

```javascript
container.appendChild(newElement);
```

Inserts at the end.

```text
First
Second
New Element
```

### 2. `append()`

```javascript
container.append(newElement);
```

Also inserts at the end, but accepts strings and multiple arguments.

```text
First
Second
New Element
```

### 3. `prepend()`

```javascript
container.prepend(newElement);
```

Inserts at the beginning.

```text
New Element
First
Second
```

### 4. `insertBefore()`

```javascript
container.insertBefore(newElement, second);
```

Inserts before the specified reference node.

```text
First
New Element
Second
```

### Comparison table

| Method | Insertion position | Multiple arguments | Accepts strings |
|---|---|---|---|
| `appendChild()` | End | No | No |
| `append()` | End | Yes | Yes |
| `prepend()` | Beginning | Yes | Yes |
| `insertBefore()` | Before reference node | No | No |

# 17. Important Concept: Nodes and Elements

When working with DOM insertion methods, it is important to understand the difference between a node and an element.

An **element** is a specific type of node representing an HTML element.

A **node** is a more general DOM object. Nodes include:

- Element nodes.
- Text nodes.
- Comment nodes.
- Document nodes.

For example:

```html
<div id="container">
    Hello
    <p>JavaScript</p>
    <!-- This is a comment -->
</div>
```

The `div` is an element node.

Inside it:

- `Hello` is a text node.
- `p` is an element node.
- The comment is a comment node.

This distinction matters because methods such as `appendChild()` and `insertBefore()` work with nodes, not just HTML elements.

## 17.1 `children` vs `childNodes`

These properties are useful when examining the children of an element.

### `children`

Returns a live `HTMLCollection` containing only element children.

```javascript
const container = document.getElementById("container");

console.log(container.children);
```

Text nodes and comment nodes are excluded.

### `childNodes`

Returns a live `NodeList` containing all child nodes, including text and comment nodes.

```javascript
console.log(container.childNodes);
```

Whitespace between HTML tags can also create text nodes.

### Comparison

| Feature | `children` | `childNodes` |
|---|---|---|
| Returns | `HTMLCollection` | `NodeList` |
| Includes element nodes | Yes | Yes |
| Includes text nodes | No | Yes |
| Includes comment nodes | No | Yes |
| Live collection | Yes | Yes |

Example:

```html
<div id="container">
    Hello
    <p>JavaScript</p>
</div>
```

```javascript
const container = document.getElementById("container");

console.log(container.children.length);
console.log(container.childNodes.length);
```

Typical output:

```text
1
3
```

Explanation:

- `children` contains the paragraph element.
- `childNodes` contains the text node before the paragraph, the paragraph element, and the trailing whitespace text node.

Exact text-node counts depend on the whitespace and formatting in the HTML.

# 18. Important Concept: Moving vs Copying DOM Elements

This is a common source of confusion.

Suppose:

```html
<div id="first">
    <p id="message">Hello</p>
</div>

<div id="second"></div>
```

Now:

```javascript
const message = document.getElementById("message");

const second = document.getElementById("second");

second.appendChild(message);
```

What happens?

The paragraph moves from the first container to the second container.

It does not create a second paragraph.

### To create a copy instead

Use `cloneNode()`:

```javascript
const copy = message.cloneNode(true);

second.appendChild(copy);
```

Now the original paragraph remains in its original location, and a copy is inserted into the second container.

Remember:

```javascript
parent.appendChild(existingElement);
```

Moves the existing element.

```javascript
parent.appendChild(existingElement.cloneNode(true));
```

Inserts a copy.

        type="text"

        const taskInput = document.getElementById("taskInput");

        const addButton = document.getElementById("addButton");

            const taskText = taskInput.value.trim();

# 21. Common Mistakes and Their Corrections

## Mistake 1: Thinking `createElement()` automatically displays an element

Incorrect assumption:

```javascript
const heading = document.createElement("h1");

heading.textContent = "Hello";
```

The heading is created but not inserted.

Correct:

```javascript
document.body.appendChild(heading);
```

## Mistake 2: Forgetting to select a parent element

Incorrect:

```javascript
appendChild(paragraph);
```

Correct:

```javascript
container.appendChild(paragraph);
```

`appendChild()` must be called on the parent node.

## Mistake 3: Passing a string to `appendChild()`

Incorrect:

```javascript
container.appendChild("Hello");
```

`appendChild()` expects a Node, not a string.

Correct:

```javascript
container.append("Hello");
```

Or:

```javascript
const text = document.createTextNode("Hello");

container.appendChild(text);
```

## Mistake 4: Confusing `append()` with HTML parsing

Incorrect assumption:

```javascript
container.append("<h1>Hello</h1>");
```

This does not create a heading. It inserts literal text.

Correct:

```javascript
const heading = document.createElement("h1");

heading.textContent = "Hello";

container.append(heading);
```

Or, when the HTML string is trusted and appropriate:

```javascript
container.insertAdjacentHTML(
    "beforeend",
    "<h1>Hello</h1>"
);
```

## Mistake 5: Using the wrong reference node in `insertBefore()`

Incorrect:

```javascript
container.insertBefore(newElement, nullElement);
```

if `nullElement` is not a valid child node.

Correct:

```javascript
container.insertBefore(newElement, existingChild);
```

Or use `null` to insert at the end:

```javascript
container.insertBefore(newElement, null);
```

## Mistake 6: Confusing the order of `replaceChild()` arguments

Incorrect:

```javascript
container.replaceChild(oldElement, newElement);
```

Correct:

```javascript
container.replaceChild(newElement, oldElement);
```

Remember:

```javascript
parent.replaceChild(NEW, OLD);
```

## Mistake 7: Calling `removeChild()` on the wrong parent

Incorrect:

```javascript
anotherContainer.removeChild(message);
```

if `message` is not a child of `anotherContainer`.

Correct:

```javascript
message.remove();
```

Or call `removeChild()` on its actual parent.

## Mistake 8: Forgetting that appending an existing element moves it

```javascript
secondContainer.appendChild(message);
```

This moves `message` from its previous parent.

To duplicate it:

```javascript
const copy = message.cloneNode(true);

secondContainer.appendChild(copy);
```

## Mistake 9: Using untrusted data with `innerHTML` or `insertAdjacentHTML()`

Risky:

```javascript
container.insertAdjacentHTML(
    "beforeend",
    userInput
);
```

Safer for plain text:

```javascript
const paragraph = document.createElement("p");

paragraph.textContent = userInput;

container.append(paragraph);
```

# 22. Important Interview Questions and Answers

## Q1. What is dynamic DOM manipulation?

Dynamic DOM manipulation is the process of creating, modifying, inserting, replacing, or removing HTML elements using JavaScript while a webpage is running.

## Q2. What is `document.createElement()`?

`document.createElement()` is a DOM method used to create a new HTML element node with the specified tag name. The created element is not automatically inserted into the document.

## Q3. Does `createElement()` automatically add an element to the webpage?

No. It only creates an element object. We must insert it using methods such as `appendChild()`, `append()`, or `prepend()`.

## Q4. What is `document.createTextNode()`?

It creates a text node containing the specified text. The text node must be inserted into an element to become part of the document.

## Q5. What is the difference between `createElement()` and `createTextNode()`?

`createElement()` creates an HTML element node, whereas `createTextNode()` creates a text node containing plain text.

## Q6. What is `appendChild()`?

`appendChild()` inserts a node at the end of a parent's child node list. It accepts one Node and returns the inserted node.

## Q7. What is `append()`?

`append()` inserts one or more nodes or strings at the end of an element's children. Unlike `appendChild()`, it accepts strings and multiple arguments.

## Q8. What is `prepend()`?

`prepend()` inserts one or more nodes or strings at the beginning of an element's children.

## Q9. What is `insertBefore()`?

`insertBefore()` inserts a new node before a specified existing child node of a parent.

## Q10. What is `insertAdjacentElement()`?

It inserts an existing element at a specified position relative to another element using positions such as `beforebegin`, `afterbegin`, `beforeend`, and `afterend`.

## Q11. What is `insertAdjacentHTML()`?

It parses an HTML string and inserts the resulting HTML at a specified position relative to an element.

## Q12. What is the difference between `append()` and `insertAdjacentHTML()`?

`append()` treats a string as text, whereas `insertAdjacentHTML()` parses the string as HTML and creates the corresponding DOM elements.

## Q13. What is `replaceChild()`?

`replaceChild()` replaces an existing child node with a new node inside a parent element. It returns the old node.

## Q14. What is `replaceWith()`?

`replaceWith()` replaces the element on which it is called with one or more nodes or strings.

## Q15. What is `removeChild()`?

`removeChild()` removes a specified child node from its parent and returns the removed node.

## Q16. What is `remove()`?

`remove()` removes an element directly from the DOM without requiring a parent reference.

## Q17. What is the difference between `remove()` and `removeChild()`?

`remove()` is called directly on the element being removed. `removeChild()` is called on its parent and requires the child node as an argument.

## Q18. What is `cloneNode()`?

`cloneNode()` creates a copy of a DOM node. It accepts an optional Boolean parameter that determines whether descendant nodes are copied.

## Q19. What is the difference between shallow and deep cloning?

Shallow cloning copies the node without its child nodes. Deep cloning copies the node along with its descendants.

## Q20. Does `appendChild()` copy an existing node?

No. If the node is already in the DOM, `appendChild()` moves it to the new parent. To create a copy, use `cloneNode()`.

## Q21. What is the difference between `children` and `childNodes`?

`children` returns a live `HTMLCollection` of element children only. `childNodes` returns a live `NodeList` containing all child nodes, including text and comment nodes.

## Q22. Why should we avoid inserting untrusted input using `insertAdjacentHTML()`?

Because the browser parses the supplied string as HTML. Untrusted content can contain malicious markup that may cause Cross-Site Scripting (XSS). For plain text, use `textContent`.

## Q23. Does removing an element destroy its JavaScript object immediately?

No. Removing an element detaches it from the document. If JavaScript still holds a reference to it, the object can still be accessed. It becomes eligible for garbage collection only when it is no longer reachable.

## Q24. Which method would you use to add a new task to a to-do list?

A common approach is:

1. Create an `li` using `document.createElement()`.
2. Set its text using `textContent`.
3. Insert it into the list using `appendChild()` or `append()`.
