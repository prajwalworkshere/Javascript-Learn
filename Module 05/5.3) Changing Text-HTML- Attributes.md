# Topic 5.3: Changing Text, HTML, and Attributes in JavaScript

## 1. Introduction

In the previous topic, we learned how to select HTML elements using methods such as:

- `getElementById()`
- `getElementsByClassName()`
- `querySelector()`
- `querySelectorAll()`

But selecting an element is only the first step.

Once we select an element, we often need to:

1. Read its existing text.
2. Change its text.
3. Insert HTML inside it.
4. Read its HTML content.
5. Read or change its attributes.
6. Remove attributes.
7. Read or update input values.

JavaScript provides several DOM properties and methods for these operations.

### Example: Changing a heading

HTML:

```html
<h1 id="heading">Welcome to My Website</h1>
```

JavaScript:

```javascript
const heading = document.getElementById("heading");

heading.textContent = "Welcome to JavaScript!";
```

**Before:**

```text
Welcome to My Website
```

**After:**

```text
Welcome to JavaScript!
```

JavaScript selected the heading and changed its text.

# 2. Understanding the Three Main Content Properties

The three important properties for working with element content are:

| Property | Purpose |
|---|---|
| `textContent` | Gets or sets the text content of an element and its descendants |
| `innerText` | Gets or sets the rendered text of an element |
| `innerHTML` | Gets or sets the HTML markup inside an element |

Although these properties may look similar, they behave differently.

Let's understand each one carefully.

---

# 3. `textContent` in JavaScript

## 3.1 Definition

`textContent` is a DOM property used to get or set the text content of an HTML element and all its descendants.

When reading it, JavaScript returns the concatenated text of descendant text nodes.

When setting it, JavaScript replaces the element's existing child content with a text node containing the supplied value.

**Interview definition:**

`textContent` is a DOM property that retrieves or updates the text content of an element and its descendants without interpreting the supplied value as HTML.

## 3.2 Syntax

**Reading text:**

```javascript
element.textContent;
```

**Changing text:**

```javascript
element.textContent = "New text";
```

## 3.3 Example 1: Reading text using `textContent`

```html
<!DOCTYPE html>
<html>
<body>

    <h1 id="heading">Learn JavaScript</h1>

    <script>
        const heading = document.getElementById("heading");

        console.log(heading.textContent);
    </script>

</body>
</html>
```

**Expected output:**

```text
Learn JavaScript
```

### Dry run

| Step | Operation | Result |
|---|---|---|
| 1 | Select element using ID | `<h1>` selected |
| 2 | Access `heading.textContent` | Reads text |
| 3 | Print result | `Learn JavaScript` |

## 3.4 Example 2: Changing text using `textContent`

```html
<!DOCTYPE html>
<html>
<body>

    <h1 id="heading">Old Heading</h1>

    <script>
        const heading = document.getElementById("heading");

        heading.textContent = "New Heading";

        console.log(heading.textContent);
    </script>

</body>
</html>
```

**Expected output:**

```text
New Heading
```

**Browser display:**

```text
New Heading
```

### Explanation

1. JavaScript selects the heading.
2. `heading.textContent` accesses its text.
3. The assignment operator `=` assigns a new string.
4. The existing text is replaced.
5. The browser displays the updated text.

## 3.5 Example 3: Replacing existing HTML content

Consider:

```html
<div id="container">
    <h2>Old Heading</h2>
    <p>Old paragraph</p>
</div>
```

JavaScript:

```javascript
const container = document.getElementById("container");

container.textContent = "New Content";
```

After execution, the resulting HTML structure is equivalent to:

```html
<div id="container">New Content</div>
```

**Important:** Setting `textContent` replaces all existing child nodes. It does not simply append text.

The old `<h2>` and `<p>` elements are removed.

## 3.6 Example 4: HTML-looking text remains text

```html
<div id="output"></div>

<script>
    const output = document.getElementById("output");

    output.textContent = "<h1>Hello</h1>";
</script>
```

**Browser display:**

```text
<h1>Hello</h1>
```

The browser displays the angle brackets and tags as ordinary text.

It does not create an actual heading element.

Why?

Because `textContent` treats the supplied value as text, not HTML markup.

## 3.7 Important behavior

- Reads text from descendant elements.
- Setting it replaces existing child content.
- Does not parse supplied strings as HTML.
- Includes text from hidden descendants.
- Does not depend on CSS visibility.
- Is generally the preferred property for inserting plain text.

---

# 4. `innerText` in JavaScript

## 4.1 Definition

`innerText` is a DOM property that gets or sets the rendered text of an element.

It considers how text is presented to the user, including CSS visibility and layout.

**Interview definition:**

`innerText` is a DOM property used to retrieve or update the rendered text content of an element, taking the displayed appearance of the content into account.

## 4.2 Syntax

**Reading text:**

```javascript
element.innerText;
```

**Changing text:**

```javascript
element.innerText = "New text";
```

## 4.3 Example 1: Reading text using `innerText`

```html
<!DOCTYPE html>
<html>
<body>

    <h1 id="heading">Learn JavaScript</h1>

    <script>
        const heading = document.getElementById("heading");

        console.log(heading.innerText);
    </script>

</body>
</html>
```

**Expected output:**

```text
Learn JavaScript
```

## 4.4 Example 2: Understanding hidden elements

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container">
        <p>Visible paragraph</p>

        <p style="display: none;">
            Hidden paragraph
        </p>
    </div>

    <script>
        const container = document.getElementById("container");

        console.log("textContent:", container.textContent);
        console.log("innerText:", container.innerText);
    </script>

</body>
</html>
```

**Expected output:**

```text
textContent: 
        Visible paragraph

        
            Hidden paragraph
        
    
innerText: Visible paragraph
```

The exact whitespace in console output can vary with the browser and formatting.

### Why are the results different?

`textContent` reads text from the DOM tree, including text inside hidden elements.

`innerText` reads rendered text and generally excludes content that is not being rendered, such as an element hidden using `display: none`.

## 4.5 Example 3: Changing text using `innerText`

```html
<h2 id="heading">Old Heading</h2>

<script>
    const heading = document.getElementById("heading");

    heading.innerText = "Updated Heading";

    console.log(heading.innerText);
</script>
```

**Expected output:**

```text
Updated Heading
```

The heading now displays `Updated Heading`.

## 4.6 Important behavior

- Reads rendered text rather than simply reading all descendant text nodes.
- Considers CSS visibility and layout.
- Hidden content may be excluded.
- Setting it replaces the element's existing child content with text.
- Reading it can require the browser to calculate layout, which may be more expensive than reading `textContent`.

# 5. `innerHTML` in JavaScript

## 5.1 Definition

`innerHTML` is a DOM property used to get or set the HTML markup contained inside an element.

Unlike `textContent` and `innerText`, it interprets assigned strings as HTML markup.

**Interview definition:**

`innerHTML` is a DOM property that retrieves or modifies the HTML markup inside an element. When a string is assigned to it, the browser parses that string and creates the corresponding DOM elements.

## 5.2 Syntax

**Reading HTML:**

```javascript
element.innerHTML;
```

**Changing HTML:**

```javascript
element.innerHTML = "<h1>Hello</h1>";
```

## 5.3 Example 1: Reading HTML using `innerHTML`

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container">
        <h2>JavaScript</h2>
        <p>Learning DOM manipulation</p>
    </div>

    <script>
        const container = document.getElementById("container");

        console.log(container.innerHTML);
    </script>

</body>
</html>
```

**Expected output:**

```html
        <h2>JavaScript</h2>
        <p>Learning DOM manipulation</p>
```

The exact indentation and serialization formatting can vary.

Notice that `innerHTML` returns the HTML markup inside the selected element, including the tags.

It does not include the selected element's own outer tag.

## 5.4 Example 2: Changing HTML using `innerHTML`

```html
<!DOCTYPE html>
<html>
<body>

    <div id="container"></div>

    <script>
        const container = document.getElementById("container");

        container.innerHTML = "<h1>Hello JavaScript</h1>";

    </script>

</body>
</html>
```

**Browser display:**

<escape>Hello JavaScript</escape>

The browser creates an actual `<h1>` element.

The resulting DOM structure is:

```html
<div id="container">
    <h1>Hello JavaScript</h1>
</div>
```

## 5.5 Example 3: Inserting multiple HTML elements

```html
<div id="container"></div>

<script>
    const container = document.getElementById("container");

    container.innerHTML = `
        <h2>My Profile</h2>
        <p>Name: Prajwal</p>
        <p>Role: Developer</p>
    `;
</script>
```

**Browser display:**

```text
My Profile

Name: Prajwal

Role: Developer
```

Here, a template literal is used to write multiple lines of HTML.

The browser parses the markup and creates the corresponding elements.

## 5.6 Example 4: Replacing existing content

HTML:

```html
<div id="container">
    <p>Old paragraph</p>
</div>
```

JavaScript:

```javascript
const container = document.getElementById("container");

container.innerHTML = "<h2>New Heading</h2>";
```

Result:

```html
<div id="container">
    <h2>New Heading</h2>
</div>
```

The previous paragraph is replaced.

## 5.7 Example 5: Appending HTML versus replacing HTML

Suppose we have:

```html
<div id="container">
    <p>First paragraph</p>
</div>
```

Using assignment:

```javascript
const container = document.getElementById("container");

container.innerHTML = "<p>Second paragraph</p>";
```

Result:

```html
<div id="container">
    <p>Second paragraph</p>
</div>
```

The old content is replaced.

If you want to preserve existing content while adding new markup, one approach is:

```javascript
container.innerHTML += "<p>Second paragraph</p>";
```

Result:

```html
<div id="container">
    <p>First paragraph</p>
    <p>Second paragraph</p>
</div>
```

**Important:** `innerHTML +=` reads and reparses the existing markup. This can recreate descendant elements and affect their attached event listeners and other state. For adding elements, DOM methods such as `insertAdjacentHTML()` or `append()` are often better choices. We'll study element creation and insertion in Topic 5.5.

# 6. Difference Between `textContent`, `innerText`, and `innerHTML`

This is one of the most important comparisons in DOM manipulation.

Consider this HTML:

```html
<div id="container">
    <h2>Hello</h2>
    <p>Welcome to JavaScript</p>
</div>
```

JavaScript:

```javascript
const container = document.getElementById("container");

console.log(container.textContent);
console.log(container.innerText);
console.log(container.innerHTML);
```

### Conceptual output

`textContent`:

```text
Hello
Welcome to JavaScript
```

`innerText`:

```text
Hello
Welcome to JavaScript
```

`innerHTML`:

```html
<h2>Hello</h2>
<p>Welcome to JavaScript</p>
```

### Comparison table

| Feature | `textContent` | `innerText` | `innerHTML` |
|---|---|---|---|
| Reads content | Yes | Yes | Yes |
| Changes content | Yes | Yes | Yes |
| Returns text or markup | Text | Rendered text | HTML markup |
| Considers CSS visibility when reading | No | Yes | No |
| Parses assigned HTML | No | No | Yes |
| Replaces existing child content when set | Yes | Yes | Yes |
| Includes hidden descendant text when reading | Yes | Generally no | Yes, as markup |
| Best use | Plain text | User-visible rendered text | Intentionally inserting HTML |

### Which one should you use?

| Requirement | Recommended property |
|---|---|
| Read all descendant text | `textContent` |
| Change an element's plain text | `textContent` |
| Read rendered text as displayed | `innerText` |
| Insert HTML elements using markup | `innerHTML`, with trusted or safely sanitized markup |
| Display user-provided text | `textContent` |

**General rule:** Prefer `textContent` for plain text. Use `innerHTML` only when you intentionally need to parse HTML.

# 7. Security: Why `innerHTML` Can Be Dangerous

This is an important practical and interview concept.

## 7.1 Understanding the problem

Suppose a user enters this text into a website:

```html
<img src=x onerror="alert('Hacked!')">
```

If your application inserts that untrusted value using `innerHTML`, the browser parses it as HTML.

An image with an event-handler attribute may execute JavaScript when the image fails to load.

This is an example of a Cross-Site Scripting (XSS) vulnerability.

## 7.2 Unsafe example

```html
<div id="output"></div>

<script>
    const userInput =
        '<img src=x onerror="alert(\'Hacked!\')">';

    document.getElementById("output").innerHTML = userInput;
</script>
```

The browser interprets the supplied string as HTML, creating a potentially dangerous element.

## 7.3 Safe approach for plain text

```html
<div id="output"></div>

<script>
    const userInput =
        '<img src=x onerror="alert(\'Hacked!\')">';

    document.getElementById("output").textContent = userInput;
</script>
```

Now the browser displays the input as ordinary text.

It does not create an image element or interpret the event-handler attribute.

## 7.4 Important security rules

- Do not insert untrusted user input directly into `innerHTML`.
- Prefer `textContent` when displaying plain text.
- If HTML from an external or user-controlled source must be allowed, use a trusted HTML sanitization solution.
- Do not assume that escaping only a few characters is sufficient to prevent every XSS vulnerability.
- Be careful with event-handler attributes and unsafe URLs.

**Interview definition — XSS:**

Cross-Site Scripting (XSS) is a security vulnerability in which an attacker causes malicious scripts to execute in another user's browser through a vulnerable web application.

# 8. HTML Attributes and DOM Properties

Before learning `getAttribute()` and `setAttribute()`, understand the difference between an HTML attribute and a DOM property.

Consider:

```html
<input id="username" type="text" value="Prajwal">
```

There are two related concepts:

### HTML attribute

An attribute is written in the HTML markup.

```html
value="Prajwal"
```

### DOM property

A property is exposed on the JavaScript DOM object representing that HTML element.

```javascript
input.value;
input.type;
input.id;
```

The attribute describes information in the HTML markup. The DOM property represents the corresponding state or functionality exposed by the browser.

They are related, but they are not always identical.

### Example

```html
<input id="username" value="Prajwal">

<script>
    const input = document.getElementById("username");

    console.log(input.getAttribute("value"));
    console.log(input.value);
</script>
```

**Expected output:**

```text
Prajwal
Prajwal
```

Initially, both values are the same.

But consider what happens when the user edits the input.

```html
<input id="username" value="Prajwal">

<script>
    const input = document.getElementById("username");

    input.value = "Rahul";

    console.log(input.getAttribute("value"));
    console.log(input.value);
</script>
```

**Expected output:**

```text
Prajwal
Rahul
```

Why?

- `getAttribute("value")` reads the original HTML content attribute.
- `input.value` reads the current value of the input control.
- Changing the live `value` property does not automatically change the original `value` attribute.

This distinction is particularly important when working with forms.

# 9. `getAttribute()` in JavaScript

## 9.1 Definition

`getAttribute()` is a DOM method used to retrieve the value of a specified HTML attribute.

It returns the attribute's value as a string, or `null` if the attribute does not exist.

### Interview definition

`getAttribute()` is a DOM method that retrieves the value of a specified attribute from an HTML element.

## 9.2 Syntax

```javascript

```

## 9.3 Example 1: Reading the ID attribute

```html
<h1 id="heading">Welcome</h1>

<script>
    const heading = document.getElementById("heading");

    console.log(heading.getAttribute("id"));
</script>
```

**Expected output:**

```text
heading
```

## 9.4 Example 2: Reading multiple attributes

```html
<a
    id="myLink"
    href="https://example.com"
    target="_blank"
>
    Visit Website
</a>

<script>
    const link = document.getElementById("myLink");
```

**Expected output:**

```text
myLink

_blank
```

## 9.5 Example 3: Reading an attribute that does not exist

```html
</script>
```

**Expected output:**

**Remember:** `getAttribute()` returns `null` when an attribute is absent, not an empty string.

# 10. `setAttribute()` in JavaScript

## 10.1 Definition

`setAttribute()` is a DOM method used to create a new attribute or update the value of an existing attribute.

### Interview definition

`setAttribute()` is a DOM method that adds a specified attribute to an HTML element or updates its existing value.

## 10.2 Syntax

```javascript
element.setAttribute("attributeName", "attributeValue");
```

It takes two main arguments:

1. Attribute name.
2. Attribute value.

The value is converted to a string.

## 10.3 Example 1: Adding an attribute

```html
<h1 id="heading">Hello</h1>

<script>
    const heading = document.getElementById("heading");

    heading.setAttribute("class", "title");

    console.log(heading.getAttribute("class"));
</script>
```

**Expected output:**

```text
title
```

The resulting HTML is:

```html
<h1 id="heading" class="title">Hello</h1>
```

## 10.4 Example 2: Updating an existing attribute

```html
<img
    id="photo"
    src="old.jpg"
    alt="Old image"
>

<script>
    const image = document.getElementById("photo");

    image.setAttribute("src", "new.jpg");

    console.log(image.getAttribute("src"));
</script>
```

**Expected output:**

```text
new.jpg
```

The image's `src` attribute is updated.

## 10.5 Example 3: Adding a link target

```html
<a id="website" href="https://example.com">
    Visit Website
</a>

<script>
    const link = document.getElementById("website");

    link.setAttribute("target", "_blank");
    link.setAttribute("rel", "noopener");

    console.log(link.getAttribute("target"));
    console.log(link.getAttribute("rel"));
</script>
```

**Expected output:**

```text
_blank
noopener
```

## 10.6 Important behavior

If the attribute already exists, `setAttribute()` updates it.

If the attribute does not exist, `setAttribute()` creates it.

For HTML elements, attribute names are generally treated case-insensitively by the HTML DOM.

```text
    |
```

# 13. Working with Input Values Using `.value`

This is an especially important part of DOM manipulation.

HTML form elements such as:

- `<input>`
- `<textarea>`
- `<select>`

have a `value` property that represents their current value.

**Important:** To read or change an input's current value, use `.value`, not `textContent`.

## 13.1 Reading an input value

```html
<!DOCTYPE html>
<html>
<body>

    <input type="text" id="username" value="Prajwal">

    <script>
        const input = document.getElementById("username");

        console.log(input.value);
    </script>

</body>
</html>
```

**Expected output:**

```text
Prajwal
```

## 13.2 Changing an input value

```html
<input type="text" id="username" value="Old Name">

<script>
    const input = document.getElementById("username");

    input.value = "New Name";

    console.log(input.value);
</script>
```

**Expected output:**

```text
New Name
```

The input box now displays `New Name`.

## 13.3 Why not use `textContent`?

```html
<input type="text" id="username" value="Prajwal">

<script>
    const input = document.getElementById("username");

    console.log(input.textContent);
    console.log(input.value);
</script>
```

**Expected output:**

```text

Prajwal
```

The input's current entered value is exposed through `.value`, not through its text content.

## 13.4 Example: Getting a value when a button is clicked

```html
<!DOCTYPE html>
<html>
<body>

    <input type="text" id="username" placeholder="Enter your name">

    <button id="submitButton">Submit</button>

    <p id="result"></p>

    <script>
        const input = document.getElementById("username");
        const button = document.getElementById("submitButton");
        const result = document.getElementById("result");

        button.addEventListener("click", function() {
            const username = input.value;

            result.textContent = "Welcome, " + username;
        });
    </script>

</body>
</html>
```

### Example interaction

User enters:

```text
Prajwal
```

After clicking Submit:

```text
Welcome, Prajwal
```

### Dry run

1. JavaScript selects the input, button, and paragraph.
2. A click event handler is registered on the button.
3. The user enters a name.
4. When the button is clicked, `input.value` reads the current input value.
5. The result paragraph's `textContent` is updated.
6. The browser displays the welcome message.

# 14. The Difference Between `.value` and the `value` Attribute

This is a commonly tested interview concept.

Consider:

```html
<input id="username" value="Prajwal">
```

There are two related ways to access the value.

```javascript
input.getAttribute("value");
input.value;
```

Initially, both return:

```text
Prajwal
```

But they represent different things.

- `getAttribute("value")` reads the HTML content attribute.
- `input.value` reads the current value of the input control.

### Complete example

```html
<!DOCTYPE html>
<html>
<body>

    <input id="username" value="Prajwal">

    <script>
        const input = document.getElementById("username");

        console.log("Initial attribute:", input.getAttribute("value"));
        console.log("Initial property:", input.value);

        input.value = "Rahul";

        console.log("Updated attribute:", input.getAttribute("value"));
        console.log("Updated property:", input.value);
    </script>

</body>
</html>
```

**Expected output:**

```text
Initial attribute: Prajwal
Initial property: Prajwal
Updated attribute: Prajwal
Updated property: Rahul
```

### Why?

The `value` attribute provides the default value in the HTML markup.

The `value` property represents the current value of the input control.

Changing the property does not automatically update the original attribute.

### What is `defaultValue`?

For an input element, `defaultValue` represents the default value associated with its HTML value attribute.

```javascript
console.log(input.defaultValue);
console.log(input.value);
```

For the previous example, after changing `input.value` to `Rahul`:

```text
Prajwal
Rahul
```

### Quick comparison

| Expression | Meaning |
|---|---|
| `input.getAttribute("value")` | Reads the HTML value attribute |
| `input.defaultValue` | Reads the default value |
| `input.value` | Reads the current input value |

# 15. Working with Boolean Attributes

Some HTML attributes are Boolean attributes.

Examples:

- `disabled`
- `checked`
- `required`
- `readonly`
- `multiple`
- `selected`

For these attributes, their presence generally means true, while their absence means false.

### Example

```html
<button id="submitButton" disabled>
    Submit
</button>
```

The button is disabled because the `disabled` attribute exists.

You can check it using:

```javascript
const button = document.getElementById("submitButton");

console.log(button.hasAttribute("disabled"));
console.log(button.disabled);
```

**Expected output:**

```text
true
true
```

### Important: Attribute values can be misleading

```javascript
button.setAttribute("disabled", "false");
```

This does not enable the button.

The `disabled` attribute is still present, so the button remains disabled.

To enable it:

```javascript
button.removeAttribute("disabled");
```

Or use the DOM property:

```javascript
button.disabled = false;
```

### Boolean attributes versus string values

```javascript
button.setAttribute("disabled", "");
```

The button is disabled because the attribute exists.

For Boolean attributes, writing:

```html
<button disabled="false">Submit</button>
```

also means the button is disabled.

The word `"false"` does not turn a Boolean HTML attribute off.

Although the main focus is reading, setting, and removing attributes, one more method is important.

## Definition

`hasAttribute()` checks whether an element contains the specified attribute.

It returns a Boolean value.

### Syntax

```javascript
element.hasAttribute("attributeName");
```

### Example

```html
<button id="submitButton" disabled>
    Submit

    const button = document.getElementById("submitButton");

```

**Expected output:**

```javascript
element.getAttribute("disabled");
element.hasAttribute("disabled");
```

- `getAttribute()` returns the attribute value or `null`.
- `hasAttribute()` returns `true` or `false` depending on whether the attribute exists.

# 17. Working with Classes: `className` and `classList`

Class manipulation is another important way to modify an element's HTML attributes and presentation.

## 17.1 `className`

`className` gets or sets the entire class attribute of an element.

### Syntax

```javascript
element.className;
```

```javascript
element.className = "new-class";
```

### Example

```html
<p id="message" class="old-class">Hello</p>

<script>
    const message = document.getElementById("message");

    console.log(message.className);

    message.className = "new-class";

    console.log(message.className);
</script>
```

**Expected output:**

```text
old-class
new-class
```

**Important:** Assigning to `className` replaces the complete class list.

If an element has:

```html
<p class="card active highlighted">Hello</p>
```

Then:

```javascript
element.className = "new-class";
```

removes the previous classes and leaves only `new-class`.

## 17.2 `classList`

`classList` provides a convenient way to work with individual classes without replacing the entire class attribute.

It returns a `DOMTokenList`.

The important methods are:

| Method | Purpose |
|---|---|
| `add()` | Adds a class |
| `remove()` | Removes a class |
| `toggle()` | Adds the class if absent; removes it if present |
| `contains()` | Checks whether a class exists |
| `replace()` | Replaces one class with another |

### Example 1: `classList.add()`

```html
<p id="message">Hello</p>

<script>
    const message = document.getElementById("message");

    message.classList.add("highlight");

    console.log(message.className);
</script>
```

Output:

```text
highlight
```

### Example 2: `classList.remove()`

```html
<p id="message" class="highlight active">Hello</p>

<script>
    const message = document.getElementById("message");

    message.classList.remove("highlight");

    console.log(message.className);
</script>
```

Output:

```text
active
```

### Example 3: `classList.toggle()`

```html
<p id="message">Hello</p>

<script>
    const message = document.getElementById("message");

    message.classList.toggle("active");
    console.log(message.classList.contains("active"));

    message.classList.toggle("active");
    console.log(message.classList.contains("active"));
</script>
```

Output:

```text
true
false
```

The first call adds the class. The second call removes it.

### Example 4: `classList.contains()`

```javascript
const message = document.getElementById("message");

console.log(message.classList.contains("active"));
```

Returns `true` if the class exists and `false` otherwise.

### Example 5: `classList.replace()`

```html
<p id="message" class="old-class">Hello</p>

<script>
    const message = document.getElementById("message");

    message.classList.replace("old-class", "new-class");

    console.log(message.className);
</script>
```

Output:

```text
new-class
```

### `className` versus `classList`

| Feature | `className` | `classList` |
|---|---|---|
| Returns | Class attribute as a string | `DOMTokenList` |
| Add one class | Can be done by rewriting the string | `add()` |
| Remove one class | Requires string manipulation or reassignment | `remove()` |
| Toggle a class | No built-in toggle method | `toggle()` |
| Check a class | Requires string checking | `contains()` |
| Best use | Reading or replacing the full class string | Managing individual classes |

**Recommendation:** Prefer `classList` when adding, removing, checking, or toggling individual classes.

# 18. Practical Mini-Project: Dynamic Profile Card

Let's combine what we have learned.

### Requirements

Create a simple profile card that:

1. Displays a person's name.
2. Allows the user to enter a new name.
3. Updates the displayed name after clicking a button.
4. Adds a CSS class to highlight the updated name.

### Complete runnable code

```html
<!DOCTYPE html>
<html>
<head>
    <title>Dynamic Profile Card</title>

    <style>
        .highlight {
            color: green;
            font-weight: bold;
        }

        .card {
            border: 1px solid black;
            padding: 15px;
            width: 250px;
        }
    </style>
</head>

<body>

    <div class="card">
        <h2>My Profile</h2>

        <p id="username">Prajwal</p>

        <input
            type="text"
            id="nameInput"
            placeholder="Enter new name"
        >

        <button id="updateButton">
            Update Name
        </button>
    </div>

    <script>
        const username = document.getElementById("username");
        const input = document.getElementById("nameInput");
        const button = document.getElementById("updateButton");

        button.addEventListener("click", function() {

            const newName = input.value.trim();

            if (newName !== "") {

                username.textContent = newName;

                username.classList.add("highlight");

                input.value = "";

            } else {

                alert("Please enter a name");

            }

        });
    </script>

</body>
</html>
```

### Initial browser display

```text
My Profile

Prajwal

[Enter new name]

[Update Name]
```

### Example interaction

The user enters:

```text
Rahul
```

After clicking Update Name:

```text
My Profile

Rahul

[Enter new name]

[Update Name]
```

The updated name appears in green and bold.

### Understanding the execution flow

| Step | JavaScript operation | Purpose |
|---|---|---|
| 1 | `getElementById()` | Selects the required elements |
| 2 | `addEventListener()` | Registers a click handler |
| 3 | `input.value` | Reads the current input |
| 4 | `trim()` | Removes surrounding whitespace |
| 5 | `if` condition | Checks whether the value is empty |
| 6 | `textContent` | Updates the displayed name |
| 7 | `classList.add()` | Applies the highlight class |
| 8 | `input.value = ""` | Clears the input field |

This project demonstrates how DOM selection, text modification, input values, events, and class manipulation work together.

# 19. Common Mistakes and Their Corrections

## Mistake 1: Using `innerHTML` when only text is required

Incorrect:

```javascript
element.innerHTML = userInput;
```

Correct for plain text:

```javascript
element.textContent = userInput;
```

Reason: `innerHTML` interprets the supplied string as markup and can introduce XSS vulnerabilities when used with untrusted data.

## Mistake 2: Using `textContent` to insert HTML elements

Incorrect if you intend to create an actual heading:

```javascript
element.textContent = "<h1>Hello</h1>";
```

This displays the tags as text.

Correct when intentionally inserting trusted HTML:

```javascript
element.innerHTML = "<h1>Hello</h1>";
```

## Mistake 3: Confusing `innerText` and `textContent`

```javascript
element.textContent;
element.innerText;
```

They are not interchangeable.

- `textContent` reads descendant text regardless of CSS visibility.
- `innerText` reads rendered text and considers visibility and layout.

## Mistake 4: Using `textContent` to read an input value

Incorrect:

```javascript
const input = document.getElementById("username");

console.log(input.textContent);
```

Correct:

```javascript
console.log(input.value);
```

## Mistake 5: Thinking `setAttribute("disabled", "false")` enables a button

Incorrect:

```javascript
button.setAttribute("disabled", "false");
```

Correct:

```javascript
button.removeAttribute("disabled");
```

Or:

```javascript
button.disabled = false;
```

## Mistake 6: Replacing every class accidentally

Suppose:

```html
<p id="message" class="card active">Hello</p>
```

Incorrect if you want to add one class:

```javascript
message.className = "highlight";
```

This replaces both existing classes.

Correct:

```javascript
message.classList.add("highlight");
```

## Mistake 7: Forgetting that `getAttribute()` can return `null`

```javascript
const result = element.getAttribute("missing");
console.log(result);
```

Output:

```text
null
```

Check whether the attribute exists before relying on its value.

## Mistake 8: Confusing the attribute with the current property value

```javascript
input.setAttribute("value", "Prajwal");
input.value = "Rahul";
```

After these statements:

```javascript
console.log(input.getAttribute("value")); // Prajwal
console.log(input.value);                 // Rahul
```

The current input value and the HTML attribute can differ.

# 21. Interview Questions and Answers

## Q1. What is `textContent` in JavaScript?

`textContent` is a DOM property that retrieves or updates the text content of an element and its descendants without interpreting assigned content as HTML.

## Q2. What is `innerText`?

`innerText` is a DOM property that retrieves or updates the rendered text of an element, considering how the text is displayed in the browser.

## Q3. What is `innerHTML`?

`innerHTML` is a DOM property that retrieves or modifies the HTML markup inside an element. When a string is assigned, the browser parses it as HTML.

## Q4. What is the difference between `textContent` and `innerHTML`?

`textContent` treats assigned content as text, whereas `innerHTML` parses assigned content as HTML markup and creates corresponding DOM elements.

## Q5. What is the difference between `innerText` and `textContent`?

`innerText` considers rendered text and CSS visibility, while `textContent` reads descendant text regardless of whether it is visually hidden.

## Q6. Which property should you use to display user-provided text?

Prefer `textContent` because it treats the value as text rather than parsing it as HTML.

## Q7. Why can `innerHTML` be dangerous?

Inserting untrusted strings using `innerHTML` can allow attackers to inject malicious HTML and scripts, potentially creating XSS vulnerabilities.

## Q8. What is `getAttribute()`?

`getAttribute()` retrieves the value of a specified HTML attribute. It returns `null` if the attribute does not exist.

## Q9. What is `setAttribute()`?

`setAttribute()` creates a new attribute or updates an existing attribute on an HTML element.

## Q10. What is `removeAttribute()`?

`removeAttribute()` removes a specified attribute from an HTML element.

## Q11. What is the difference between an HTML attribute and a DOM property?

An HTML attribute is part of the element's markup, while a DOM property is a JavaScript-accessible property on the element object. They are related but can represent different values or states.

## Q12. What is the difference between `input.value` and `input.getAttribute("value")`?

`input.value` represents the current value of the input control, whereas `getAttribute("value")` retrieves the HTML value attribute, which generally represents the default value.

## Q13. How do you get the current value of an input field?

Use:

```javascript
const value = input.value;
```

## Q14. How do you disable a button using JavaScript?

Using the DOM property:

```javascript
button.disabled = true;
```

Or:

```javascript
button.setAttribute("disabled", "");
```

## Q15. How do you enable a disabled button?

Using the DOM property:

```javascript
button.disabled = false;
```

Or:

```javascript
button.removeAttribute("disabled");
```

## Q16. What is `hasAttribute()`?

`hasAttribute()` checks whether an element contains a specified attribute and returns `true` or `false`.

## Q17. What is `className`?

`className` is a DOM property that reads or replaces the complete class attribute of an element.

## Q18. What is `classList`?

`classList` provides a `DOMTokenList` interface for managing individual classes using methods such as `add()`, `remove()`, `toggle()`, `contains()`, and `replace()`.

## Q19. What is the difference between `className` and `classList`?

`className` works with the complete class string, whereas `classList` allows individual classes to be added, removed, checked, or toggled.

## Q20. Does setting `textContent` preserve existing child elements?

No. Setting `textContent` replaces the existing child content with a text node.

## Q21. Does setting `innerHTML` preserve existing child elements?

No. Assigning to `innerHTML` replaces the existing child content with the parsed markup.

## Q22. What is XSS?

Cross-Site Scripting is a security vulnerability in which malicious scripts are injected into a web application and executed in another user's browser.
