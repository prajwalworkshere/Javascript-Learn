# Module 5 Roadmap

| Module | Topic | What You'll Learn |
| :--- | :--- | :--- |
| 5.1 | Introduction to the DOM and how it works | DOM tree structure, nodes, and how browsers parse HTML into JavaScript objects. |
| 5.2 | Selecting HTML elements | Using methods like getElementById, querySelector, and querySelectorAll to target elements. |
| 5.3 | Changing text, HTML, and attributes | Modifying content using innerText, textContent, innerHTML, and managing attributes via setAttribute. |
| 5.4 | Modifying CSS styles and classes | Dynamically altering styles with the style property and managing classes using classList (add, remove, toggle). |
| 5.5 | Creating, inserting, replacing, and removing elements | Building new DOM elements with createElement, placing them using appendChild or insertBefore, and deleting nodes. |
| 5.6 | JavaScript events and event listeners | Handling user interactions using addEventListener for clicks, keypresses, and other window events. |
| 5.7 | Event objects, bubbling, and delegation | Understanding event propagation, using the event object, and optimizing performance with event delegation. |
| 5.8 | Forms, inputs, and validation | Capturing form data, handling submission events, and validating user input before processing. |
| 5.9 | Mini-project: Interactive web page | Combining all concepts to build a functional, dynamic, and highly interactive frontend application. |
